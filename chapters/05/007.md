## execve：把状态机复位为另一程序

![图 113：execve：把状态机复位为另一程序（01:13:13）。](/assets/images/05/0113.webp)

图 113：execve：把状态机复位为另一程序（01:13:13）。

程序 a fork 后，得到 a 和 clone。另一个调用叫 execve：execute，v 表示参数向量，e 表示 environment、环境变量。还记得 C 语言状态机的初始状态吗？main 通过 argc、argv 得到命令行参数。若 A′ 调用 execve，指定 a\.out，原来复制自 a 的全部状态就在原地销毁，再变成新程序的初始状态。这可以理解为状态机复位。a 执行、fork 复制，到了 execve，就替换成另一个程序，还能传入 main 参数和环境变量。

大家最早写简单的 main，后来知道它能带参数，今天又看到完整形式。argc 是 argument 的 count，也就是参数数量。

## execve 设置参数、环境变量和程序入口

![图 114：execve 设置参数、环境变量和程序入口（01:15:00）。](/assets/images/05/0114.webp)

图 114：execve 设置参数、环境变量和程序入口（01:15:00）。

![图 115：execve 演示中的 argv 与 envp（01:15:02）。](/assets/images/05/0115.webp)

图 115：execve 演示中的 argv 与 envp（01:15:02）。

```
#include <unistd.h>
#include <stdio.h>

int main() {
    char *const argv[] = { "/bin/bash", "-c", "env", NULL };
    char *const envp[] = { "HELLO=WORLD", NULL };

    // Reset the state machine to "/bin/bash"
    execve(argv[0], argv, envp);

    // We are here only on error.
    printf("Hello, World!\n");
}
```

argv 是 argument 的 vector。argv0 是命令行调用的程序，比如 a\.out。运行 \./a\.out 1 2 3，argv 的 1、2、3 分别是 1、2、3，这就是 procfs 的 command line、cmdline 中看到的参数。此外，main 还能接收环境变量，不使用这个参数也没关系，程序可能不 care 环境。在 C 里，也可以通过 environ 访问当前环境变量，无须从 main 参数取出。

状态机复位解释了这些信息怎样产生。在 UNIX 世界，这是执行程序的唯一系统调用，所以用 strace 追踪任何程序，第一条调用都是 execve。

进程复位后，操作系统资源默认会继承，讲文件描述符时还会讨论。用 execv 库函数启动，也默认继承环境变量，OpenAI 的 API key 就传给子进程；子进程若有不良行为，可能把 key 泄露。我担心龙虾这样做迟早出事，但不确定它是否把 key 放在环境变量，因为现在也有更好的管理方式。许多人仍喜欢这样配置，早期教程也常要求在 \.bashrc 里 export OpenAI API key。

这样所有应用都能使用 key，也有风险；若我刚才这样展示，就得赶快 disable API key。环境变量还有许多日常用法。echo $PWD 能获取当前 working directory；term 表示终端类型。我使用 foot，但它伪装为兼容的 xterm\-256color。
