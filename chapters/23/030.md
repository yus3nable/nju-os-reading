只要支持 random read，就能借助指针实现任意随机读写的数据结构，比如 list、set。这叫 persistent data structure，恰好与这里的“持久化”重名。怎样实现？假设有一棵二叉树，它可能具有 log n 时间复杂度。

![图 41：插入新节点之前的二叉树（00:48:00）。](/assets/images/23/0041.webp)

图 41：插入新节点之前的二叉树（00:48:00）。

从根到叶最多 log n 层。每个节点存更多数据，log 的底可能更大，树就更浅。要插入、删除节点，树结构会变化。比如插入 n，本来想做 x 的 left 等于 n，但已经存进只读部分的节点不能改，x 的 left、right 已固定，可能都是空。怎么办？可以新建节点，把根到 x 的整条路径复制一份，其他指针仍指向旧节点。

无论共享子树中有多少节点，它们都没变，左右子树仍然正确。只复制根到叶的路径，代价是 log n。新复制的节点可以连上新建的 n，就在 log n 空间中完成插入。这就是 persistent data structure。
