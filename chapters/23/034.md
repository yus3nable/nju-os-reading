我们希望它有电子的密度，电路的速度，这才能和我们运行在 5GHz 的 CPU 的速度能够匹配，那什么东西呢？只有一种东西可以满足，那就是电路，所以就有了 flash memory，然后这个想法也是可能不是那么的惊天动地，你就是希望在一个电路里面挖一个坑。然后你把电子填进去就是一个状态。然后再把电子放跑它就是另一个状态。对吧？就跟我们的说，我们一个磁针朝着这里，朝着那里就可以区分零和一，一个坑挖下去和填起来就是零和一一样，就可以区分零和一的状态。当然在这里。资本家为了尽可能的压榨一个坑里面的数据。

甚至是可以用精确的控制放进去多少电子，这样它就产生一个电势差，对吧？然后通过这个测量它的电势差来决定，来决定你的 bit到底是多少，这样就可以在一个空间里面实现多个 bit，比如说你可以实现两个 bit，TLC 是三个 bit，QLC 是四个 bit，对，这就是一个 bit 的 flash memory，对，这个 flash memory 和这个 MOSFET 非常像，只是在上面有一个 floating gate。然后在这个浮栅上面你对它充电和放电。然后你就可以把电子塞进去。

然后再可以把电子给放出来，这样充电放电来实现零和一，然后 flash memory 就有一些完全不讲道理的特点了，就是它全身都是好处，首先它便宜。
