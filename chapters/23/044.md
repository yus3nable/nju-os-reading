课件中的块数组抽象；block 类型和 NUM\_BLOCKS 未展开：

```
struct block disk[NUM_BLOCKS];
```

那我们的操作系统，也需要对这样的 byte array，做一定的抽象，那我们是怎么做这个抽象的呢？然后回顾一下，刚才我们的各种各样的存储设备，对吧，从 Project Silica，到我们的磁盘，再到我们的闪存。实际上光你光能存储一个 bit，可能是有各种各样好的办法的，但是你如果要把这个 bit 给找出来。对吧，因为你有好多好多，你本质上是一个这样的 byte array 的逻辑结构，如果你想要把一个 bit 给找出来，你就需要一个定位的操作。对吧。一个寻址的操作。

而这个寻址的操作，是在你设计硬件的时候要付出代价的。
