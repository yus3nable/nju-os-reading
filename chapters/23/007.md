我记得我小的时候，真的还在玩小霸王的时候，学习机就是这样的东西，对吧？我小的时候这样的学习机是要插卡带的，然后那个卡带里面是有只读的 read\-only 的 memory 的。然后如果你想要 persist 的，比如说那个学习机上还可以写 basic 的程序。然后如果你想要写 basic 的话，你会需要连接一个录音机，然后它把音频信号转写到一个磁带上。就是一个这样的磁带上，然后你再可以把它读出来。所以一直到我小的时候，我们其实还在用这样的设备来存储。
