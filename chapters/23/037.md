U 盘等 flash memory 用电路存 1 bit，通过 floating gate 充放电表示状态，但有一个致命缺点：放电不彻底，每次都有残留电子。放电应该要 20 伏，即便这么高，也无法完全放干净。

课件用于提出问题的 Python 片段；Path 来自 pathlib，导入语句未展开：

```
for i in range(1000):
    Path("a.txt").write_text(str(i))
```

几千或几万次以后，flash cell 就像一直充着电，进入 Erase Saturation，发生 wear out，不能用了。今天 QLC flash cell 大概只有一千次写入寿命。那么反复写一个文件，文件是不是很快就坏？

比如把 a\.txt 写一千次，每次不同值，按 erase 一千次就坏的说法，似乎就该损坏。但大家没遇过，日志、系统文件等已经修改很多次，显然可能超过一千次，为什么还没坏？
