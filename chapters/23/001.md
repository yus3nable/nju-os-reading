我们今天进入持久化部分的第二节课，我们来讲存储设备的抽象，就我会讲一个 bit 是怎么存储的，所以我今天带了一些比较有趣的存储设备，一会儿会给大家展示。在今天的课正式开始之前，我先评论一下，应该是昨天我在群里看到一位老朋友在 DeepSeek 招聘Agent Harness 研发工程师，然后我发现他们对 Harness Engineering 的定义，对吧？除了模型本身以外，所有的工作都是属于Harness 的范畴，然后希望这个 Job 是参与 DeepSeek 桌面端 agent 产品研发的全过程，所以他们可能会有个像 Codex 这样的东西，我不知道他们想做什么，但他们很有可能会在不远的将来就要发布。

然后他这个 Job Description 里面有一个认知的要求，他说能够在 AI 的辅助下，在没有直接经验的领域，比如说语言，技术，框架等，进行有质量保障的编程工作。然后对于 Agent Harness 的开发有极大的热情，对模型的行为有品位有判断力，对开发者体验有强感知，就是深度使用过 Coding Agent 等等等等等等等等等等。所以你看到 DeepSeek 岗位在招什么，他就在招 AI 原生时代的超级个体，因为你如果真正用过这些 Agent 的话，你会发现你的效率其实是很高的，你其实没什么产品是不能做的，因为你可以在没有直接经验的领域进行编程工作。对吧，然后我就跟这个写这个 JD 的人聊了一会儿，那他就说这年头还有不拥抱 AI 的学生啊，然后我突然就觉得你看可能有不少同学在到上我这门课之前都没有用过 Coding Agent 这样的东西，也许啊，有可能。然后你马上就觉得是我们在大学里面学的这些传统的学习方法，可以说就是出生就是死亡了，所以我们真的有必要去重新思考一下我们看待每一个知识，然后包括我上课的时候我也经常会想我们在做每一件事情的时候，未来会变成什么样的。当然技术性的内容还是要讲的，所以我继续啊，今天要讲持久化。
