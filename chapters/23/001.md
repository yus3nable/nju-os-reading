今天是持久化部分的第二节课，讲存储设备的抽象，从一个 bit 怎样存储开始。我带了一些存储设备，稍后展示。先评论一件事：应该是昨天，在群里看到一位老朋友为 DeepSeek 招聘 Agent Harness 研发工程师。按他们对 Harness Engineering 的定义，模型本身以外的工作，都属于 Harness。这个 Job 要参与 DeepSeek 桌面端 agent 产品研发全过程，可能是类似 Codex 的产品。我不知道具体想做什么，但很可能不久就会发布。

![图 1：DeepSeek 的 Agent Harness 招聘与任职要求（00:00:30）。](/assets/images/23/0001.webp)

图 1：DeepSeek 的 Agent Harness 招聘与任职要求（00:00:30）。

Job Description 要求：借助 AI，在没有直接经验的领域，包括语言、技术、框架等，完成有质量保障的编程；对 Agent Harness 开发有热情，对模型行为有品位、判断力，对开发者体验有感知，深度使用过 Coding Agent。这是在招 AI 原生时代的超级个体。用过 Agent 就能感到效率提升，几乎没有不能做的产品，因为能在缺乏直接经验的领域编程。我与写 JD 的人聊，他说：“这年头还有不拥抱 AI 的学生啊。”可能有些同学在上这门课前没用过 Coding Agent，也许如此。这让我觉得，大学里传统学习方法可能出生就是死亡，需要重新思考每一项知识。我上课也常想，所做的事未来会变成什么样。技术内容仍然要讲，今天继续持久化。

![图 2：Agent 建议将摄像头改为 YUYV 640×480，等待确认（00:02:00）。](/assets/images/23/0002.webp)

图 2：Agent 建议将摄像头改为 YUYV 640×480，等待确认（00:02:00）。

画面中 Agent 提议的摄像头参数修改；此时仍停在确认界面：

```
# 修改前
vlc v4l2:///dev/video0 --v4l2-chroma=MJPG \
    --v4l2-width=1280 --v4l2-height=720 --v4l2-fps=25
# 提议修改为
vlc v4l2:///dev/video0 --v4l2-chroma=YUYV \
    --v4l2-width=640 --v4l2-height=480 --v4l2-fps=25
```
