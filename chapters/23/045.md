电路需要额外的寻址电路、行选通和列选通信号；磁盘需要读写头、转轴。SSD 原本就是电路，再增加一些电路可能没那么困难，磁盘、Project Silica 等则要额外物理器件配合。为了降低定位成本，设备虽然表现为 byte array，仍希望多个 byte 共享定位组件。

即使 SSD，也会按 die、plane、block、page 分层组织。page 一般是 16KB，这个 size 不固定。16KB 数据一次并行读出；erase 的单位可能更大，比如 4 兆一起擦除。

写入也可能以 16KB 为单位，减少寻址开销，省去为每个 bit 单独配置行选通、列选通线的电路。同样，磁盘、软盘可能按 512 字节组织，一段连续的 512 字节叫 sector、扇区，开始读就连续读完。

设备无需转到任意位置只读一个字节。程序可以通过 memory access locality，让读写具有局部性，与设备的降成本设计相互配合。因此希望看到的是 byte array，设备层呈现的却是 struct block 数组，每块可能是 16KB。

也可能是更大尺寸，或者 4KB。
