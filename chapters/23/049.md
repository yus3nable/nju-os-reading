Linux 会实现上层接口，这是课堂介绍的原理。回想开课时 DeepSeek 的招聘要求：在没有直接经验的领域，借助 AI 做有质量保障的编程。我就来实践，假装对这件事完全不了解，只是听操作系统课知道设备按块读写。能不能真的在系统内部看到这些操作？

我写了几行 prompt，也让它遵循一些设计，把程序分成几个组件，相互通信。实际我知道 Linux 内核里发生了什么，只是故意假装不知道。AI 实现了几个工具，其中一个能在存储系统发生 block 读写时，把操作直接打印出来，里面用到了 eBPF。

不懂 eBPF 也不要紧。操作系统是程序，就能 debug；块读写一定有代码实现，就有办法在执行这些操作时观察它。

终端先因权限不足失败，随后用 sudo 启动跟踪：

```
$ ./bio-trace.bt
ERROR: bpftrace currently only supports running as the root user.
$ sudo ./bio-trace.bt
Attaching 6 probes...
```

这是 first principle，按它就能做到。不明白的细节可以再问 AI。这样就拿到了系统中全部 block read、write 的序列。
