Linux 帮你，帮你实现的，当然这是我上课的时候讲的原理，还记得我今天刚开始上课的时候那一页幻灯片说，DeepSeek 在招能够在没有直接经验的领域，进行有质量保障编程工作的人，然后我就想着来实践一下，我假装我对，假装我对这件事情一点都不了解，今天我上了操作系统课，我听说，听老师说，Linux 操作系统里面有这么一些东西，因为这个好理解对吧，这个世界上有一个东西叫读块和写块，这个设备是按块访问的，这个是非常容易理解的，所有人都知道。我们能不能真的在操作系统里面看到它呢？

我作为一个没有任何知识的人，于是我就写了几行的 prompt，当然我一定程度上让它遵循了我的一些比较好的设计，比如说我分成了几个组件，然后让这些组件互相通信，当然我是有概念的，我是知道 Linux 内核里面发生了什么的，但是我故意假装我自己不知道，我发现 AI 可以非常好的，OK，我让 AI 帮我实现了好几个工具。然后这其中的一个工具就是，当我有任何磁盘或者说存储系统的 block 的读或者写的时候，我都可以把这个读和写直接打印出来。对吧。你不知道这是怎么实现的，比如说这里面用了 eBPF。

你们可能不知道 eBPF 是什么，你也不需要知道，你只需要知道的是操作系统也是一个程序，如果是一个程序，我没有任何道理，我不能 debug 它，没有任何道理不能在它执行一些关键操作的时候，我把这关键操作给拉出来，因为我知道读一个 block 或者写一个block，它一定是有代码实现的，对吧。

终端先因权限不足失败，随后用 sudo 启动跟踪：

```
$ ./bio-trace.bt
ERROR: bpftrace currently only supports running as the root user.
$ sudo ./bio-trace.bt
Attaching 6 probes...
```

这是你知道的 first principle，然后这件事情就是能做到的，所以你看到这里面有一些你可能不太明白的东西，但这都不要紧，你不明白你能问问 AI，让 AI 教你解释明白，然后既然你得到了这个系统里面所有的 block 的 read 和 write。
