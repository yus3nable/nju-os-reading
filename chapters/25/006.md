Agent 列出的三个接口名：

```
inotify_init() / inotify_init1()
inotify_add_watch()
inotify_rm_watch()
```

Linux 常用文件描述符表示对象，因此能用 epoll、select 监听。可以持有多个 inotify 文件描述符，任一个有更新都能发现。相关接口还有 inotify\_init、inotify\_add\_watch、inotify\_rm\_watch。
