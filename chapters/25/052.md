忘装软件后，如果改原 RUN 命令，就要退到该命令之前的 layer，重新 replay 这条及后续全部命令。连 Ubuntu 22\.04 基础镜像都改了，更要重放全部操作。因此想补一个包，可以再加 run apt install，在现有层上增加 upper，下面都保留为 lower。逐层叠加，又是 persistent data structure。
