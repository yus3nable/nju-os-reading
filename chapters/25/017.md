这个机制很 powerful。代码由自己写，内核暴露各种 trace point，可以让 AI 全部列出，能做的事很多。我们确实 vibe code 过 bpf 程序，捕获全部键盘按键、鼠标移动，还能结合关键系统调用 trace。

比如 execve trace 加鼠标、键盘 trace，基本能复原这台 Linux 上全部操作轨迹。它也能辅助学习 shell、Vim。我也想更熟练，但有时没动力做这样自虐的训练。可以先用 BPF 把带时间戳的按键 trace 从内核取出来。

再结合 Vim buffer 随时间 evolve 的快照，让模型判断：“做这个编辑能否更好？”模型就能不断指出更有效的操作方式。实现不难，但持续这样训练会带来很大心智负担，可能只有愿意自虐的人会做。

这些原本可能想不到的事，都是从 inotify、strace、ltrace 逐步想到的。
