上一节课我们讲了文件系统增删改查那个部分的 API，对吧，因为你们已经非常熟练的可以在 Windows 的那个资源管理器里面右键，然后新建一个目录，然后可以编辑一个文本文件，这些其实都是大家非常熟悉的 API，然后我们知道了像 mkdir，然后 Link，Unlink，Symlink 这样的机制，你不仅可以创建一个普通的文件，而且你还可以创建两份指针指向完全相同的一个文件，两个它可能是不同的名字，但是一份改了，另一份会跟着同步地修改，我们也可以做一个像快捷方式一样的符号链接，以及我们可以在文件上面可以标注一些属性，可以把从 Unix 默认的这个 Mode，比如说读写执行的权限，然后到比如说 Windows 里面，其实 FAT 里面是没有这些读写执行的权限，但是它有一些其他自己的这个文件的 MetaData，然后到 Extended Attributes，可以允许你把任意的一个Key\-Value 的值写到一个文件里，并且带着这个值来跑。

然后我们上节课讲的都是这些相对来说比较简单的对文件的一小步操作，增删改查，然后我们当然可以写一个应用程序来管理很多这样的文件，OK 没问题，但是操作系统上面能干的事情远远不止于此，所以我今天就会说在增删改查的基础上，我们现在可以设计真正的文件系统级的 API 了，对吧？在上节课的时候，我觉得有一个比较有趣的 API 是 Mount 挂载，挂载就是一个文件系统级的API，他说我可以把一个块设备，一个字节序列的抽象，然后把这个，比如说一个甚至是文件系统里的一个文件，可以通过一个回环设备，对吧？

任何一个设备，块设备都可以把上面的文件系统挂载到目录树当中，这就在目录树里面创建了一个新的目录，对吧？然后它里面有好多好多的东西，这个很有趣，所以今天的我们的思路是回到这样的一个根本的问题上，文件系统我们说是一个数据结构，它是一个Abstract Data Type，既然它是数据结构，理论上说是我们可以定义这个数据结构上面的各种各样的操作的，比如说你们学数据结构的例子，如果是一个 persistent 的 Data Structure。
