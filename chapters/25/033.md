本地没有 A、B 分叉，只有远端产生 C、D，就能直接拉过来同步，这叫 Fast Forward。有时拉其他 Git repo 会看到这个 Message，表示本地只需接上原先没有的提交。

![图 41：没有本地分叉时直接向前同步（00:47:17）。](/assets/images/25/0041.webp)

图 41：没有本地分叉时直接向前同步（00:47:17）。

若本地已有 A、B，标准 Merge 因为已经 Diverge，就要新建 E。这里特意 NoFast Forward，合并 newnew，要求创建新 Commit。查看 Merge branch 'newnew' into new，会有两个 Parent，一个是 531，另一个是远端提交。这就是新合并节点。
