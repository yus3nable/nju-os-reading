先看监控：希望文件系统变化时收到通知。

![图 3：监控需求与 stat、diff 原型（00:04:09）。](/assets/images/25/0003.webp)

图 3：监控需求与 stat、diff 原型（00:04:09）。

课件中的 Bash 命令；\*\* 的匹配范围按原课说明取决于 shell 配置：

```
diff <(stat -c '%n %y' **) <(sleep 2; date > a.txt; stat -c '%n %y' **)
```

最好还能知道哪个文件变了。开发 web server 时就有这种需求，比如 Python flask 的 debug mode。假设框架中有一个 route，请求 /hello，会调用对应 function 返回结果，与 httpd 实验相似。

a\.py 执行后，内容已经加载进进程地址空间。再改磁盘上的 a\.py，内存中仍是旧的 hello，需要 reload。可能要重建进程、杀掉旧进程，因此先要监控文件系统。

![图 4：代码修改以后，进程中的旧内容仍在（00:05:11）。](/assets/images/25/0004.webp)

图 4：代码修改以后，进程中的旧内容仍在（00:05:11）。

项目有几百、几千个文件时更需要。next\.js 的 reload 更彻底，保存 css 的瞬间，旁边浏览器里的页面就更新了。让 coding agent 修改前端 style，还能看见界面随它逐步变化，直到改出目标效果。这是实用需求，原则上不依赖操作系统专门支持也能实现，比如给 a\.txt 写一个 shell script。
