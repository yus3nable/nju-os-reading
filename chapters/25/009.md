对吧，你改一个文件的 modifytime，它的上一级的目录的 modifytime 也会修改，那你就问啊，如果我有好多好多层目录，比如说我现在有这个一二两层的目录。如果我在这里 touch 一个 a\.txt，那它的上级目录的修改时间改了，那它的再上级会不会改呢？它会不会一层一层的向上传递呢？

图 13：嵌套目录中只有直接父目录收到 modified（00:12:59）。

嵌套目录事件中的连续片段；同一轮其他事件未展开：

```
Event 'created'
  Path: ./t/1/2/a.txt
Event 'modified'
  Path: ./t/1/2
Event 'opened'
  Path: ./t/1/2/a.txt
```

它不会，对吧，你看到这里只有 t/1/2 改了，然后 t/1/2 的 a\.txt open，打开了，修改了，关闭了，然后关闭的时候这个modificationtime 又会，对吧，或者修改以后那 modificationtime 又会改变。所以你看到这里有一个 t/1/2。好，这就是你可以去监视、监听文件系统的变化，没有什么困难的，对吧，它就是一个很切实的需求。
