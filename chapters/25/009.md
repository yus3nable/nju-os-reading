刚才文件变化，上级目录的 modifytime 也跟着改。若有一、二两层目录，在里面 touch a\.txt，上级的修改时间变了，再上级会变吗？会逐层传播吗？

![图 13：嵌套目录中只有直接父目录收到 modified（00:12:59）。](/assets/images/25/0013.webp)

图 13：嵌套目录中只有直接父目录收到 modified（00:12:59）。

嵌套目录事件中的连续片段；同一轮其他事件未展开：

```
Event 'created'
  Path: ./t/1/2/a.txt
Event 'modified'
  Path: ./t/1/2
Event 'opened'
  Path: ./t/1/2/a.txt
```

不会。这里只看到 t/1/2 改变，里面的 a\.txt 依次 open、修改、关闭，修改或关闭时 modificationtime 又变化。监控能直接看到这些文件系统事件，是很实际的需求。
