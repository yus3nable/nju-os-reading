在 \.git 目录中查看 HEAD、TAIL 并比较；diff 仅转录内容变化：

```
$ cat HEAD
ref: refs/heads/master
$ cat TAIL
ba1ce3b34b7bc61913ce4ab2b914dafb8963b201
$ git diff HEAD TAIL
-Hello, World
+Hello
```
