对象放进 \.git/objects，像上节课 nix store 一样。tree、commit 等 object 也在里面。其余则是引用：HEAD、head 是指针，指向 refs/heads/master，而这个文件再指向 commit object。

现在它指向最新 commit。我也可以仿照创建 tail，或者 TAIL，在其中放 ref 指针，然后 git diff head 和 TAIL，比较两个对象。

![图 30：创建 TAIL 后比较 HEAD 与 TAIL（00:39:29）。](/assets/images/25/0030.webp)

图 30：创建 TAIL 后比较 HEAD 与 TAIL（00:39:29）。

在 \.git 目录中查看 HEAD、TAIL 并比较；diff 仅转录内容变化：

```
$ cat HEAD
ref: refs/heads/master
$ cat TAIL
ba1ce3b34b7bc61913ce4ab2b914dafb8963b201
$ git diff HEAD TAIL
-Hello, World
+Hello
```
