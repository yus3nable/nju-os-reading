SICP 中 functional programming 的作用又体现出来了。Git 的常用 feature 已有基本概念，更多细节可以继续问 AI。既然 persistent data structure 这么好，能否把整个文件系统也这样实现？

已经有这样的文件系统，历史十来年甚至更早，大概十几年的时候就能在 production 用。但早期有 bug，我们长期使用时，遇到过整个文件系统无法使用。

图 50：Btrfs 的文件系统快照接口与共享结构（00:58:43）。

课件中的快照接口片段；fd 和其余参数依赖文件系统及调用上下文：

```
ioctl(fd, BTRFS_IOC_SNAP_CREATE, ...);
```

它叫 Btrfs，采用数据结构课的 B\-tree。一个大块可以形成比如 4096 叉树，比二叉树的索引层数浅得多。Everything is a B\-tree。与 Git 不同，Git 已有文件系统，往 \.git/objects 放对象即可；Btrfs 必须在块设备上实现。

需要从零构建块设备上的 persistent data structure，再用它组织所有内容。
