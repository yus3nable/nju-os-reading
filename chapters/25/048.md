多个 lower 可以 overlay 成一个目录。

![图 55：OverlayFS 的 mount 参数与 whiteout（01:08:36）。](/assets/images/25/0055.webp)

图 55：OverlayFS 的 mount 参数与 whiteout（01:08:36）。

课件中的联合挂载参数示意；L1、L2、U、W 与 path\_to\_merged 是目录占位符：

```
mount -t overlay overlay \
    -o lowerdir=L1:L2:...,upperdir=U,workdir=W \
    path_to_merged
```

但 upper 只有一个，还需要临时 work directory，供操作系统使用。我的 demo\.sh 就是 mount lower、upper 和 work directory，后者必须为空，否则应该会报错。右侧实时监控 OverlayFS 变化。

先向 upper 放 a\.txt，实体文件出现在 upper，overlay 中也能看到。echo 修改 upper，overlay 同步更新。

![图 56：upper 新增 a\.txt，overlay 同时可见（01:09:38）。](/assets/images/25/0056.webp)

图 56：upper 新增 a\.txt，overlay 同时可见（01:09:38）。
