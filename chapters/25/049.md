对吧，在你 hash table 里面删除的时候，你需要一个 tombstone，然后类似的，你看到 lower 里面这个 lower\.txt 是永远不变的，lower 是不会变的，lower 的多少层，无论你 overlay 多少层，它都不会变。

![图 58：删除 lower\.txt 后，overlay 中不再显示它（01:10:41）。](/assets/images/25/0058.webp)

图 58：删除 lower\.txt 后，overlay 中不再显示它（01:10:41）。

但是它在 upper 这一层里面，就产生了一个很有意思的对象，一个字符设备文件，然后这个字符设备文件，你当然没有办法访问的，比如说你可以试图 cat，你看它会说 Permission denied，这是一个假装出来的不存在的文件。

![图 59：upper 中的 whiteout 字符设备与读取失败（01:10:58）。](/assets/images/25/0059.webp)

图 59：upper 中的 whiteout 字符设备与读取失败（01:10:58）。

upper 中的 whiteout 行与实际读取结果：

```
c--------- 2 root root 0, 0 May 28 15:36 lower.txt
$ cat lower.txt
cat: lower.txt: Permission denied
```
