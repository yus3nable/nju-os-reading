这里做 diff。尖括号中的内容可以是任意命令，右边用分号连接：睡两秒，把 date 写进 a\.txt，再执行另一个命令。这种写法把命令输出变成文件接口，交给需要两个文件的 diff，比如 diff a\.txt b\.txt。stat 则输出文件元数据，包括 mode、modification time 等 attributes。

![图 5：尖括号把命令输出交给文件接口（00:06:45）。](/assets/images/25/0005.webp)

图 5：尖括号把命令输出交给文件接口（00:06:45）。

后面跟通配符，就能列出 /etc 等目录下所有文件的修改时间。这里 \*\* 匹配当前目录及子目录，bash 要做相应配置才有这个 feature，也可用 \*\*/\* 表示目录下的文件。脚本先立即取得修改时间，睡两秒，改 a\.txt，再 stat 一次，diff 就能发现变化。如果睡两秒却不改文件，diff 没有输出。这一行就能形成 last modified 列表。

![图 6：修改文件得到差异，不修改时没有输出（00:07:47）。](/assets/images/25/0006.webp)

图 6：修改文件得到差异，不修改时没有输出（00:07:47）。

第二次执行不再写入文件，diff 没有输出：

```
diff <(stat -c '%n %y' **) <(sleep 2; stat -c '%n %y' **)
```

监控需求合理，也确实可以实现。
