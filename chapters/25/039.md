merge commit 在对象内容中记录的两个 parent：

```
parent 755ebd91c1a5bd7a1eee906013f65fc6036ddeb3
parent 531edd8e67359bedc84adfa2e5c6f9c6a83d2cac

Merge branch 'newnew' into new
```

甚至我在这里可以有一个 git，有个 git reflog，就是除了，就你的 git，比如说你 git reset \-\-hard，那你那些没有 add 的那些东西就丢了，但是其他所有的东西，因为它是 persistent data structure，所有的对象都留在文件系统里，只要你不做 git gc，你哪怕有一个 commit 被，就是你 commit 是一个没有任何引用的 committer 这种，你把它整个都弄坏了，因为它是 persistent data structure。

你的 tree object，你的 blob object，实际上都在文件系统里，只要你不 gc，你都可以捞回来，然后你可以在这个 git reflog 里面找到所有的历史，所以既然这是一个 persistent data structure。
