merge commit 在对象内容中记录的两个 parent：

```
parent 755ebd91c1a5bd7a1eee906013f65fc6036ddeb3
parent 531edd8e67359bedc84adfa2e5c6f9c6a83d2cac

Merge branch 'newnew' into new
```

git reflog 会记录历史。git reset \-\-hard 后，未 add 的内容会丢，但其他对象因为已经持久化，还在文件系统。只要不 git gc，即便 commit 已无引用，或者引用关系弄坏，对象仍可能恢复。

![图 47：reflog 记录 HEAD 的移动（00:55:36）。](/assets/images/25/0047.webp)

图 47：reflog 记录 HEAD 的移动（00:55:36）。

tree object、blob object 仍在，都可能恢复。git reflog 能帮助找回历史，这正是 persistent data structure 带来的能力。
