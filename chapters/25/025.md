对象采用压缩存储。知道这个机制，就能让 AI 随时构建工具，再修改为从命令行接收路径、打印内容。可以试试 \.git/objectss 下 75 目录中的对象。

用 wildcard 匹配当前 git 的所有 objects，再把内容打印出来。

![图 27：xargs 找不到 git\-cat，随后改用 \./git\-cat（00:36:54）。](/assets/images/25/0027.webp)

图 27：xargs 找不到 git\-cat，随后改用 \./git\-cat（00:36:54）。

现场先让 xargs 查找 git\-cat，失败后补上当前目录路径：

```
$ echo .git/objects/*/* | xargs git-cat
xargs: git-cat: No such file or directory
$ echo .git/objects/*/* | xargs ./git-cat
```
