不想创建 E，也有其他方式，需要 git cherry\-pick。它能取任意提交的改动。比如10 年前复制一份 Linux 内核，自己持续改，上游 10 年也变化很大，整体合并、解决全部冲突已经做不到。

但上游为老代码加了安全补丁，恰好与本地没冲突，只想取这个补丁，就能 git cherry\-pick。可以把任意 A 到 B 提交看作 Diff，在 A 上 apply AB Diff 就到 B。A 是 Tree，记录 A、B 之间差异。

就能把 AB Diff cherry\-pick 到另一处。
