ggfs\.c 的操作表片段；右侧各回调函数在文件其他位置定义：

```
static struct fuse_operations ggfs_ops = {
    .getattr  = ggfs_getattr,
    .readdir  = ggfs_readdir,
    .open     = ggfs_open,
    .read     = ggfs_read,
    .write    = ggfs_write,
    .truncate = ggfs_truncate,
    .statfs   = ggfs_statfs,
    .create   = ggfs_create,
    .mkdir    = ggfs_mkdir,
    .unlink   = ggfs_unlink,
    .rename   = ggfs_rename,
};
```

比如说 readdir，我只要实现这个 readdir，我想要给它什么文件就给它什么文件，然后他问我要文件的时候，我想要给它什么数据就什么数据，完全是由我的文件系统的实现来提供的，就是代码，代码是 turing complete 的，所以理论上说你可以做任何事，它的效果是什么呢？
