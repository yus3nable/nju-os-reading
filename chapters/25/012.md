我追踪的是文件系统里面的和修改相关的函数，然后在那个函数来的时候，我可能往一个队列里面放一个信息，恭喜你就发明了一个非常现在非常火热的机制，叫做 eBPF，叫 Extended Berkeley Packet Filter，你听它的名字就知道它是干什么用的呢？它是在网络子系统上用的，因为网络是这个世界上速度最快的设备之一，而且很有意思的是，所有的 IO。比如说 Linux，我们现在讲 IO 的时候。比如说块设备是 block read，block write。

然后你的应用程序，你可以用 read write 的系统，然后用 mmap 去访问 IO，但是这些操作对网卡通通不适用，你们不用 read write，不用 mmap 去访问你们的网卡，因为网卡来包的速度实在是太快了，如果你们到数据中心的网卡上面，你会看到那个，如果你看一下那个 packet count 的话，你甚至会觉得那个 64 位整数都可能快要溢出的那种感觉。对吧，一个几百 GB per second，而且那个带宽一般能用满的数据中心的一个服务器。然后不停地在向操作系统内核。

发送中断，你需要所有的 CPU，可能几十个 CPU 一起响应这个中断，你才能响应得过来，然后最终所有的 IO 设备也都活成了网卡的样子，所以 Linux 现在有个叫 io\_uring 的机制，然后它就是网卡的一个 ring buffer 的设计。
