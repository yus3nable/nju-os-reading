目录现在有文件，但都由代码虚构，磁盘没有对应文件数据。cat、打开等行为，也由程序返回结果，理论上甚至能返回随机数。向选项文件写任意数据，文件系统内部状态就会变化，驱动 galgame。

![图 67：挂载 ggfs 后读取选项并准备写入（01:20:02）。](/assets/images/25/0067.webp)

图 67：挂载 ggfs 后读取选项并准备写入（01:20:02）。

挂载结果与选项文件的读写；写入选项后进入下一场景：

```
$ mount | grep ggfs
ggfs on /tmp/ggfs type fuse.ggfs (rw,nosuid,nodev,relatime,user_id=0,group_id=0)
$ cat 1.飲料コーナーへ
1.飲料コーナーへ
$ echo > 2.お菓子コーナーへ
```

![图 68：写入选项文件后游戏场景发生变化（01:20:03）。](/assets/images/25/0068.webp)

图 68：写入选项文件后游戏场景发生变化（01:20:03）。

写入后目录内容变了，因为 write 回调进入 Fuse 实现，可以计算、更新游戏状态。Fuse 还能做很多事，比如把远程 SSH 目录映射成本地目录。
