用 Fuse 把本地目录操作代理给远端即可，远程 Git 仓库也能成为本地目录。还有 dbfs，把文件系统存进数据库。Fat 崩溃时可能不一致，数据库若通过 append\-only 等机制保证一致性，就能在其上实现文件系统。

比如 filesystem\.db，用 SQLite 引擎保存文件系统，把操作转换成 SQL 查询。也能反过来，ffs 项目把其他数据变成文件系统，类似刚才 Galgame 的做法。
