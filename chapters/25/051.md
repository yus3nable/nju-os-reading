课件中的 Dockerfile 片段；中间步骤与安装的软件包未展开：

```
FROM ubuntu:22.04
ENV DEBIAN_FRONTEND=noninteractive
# 中间步骤未展开
RUN apt-get update
RUN apt-get install -y ... && apt-get upgrade -y
```

比如说它从一个已有的镜像开始，那我可以假设它有一个已有的，已有的比如说 Ubuntu 22\.04，好，23\.04，OK，在 docker 里面这叫一个 layer，接下来我会配置一些比如说我要设置一个环境变量等等，以及这里有一个叫 run。然后叫 run 的时候，每当我运行一个 run 的时候，我都会在这个相当于启动一个虚拟机。然后当然这是容器，容器我不知道我这个学期有没有时间来讲了。然后它会创建一个 upper，它会挂载一个 upper。然后挂载一个 upper。

然后底下是上面那层的 Ubuntu 22\.04，然后它现在把这个东西，就这一整个两层的文件系统放到虚拟机里，然后让虚拟机执行那个apt\-get update，然后这个 apt\-get update 不就写到这个 upper 里了吗？对吧，写到这个 upper 里。然后写到 upper 里面，等到虚拟机运行结束了，它就不是 upper 了，它就是第一层，它相当于是 run apt update 的以后的这个结果。然后它接下来再运行下一个比如说我要装软件。apt\-get install \-y。

它会在这再放一个 upper，就刚才装执行那个上一条命令的那个 apt\-get update，它就会变成一个 lower 的层，然后这层就不会变了，然后在这里面它就变成 upper，它再变成 apt install。然后 install 完了以后，后面你要再执行下一个命令，它又变成了。对吧，它又变成了一个 layer，它就一层一层一层堆上去了。
