课件中的 Dockerfile 片段；中间步骤与安装的软件包未展开：

```
FROM ubuntu:22.04
ENV DEBIAN_FRONTEND=noninteractive
# 中间步骤未展开
RUN apt-get update
RUN apt-get install -y ... && apt-get upgrade -y
```

从现有镜像开始，比如 Ubuntu 22\.04、23\.04，在 docker 中叫 layer。设置环境变量后，每次 run 相当于启动虚拟机——当然这里是容器，这学期不确定是否有时间展开。它会挂一个新的 upper。

下层是 Ubuntu 22\.04，把两层文件系统交给这个运行环境，执行 apt\-get update，所有写入落在 upper。运行结束，这层成为执行后的结果。接着用 apt\-get install \-y 安装软件。

再加新 upper。上一次 apt\-get update 的结果成为不变 lower，新安装写入当前 upper。完成后，它又固定成 layer，供下条命令叠加。
