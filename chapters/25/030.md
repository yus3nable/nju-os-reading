找到 stash object，会看到它是一个 Commit，带 Tree 和两个 Parent。仍然是数据结构，只是平时写 B\-tree、Binary Search Tree 用 struct Node 的 \*left、\*right 指针。

![图 35：stash 对象中可见两个 parent（00:43:08）。](/assets/images/25/0035.webp)

图 35：stash 对象中可见两个 parent（00:43:08）。

画面中 stash commit 的 tree、两个 parent 和消息；author 等字段未展开：

```
tree 2d06016c5e09cf6f2aca5a8ec520760bd6ae316b
parent 531edd8e67359bedc84adfa2e5c6f9c6a83d2cac
parent 32bcade012d0e8f1c3e0b6b8b48fbdbf7c4b9699

WIP on newnew: 531edd8 check in git-cat
```

这里用 hash 表示指针。不同类型节点带各自 Data。stash commit 的两个 Parent，一个 Head，一个 next stash，组成 Stash Stack，所以能 Push、pop，把 Commit 串起来。自己的 Commit History，也能直接交给 AI 阅读。

让它解释实际对象和关系即可。
