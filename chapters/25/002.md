前面讲过，append\-only 加 random read 能实现任意数据结构，保留所有历史版本，回退到过去的快照。算法中也有整体操作的例子：集合包含三、五、十，用 set of int 表示，想给全部元素加十，可以遍历成十三、十五、二十；也可以在结构旁记录偏移十，取出五时再加十，返回十五。要 insert 九，偏移保持正十，实际插入负一即可。

![图 2：集合整体加十：在结构外维护偏移（00:03:07）。](/assets/images/25/0002.webp)

图 2：集合整体加十：在结构外维护偏移（00:03:07）。

取出负一再加十，就得到九。数据结构有许多这样的 trick，比如数组区间加一个值，仍能保持很好的时间复杂性。文件系统也能做类似操作。今天讲四件事，主要有三件：监控、快照和覆盖。监控有点像给数据结构维护 flag，快照记录整个文件系统状态。

覆盖也叫 overlay 或 union，Docker 用到了它。最后讲终极的虚拟化：既然文件系统是数据结构，就能自己实现数据结构，让它充当文件系统。
