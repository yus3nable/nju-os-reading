然后我们怎么做一个 rebase 呢？怎么做一个 rebase 呢？rebase 是这样的，我的 rebase，如果我要在这儿，空间不够了，我画的不是特别的准确，我这样画，AB，这个叫 Delta1，这个叫 Delta2，那 rebase 做的事情是，先把 C 和 D 复制过来，先把 C 和 D 复制过来。然后他在这个状态上，试图去 cherry\-pick 从 Main 到 A 的这个 DeltaDiff。然后他会得到一个 A′，就好像是这个地方是一个补丁。

对吧，你修了一个 feature，如果他们都不冲突的话，比如说 C 和 D 改了改的文件和 Main 和 A 之间改的文件就不是同一个，OK，那这个 Delta 就可以直接 Patch 过来，对吧，他就 replay Delta1 就得到 A′。
