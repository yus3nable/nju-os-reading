从 Google File System、Bigtable 到 MapReduce，Google 建立了自己的帝国，做的就是这件事。Everything is a file 在 Unix 时代成功了，分布式计算时代依然可以沿用。先做好文件系统抽象，也就是 Google File System。下一节课开始讲 Persistence，文件就是 Byte Array。

如果能在分布式存储，也就是很多台计算机上，构建可靠的文件系统，就能存储一个 PB 的文件。PC 机放不下一个 PB，当时单台服务器也放不下，但可以把文件分片，存到不同机器：这一部分存两台，那一部分存三台。文件系统把这些机器隐藏起来。

编程时只看到文件，可以操作它，再把结果写入下一个文件。Program 仍然存在，也可以包含复杂算法。但思路变成以文件系统中的文件为中心，把程序与文件的一部分联系起来，再把处理结果写进新文件；不再先启动 Program、再把数据塞进去。

仍然是启动程序、处理数据，只是把数据带到计算和把计算带到数据有所不同。在文件基础上，还能构建 key\-value Database，解决增删改查。比如用它完成刚才 DeepSeek 例子中的 API Key 鉴权和删除。因此，文件之上有了 Database。

有了 Database，C10M 问题就在一定程度上解决了，程序只需要查询 Database。数据库背后分布在很多数据中心，读取很快，写入也相对高效。对于超大文件上的计算，他们又开发了大数据处理系统 MapReduce。三个著名的 Paper 开启了分布式计算的新时代，解决了其中的编程问题。
