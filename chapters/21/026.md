深度学习继续发展，到 transformer 时，又出现了 self\-attention 这个跨时代的发明。今天我花了点时间，想怎样用比方给大家讲清大语言模型。

![图 44：Attention：Q、K、V 与短时记忆（01:06:46）。](/assets/images/21/0044.webp)

图 44：Attention：Q、K、V 与短时记忆（01:06:46）。

我觉得可以把每一层 transformer 看成一本书。大语言模型做 next\-token prediction，比如补全“买什么什么什么什么”，或者“answer my question，什么什么什么”，要 predict 下一个 token。这个叫 q，也就是 query，是动态的，每次至少 q 不一样。另有 k、v：q 是要补全的句子，k 是书的目录，v 是书的具体内容。先把 q 和 k 放在一起，从 v 中找出一些内容。

![图 45：Q、K、V 三组数值（01:07:54）。](/assets/images/21/0045.webp)

图 45：Q、K、V 三组数值（01:07:54）。

相当于用较高权重取出 v 的一部分。书中有些内容对当前句子的补全任务不重要，就把这些内容删掉，取出有用部分。然后做 softmax，再乘以 v，形成一个大向量，作为瞬时记忆、短时记忆。每过一层 transformer，就像人思考了一层，消化这本书的内容，得到短时记忆，再生成一个相似结构，传给下一层。也就是根据问题查书，在大脑中产生想法，再经过几层 dense 神经网络。

经过相对复杂的计算后，再重写这本书、重写问题，继续经过下一层。越往上，信息密度就越接近最后要输出的 next token。刚开始还能看到每个 token，越到后面，越不知道看到的是什么。书里各部分内容也都是学出来的，这是这个架构的特点。

课件中的 CUDA 启动片段；\.\.\. 表示省略参数，依赖 CEIL\_DIV、kernel 和 CUDA 错误检查函数。

```
void matmul_forward(float* out, ..., int B, int T, int C, int OC) {
    int sqrt_block_size = 16;
    dim3 gridDim(
        CEIL_DIV(B * T, 8 * sqrt_block_size),
        CEIL_DIV(OC, 8 * sqrt_block_size)
    );
    dim3 blockDim(sqrt_block_size, sqrt_block_size);
    matmul_forward_kernel4<<<gridDim, blockDim>>>(
        out, inp, weight, bias, C, OC
    );
    cudaCheck(cudaGetLastError());
}
```
