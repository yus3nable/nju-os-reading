CPU 内部会有一个编译器。从 1990 几年到 2000 几年，这项技术对维持摩尔定律的增长很重要。到大概 2006 年，它开始失效：继续提升单处理器性能，收益越来越小，必须在硅片上放更多处理器，才能恢复能效比、维持摩尔定律。想进一步提高计算密度和能效比，就希望处理器中编译器、译码部件所占电路消耗的能量尽量降到零。

为此有两种技术。SIMD 可以用一条指令操纵 512 个 bit 的大块数据，把数据分成多个小块，同时执行一个操作。另一种编程模型是 CUDA 的 SIMT：有多份 ALU 执行单元、多份寄存器，共享一个 program counter。每份寄存器独立，即便 CUDA 中的一个线程束（thread warp）执行完全相同的指令，各个线程的寄存器仍可以不同。遇到 if/else，比如 if A else B，它会顺序执行条件下的 a、b。执行 a 时，只激活满足条件的线程，其他线程相当于什么也不做。那么 CUDA 怎样实现高性能并行计算？它依靠每个线程寄存器中的不同值，用同一条指令完成各自的计算。

比如线程束里还有 index 这样的寄存器，举例叫 index\.x，也有 xy、x 和 y。各个线程的 x 和 y 可以不同，相当于线程 id 保存在寄存器里。线程根据这个 id，算出屏幕坐标或数组下标。比如各个线程分别算出 0、1、2。下一条指令如果是 store，从整个线程束看，就是在读或写一段很长、最好连续的内存。

内存控制器可以发出一个 burst 的 read 或 write，快速完成操作。这就是 SIMT 模型的巧妙之处。
