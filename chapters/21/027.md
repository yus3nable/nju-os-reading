我们普遍觉得，这个架构可能还不是最好的，潜力也没有到头。gpt\.c 是从 llm\.c 中采出来的，回去看 llm\.c，会发现里面有 cuda code，与 mandelbrot() 比较类似。刚才的 attention forward、matrix multiplication forward 也很像 Mandelbrot，可以用各种方式并行化。

比如用 spawn、SIMD。137 行这样的运算位于 attention forward 最内层循环，执行次数最多，是一个 inner product，完全可以用 SIMD 的 FMA 指令实现。

![图 48：query 与 key 的内积循环（01:10:45）。](/assets/images/21/0048.webp)

图 48：query 与 key 的内积循环（01:10:45）。

gpt\.c 第 136—140 行的内积片段，query\_t、key\_t2、hs 和 scale 来自外层代码：

```
float val = 0.0f;
for (int i = 0; i < hs; i++) {
    val += query_t[i] * key_t2[i];
}
val *= scale;
```

这里是两个大向量，把对应元素乘起来再相加，可以用 fma 指令完成向量 inner product。SIMD 可以，SIMT 当然也可以。CUDA 版本的 gpt\.c 在 matrix multiplication 中，就调用了这样的代码。

这是 CPU 版本，那是 GPU 版本。写了带尖括号的代码，就会到 GPU 上运行，把矩阵乘法所需的 out、inp、weight 等参数发给 GPU，GPU 随即开始执行。不过，GPU 会把 kernel 调用排队，等第一个执行完，再执行第二个、第三个、第四个 kernel。
