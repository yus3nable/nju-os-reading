attention\_forward 中的三层循环；循环体见原课源码。

```
for (int b = 0; b < B; b++) {
    for (int t = 0; t < T; t++) {
        for (int h = 0; h < NH; h++) {
            // 原函数循环体
        }
    }
}
```

前面用 cuda 加速 Mandelbrot set，或用多线程加速它，代码也是 for x 从 0 到 w、y 从 0 到 h，for each pixel on the screen，渲染一个点。这里类似，对每个指定的对象计算 inner product，代码结构看起来都不长。

其中包含了人类长期实验得到的认识。直到著名的 scaling law paper，才证明 transformer 架构比 LSTM 更适合长上下文模型训练。里面还有一些概念：一个数字叫 scalar，标量；一个数组叫 vector；二维数组叫 matrix；更高维的数组叫 tensor。

tensor 听起来很 fancy，tensorflow、PyTorch 里都有很多 tensor。为什么需要它？深度学习刚兴起时，第一个爆火的应用是 AlexNet，在 ImageNet 上获得很好的分数，揭开了深度学习的序幕。当时大家觉得手工特征已经到头，做不下去了。

Geoffrey Hinton 他们的团队用 AlexNet 刷新了比赛历史记录。图像是数组，可以看成矩阵、二维数组。上节课说过，有人试着把矩阵当成图像，用 Vertex Shader、Pixel Shader 做图像加法、向量外积，进而实现矩阵运算。但深度神经网络处理图像时，通常需要很多张矩阵，不能只考虑一张矩阵输入、另一张输出。每个矩阵还有 RGB 三个 channel，说到彩色图像、黑白图像，HTML 中写颜色要用三个十六进制数，也就是红、绿、蓝三个整数。神经网络做池化后，这些矩阵还会越来越多，组成高维数据。

它包含很多大小相同的矩阵，也可能有很多份数据。比如一个 batch 有多个训练数据，这整个结构就会再复制多份。
