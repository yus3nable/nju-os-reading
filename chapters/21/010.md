到这里已经很复杂，麻烦的事情才刚开始。向 DeepSeek 请求，看起来只是给它一个 JSON，让它算出结果，比如 complete 一个 token 返回。以前在社交网络时代，或者更早的 web1\.0 时代，HTTP 后端基本上查询数据库。比如刷淘宝、tok 或微信，请求到达后端，可能是向微信要聊天记录，也可能是取图片。图片通常已经通过 CDN 分发，根据 URL 中很长的 hash 就可以取走文件。无论淘宝、抖音还是微信，基本上都是数据库查询。大语言模型背后的工作更多。首先，它也和微信、淘宝一样要做 authorization，判断 API key 是否合法。

API key 合法后，还要提供服务、计费和审计。大家可能见过，向 DeepSeek 问敏感或不合适的问题，成功让它“破甲”后，它开始输出不能输出的内容，显示一部分后又突然消失。这些也是后端要处理的事。学过的操作系统 API、并发编程知识，支撑了这些行为。

把做过的实验联系起来，就能得到比较完整的 computer science big picture。刚发布的实验是 httpd，要求实现支持 CGI 的 http 后端。在 BBS 时代，这样一个实验作业可能就足以支撑网站，做得好，startup 还可能靠它挣不少钱。今天看来，AI 一秒钟就能帮忙解决这个问题。
