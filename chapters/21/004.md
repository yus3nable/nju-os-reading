课件中的请求；DEEPSEEK\_API\_KEY 来自环境变量。

```
curl https://api.deepseek.com/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${DEEPSEEK_API_KEY}" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [
      {"role": "user", "content": "Hooo."}
    ],
    "stream": true
  }'
```

换用 DeepSeek，然后你给它是一个这样的数据，然后这个数据最后你如果执行它的话，你可以收到一个 HTTP 的 Response，然后可以看到这个 Chat 完成的结果，其实这样的使用的模式，在计算机使用的过程中，可以说是无处不在，比如说你们的 make submit。
