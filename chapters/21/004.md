课件中的请求；DEEPSEEK\_API\_KEY 来自环境变量。

```
curl https://api.deepseek.com/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${DEEPSEEK_API_KEY}" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [
      {"role": "user", "content": "Hooo."}
    ],
    "stream": true
  }'
```

envp 会在进程加载时放到栈上的某个位置，并在子进程之间继承。这个特性让 shell 中设置的环境变量不断向下传递，执行 curl 等子进程时，也能收到 DeepSeek 的 API key。随后把请求发给 api\.deepseek\.com。它还有一个 anthropic 兼容的 API，可以在 Claude Code 里换用 DeepSeek。

把这样的数据发过去，执行后就会收到 HTTP 的 Response，看到 Chat 完成的结果。这种使用模式在计算机中随处可见，比如大家的 make submit。
