先知道想做什么，再提问题。比如 main 分支能否往前退一个 commit？即使用过 Git，也未必记得精确命令。告诉模型目标，它先 git log 查看提交历史，确认要回退的 commit。

![图 8：请求将 main 回退一个 commit（00:03:53）。](/assets/images/07/0008.webp)

图 8：请求将 main 回退一个 commit（00:03:53）。

它给出 git reset \-\-hard，会覆盖当前内容，但这里是刚克隆的 repo，没有自己的代码，所以我选 yes。执行后，它确认 main 回退一个 commit，还说明本地恢复办法：git reflog 找到原提交，再 git cherry\-pick 或 git reset。

![图 9：回退完成及恢复提交的方法（00:04:28）。](/assets/images/07/0009.webp)

图 9：回退完成及恢复提交的方法（00:04:28）。
