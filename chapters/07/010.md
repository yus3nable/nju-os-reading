学过 Filesystem Hierarchy Standard，知道目录结构，也知道 open、read、write，接着看看系统里到底有哪些对象。这个命令列出 proc 下所有进程 fd 目录的条目。

![图 60：查看进程打开的文件（01:07:35）。](/assets/images/07/0060.webp)

图 60：查看进程打开的文件（01:07:35）。

```
ls -l /proc/*/fd/* 2>/dev/null \
  | awk '{print $(NF-2), $(NF-1), $NF}' \
  | claude explain it
```

每个进程打开的对象都在其中。everything is a file，从描述符就能看到对应文件，比如 tty7、pipe。

![图 61：各进程 fd 目录中的符号链接（01:08:21）。](/assets/images/07/0061.webp)

图 61：各进程 fd 目录中的符号链接（01:08:21）。

![图 62：用 awk 整理文件描述符列表（01:08:56）。](/assets/images/07/0062.webp)

图 62：用 awk 整理文件描述符列表（01:08:56）。

此刻系统打开了 /dev/pts 等伪终端、终端模拟器。比如当前终端是 /dev/pts/5，写入时会先 open 它。

![图 64：tty 显示当前终端为 /dev/pts/5（01:10:23）。](/assets/images/07/0064.webp)

图 64：tty 显示当前终端为 /dev/pts/5（01:10:23）。

再用 write 写 hello，这个 pts 就出现 hello。只要有权限，也能打开别人的终端，写入后，对方终端会显示相应数据。

![图 65：另一终端写入的 Hello 出现在当前终端（01:10:39）。](/assets/images/07/0065.webp)

图 65：另一终端写入的 Hello 出现在当前终端（01:10:39）。

还有真正控制台 /dev/tty7、空设备、GPU 渲染设备、/dev/input 型输入设备、随机数、套接字、管道等。理解 everything is a file，以及 open、read、write 这套接口，就能继续探索这些对象。
