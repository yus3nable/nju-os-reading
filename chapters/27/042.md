数据库提供 transaction 机制。transaction begin 后可以写任何代码，执行任意 turing complete 计算，也可以 sleep，事务可以任意长，乃至无限长。随时可以检查条件，比如 user 的 balance 不够，就 transaction abort。减 m、加 m 之后也能再计算别的条件，比如发现有内鬼，再 transaction abort。前面的操作看起来已经执行，abort 后仍会全部撤销。只有 transaction commit 时，过去的操作才会一起立即生效，满足 all or nothing：全部生效，或完全不生效。它还能保证 transaction 的高性能。
