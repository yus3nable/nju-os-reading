无论 QQ 还是手机整套系统，Settings 都是 Persistent 的。按下小拨片，Settings 是 0 还是 1 就持久保存了。你可能想到用文件系统实现：每个 Preference 一个文件，写入 0 或 1，再做 Fsync 或 FdataSync。实际上，这些通常由一个很小的 SQLite 数据库管理，性能很好。数据库本身是一个文件，整个 library 也是一个文件，可以嵌入各种应用。它是一个 C library that implements a small fast，self\-contained high reliability，full\-featured SQL database engine，也是 the most used database engine in the world。

每个 android app、苹果 app 都带着这样的 SQLite 引擎。系统里涉及 persistence 时，首先就会求助于 SQLite Database。它是 zero configuration，只需 libsqlite3\.so，就能享受数据库的好处。比如要做 preference 界面，获取动态构建的设置列表，直接用 SQL 从 Database 查出即可；修改设置也只需一个 SQL 查询。它保证数据稳妥地存到磁盘，无须自己考虑写配置文件后要不要 sync。这个小数据库无处不在。关系型数据库已经形成了一个很厉害的产业。
