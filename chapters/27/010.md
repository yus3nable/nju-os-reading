它都是数据结构，然后所谓的应用程序想要改变这些数据，都是数据结构的增删改查，然后所以你的本质，就实现一切应用数据，Persistence 的本质，就是实现数据结构的 Persistence，然后如果你要实现数据结构的 Persistence，也有两个典型的方法，第一个方法就是使用文件和目录，因为 Unix 已经给你一个 Everything is a file 的接口了。对吧，如果我打比方，如果我要实现一个教务系统的话，我就会这样。

比如说为每一个同学，为每一个同学我都可以建一个目录，这个目录的意思是，我希望在我的教务的 APP 底下，有我的课程号，这是我操作系统的课程号，比如说这是某一次开课的信息，然后我如果有一个同学选课的话，我就建一个目录叫 enrollment。然后比如说这个同学选了，就是 001 号 002 号 003 号，每个放一个 markdown。然后刚才你们看到我在那个教务系统里面，也可以比如说编辑我的教学周历，编辑我的什么考核信息。然后这些东西都可以存在，我的一个目录里面。比如说一个 metadata\.json，然后或者一个 syllabus 里面的 markdown，然后我的教科书是什么，可以这样，如果你要用这种方式来存储文件，有一点什么好呢？你所有的东西都是平的，你的 UNIX 世界里面，所有的工具都可以用，不仅仅 UNIX 世界里面，所有的像 find 和 grep，这些工具可以用，你的 agent 也可以用，UNIX 世界里面的，所有的工具来编辑它。对吧，变成目录的结构，其实是一个非常的，agent friendly 的方式。
