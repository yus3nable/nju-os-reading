这些数据都是数据结构。应用程序改变数据，就是对数据结构做增删改查。实现应用数据的 Persistence，就是实现数据结构的 Persistence，典型方法有两种。第一种是用文件和目录，Unix 已经提供了 Everything is a file 的接口。如果要实现教务系统，我可以这样做。

![图 16：Everything is a File：教务数据的目录结构（00:09:56）。](/assets/images/27/0016.webp)

图 16：Everything is a File：教务数据的目录结构（00:09:56）。

我可以为每个同学建一个目录。在教务 APP 底下，先有课程号，这是操作系统的课程号，再有某一次开课的信息。有同学选课，就建一个叫 enrollment 的目录，比如 001 号、002 号、003 号，每人放一个 markdown。刚才在教务系统里看到的教学周历、考核信息等，也都可以放在这个目录里，比如放进 metadata\.json，或者 syllabus 里的 markdown，记录教科书是什么。这样保存文件的好处是所有东西都是平的，可以使用 UNIX 世界里的工具，比如 find 和 grep；agent 也能用这些工具编辑。把数据组织成目录结构，对 agent 很友好。
