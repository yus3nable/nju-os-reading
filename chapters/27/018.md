我觉得用目录和文件很好，是 agent 时代的一个标准答案。如果这种方式性能不够，不想付出额外开销，也可以直接在文件上构建数据结构。文件是一个 byte array，磁盘也是 byte array。

![图 21：直接在文件上构建和映射数据结构（00:19:52）。](/assets/images/27/0021.webp)

图 21：直接在文件上构建和映射数据结构（00:19:52）。

我们通过虚拟化，在磁盘上放一个数据结构：可能是 fat 文件分配表，也可能是 unixfs 基于 inode 的树和图。这样就能得到 a\.txt 等可以随机读写的 byte array。既然可以用数据结构把一个 byte array 抽象成许多独立对象，也可以在一个 byte array 上再做抽象，变成其他数据结构。ELF 文件就是例子：有 header、program headers、一个个 PT\_LOAD 的 section、符号表等，各部分通过指针相互引用。
