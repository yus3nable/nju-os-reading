像 ext4 那样，也可以用 checksum 确保这部分合法。我没有加 checksum，因为手工编不出那个 checksum。现在重新进入教务系统，log 里有这一条命令，启动时就会做 write\-ahead replay，使用相同代码执行。execute 是所有命令的入口。［jw\.c 清除日志的函数；依赖全局 SB 和 db\_sync。］

```
static void wal_clear(void) {
    memcpy(SB->wal, "WAL:", 4);
    memset(SB->wal + 4, 0, sizeof(SB->wal) - 4);
    db_sync();
}
```

添加或删除学生，都从这个入口进入。write ahead log replay 后，就添加了 99 号同学。再看 write ahead log，已经清空，replay 完就可以清空了。这是一个 slot 的 log；理论上能做一个 slot 的 write ahead log，也能做任意复杂的 write ahead log。
