```
student_t *s = alloc_student();

s->id = id;
strncpy(s->name, name, MAX_NAME - 1);
s->next = SB->head;
```

也可以每次打开数据库后存下 base 地址，下次打开时从指针值中减去这个 base，再加上新的 base，理论上就能映射到不同位置。［db\_open 中固定地址映射的片段；BASE、DB\_SIZE、g\_fd 来自 jw\.c。］

```
void *p = mmap(BASE, DB_SIZE, PROT_READ | PROT_WRITE,
               MAP_SHARED | MAP_FIXED, g_fd, 0);
```
