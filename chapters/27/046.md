具体来说，是 SQL 语句执行的并发控制。刚才的 select 等程序叫 Structured Query Language，结构化查询语言。并发控制很难，因为每个请求会读写数据库的不同部分。数据库可能有几百张表，有些请求读这些部分，再往其中写一个值；另一些请求读其他部分，再写另一个值。情况很复杂，为了 crash consistency，还要应对这样的情况：一个线程往某张表写 x 等于某个值后，可能因为 bug 自己 crash，永远不再回来，也不提交。一般会有人知道这个线程挂了。另一个线程可能先写 y，等很长时间，再写 x 等于二，最后 committed。

这两个写可能冲突，发生冲突时只能让一个提交，不能两个都提交。一般有两种方法，后一种是更现代的方法。
