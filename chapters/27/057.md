append 可以在分布式的多个线程中并行完成，得到多个链表，再串起来 append 回去，也能得到正确结果。这样的数据库就比较好实现。首先给 key 做 hash，实现 load balance：只要 hash function 足够好，每个 key 都能变成近似的 random number，再把它模机器数量，就能送到一台随机机器，自动实现 load balance，也就能在一定程度上 scale。因此，对 key 做 hash 就能把负载分到多台机器。此外，everything is append\-only 也便于高效实现。
