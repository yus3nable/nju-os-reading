我可能需要扫码登录。这是我看到的界面，可能和你们看到的稍有不同。这是一个典型的应用程序，以 HTTP server 的方式在后台运行，和你们做 lab 时一样。我访问的 URL 比较小，看不清，但可以把任何网站想象成你们的 CGI bin：底下有一个应用程序，会启动一个进程。如果是服务全世界的服务，它可能启动一个很轻量级的协程或其他东西，总之是一段代码。代码最后返回数据到本地：HTML CSS 可以渲染成界面；JSON 数据可能由网页上的 JavaScript 代码接收，再改变网页信息。比如，我可以在这里编辑教学班或周历。

这些操作都是数据库或数据结构的增删改查。系统里有一个叫操作系统课的 record，还有怎么考试等 metadata。我不能改考核方式，这比较危险：如果改错，最后排考试时系统可能没给我排，大家就考不了试，可以不考试了。实际上我没有修改权限，你们看鼠标变成了这样。但有些信息可以改，比如授课类型。系统里还有学生选课列表，我不打开，避免暴露个人隐私：我能看到你们的电话号码，你们应该也能看到我的电话号码。这是一个很大的数据结构，有点像文件系统，可以增删改查。有些东西可能不符合你们对数据结构的传统印象，也仍然是数据结构。
