只需构建表，可以创建任意多的表，编写查询。刚才是 select，update 也是查询；insert into 则向表里插入数据。这是一个小型 domain specific 编程语言，专门管理数据。［课件中的转账伪代码；tx\_\* 表示事务边界，balance 操作表示 SQL。］

```
tx_begin();
if (user1.balance < m) tx_abort();
user1.balance -= m;
user2.balance += m;
tx_commit();
```

这样的数据库系统支持 ACID：A 是 atomicity，原子性；C 是 consistency，一致性；I 是 isolation；D 是 Durability。在操作系统课的意义上，主要关注两点。第一是 serializability，可串行化：无论多少 transaction 或查询并发执行，无论读写，也无论查询多长，最终都能排成一个全局顺序 12345678，效果如同 1 完成后执行 2，2 完成后执行 3，3 完成后执行 4，没有 weak memory model 那样的行为，是一种 strong serializability。第二是 strong crash consistency：系统随时 crash，都不会造成数据丢失，还支持任意异常情况下的 multi\-write。这是数据库对我们很有用的特性。
