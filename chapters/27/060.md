可以提供更丰富的结构，比如 mongodb 的 document based database，或 Cassandra 的 column database。Cassandra 有 cql 查询语言，也是 table 模型，但没有 full SQL support。mongodb 的操作都是 document based，类似 json、key\.json，可以对 json 里的数据结构做操作，比如 append messages。这种结构化存储比单纯 list 更好用。也有数据库想提供几乎完整的 SQL 支持，代表之一是 TiDB，是国产 startup 出海的经典案例；还有 google 的 spanner、CockroachDB 等。它们也算不上今天的版本答案。这是一个巨大的 industry，也许有同学会加入。今天还有一种新兴 database，和它们都不同。前面这些都是程序和数据结构，目的类似于刚才的示例，希望由 infrastructure 接管这些复杂问题。
