一条 unzip 命令就能解开。虽然用 file 查看时识别为 PowerPoint，它同时也是合法的 Zip archive。解开后可以看到 PPT 下的 Media 下的 Image 等文件。

［原课在演示文稿目录中的命令。］

```
unzip lec1.pptx
cd ppt/media
ls
```
