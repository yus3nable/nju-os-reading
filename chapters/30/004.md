然后这个概念从你们最小的那个单片机，从一个玩具里面的一个可能唱歌的一个芯片，然后到我们手机，对吧，手机，电脑，再到数据中心里面的超计算机，人工智能的推理的机群，都有操作系统，而且几乎它们的操作系统的形态都是比较类似的，当然是我讲的狭义的这种操作系统，所以说好 AI 来了，那么我们需要一个 agent 的操作系统，对吧，那什么是 agent 操作系统呢，可能我们现在还不知道到底什么才能算一个 Agent 操作系统，但我们可以知道的是，我们应该不是从零开始从一个 bare metal 从一个裸机上面去构建一个新的操作系统，而是我们应该会借助像 Android 那样移动操作系统，我们说 Android iOS 是非常成功的移动操作系统，但它们也不是说就从零开始从一个 arm 的处理器上面构建。

而是他们会借助一个像 Linux 这样的已经很好的经典操作系统，然后在上面再为应用再做一层封装，有点像在早期的时候，尤其比如Unix 刚刚发明的时候，我们总是写 C 语言的代码，然后直接编译成 Binary。
