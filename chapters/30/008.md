期末复习该怎样安排？可以先用刚才的内容作 top level 提纲，再思考具体怎么复习。我更希望大家从这门课学到一种主动追问的习惯。

［课件中的完整管道；在课程仓库根目录查找讲义脚本，最后一步 pbcopy 为 macOS 命令。］

```
find OS2026/ -name 'lect*.py' | \
  sort -V | \
  xargs grep -h render_os_demo | \
  awk '{$1=$1}!s[$0]++' | \
  pbcopy
```

具体知识点仍然会考，也需要掌握。短期内为考试记住的内容，将来总会忘掉，但还会留下一些印象：原来操作系统能做这件事，课堂上也见过相应代码。例如，平时只做 vibe coding 应用，可能不会想到还能入侵另一个程序的地址空间；JavaScript 模型里就没有这样的操作。

在操作系统的进程模型里，这却是合理、应该能做的事。每想到一个问题，都可以继续追问。刚才的概括已经能算复习完了，但还可以再问：“有没有更好的复习方法？”去和 AI 讨论几轮，就可能得到不同的安排。
