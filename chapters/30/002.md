好，我今天来给大家总结一下，这个学期学了什么，对吧，耳朵都听到生茧的废话说，从应用程序的视角来看，操作系统就是一组管理硬件资源提供应用生态支撑的 API，对吧，一组 system calls。然后我们是怎么在学完了操作系统这门课以后，怎么理解这句话，对吧，我从第一节课的时候我就开始说这句话，你们是从一个具体的程序的模型来出发的，你们因为你们总是写程序，你在我的操作系统，看到的所有的东西，你们我看大家都带着笔记本电脑，不管是你们打开一个 Word、打开一个浏览器，对吧，还是你们在vscode 里面编程的时候，那个插件会帮你编译运行，在这个过程当中，是应用程序无时不刻的在帮助你，不管它是用什么语言写的，你都可以把它想象成是一个，比如说 C 语言写的程序，对吧，因为比如说你是 Python 或者 JavaScript 那你可以等价的把这些功能翻译成一个 C 语言的代码，然后这个代码它就在一个虚拟化的环境里，也就是进程里。
