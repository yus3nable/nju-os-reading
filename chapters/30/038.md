［现场打开的递归汉诺塔程序。］

```
#include <stdio.h>

int N = 4;
void do_move(char from, char to) {
  printf("%c -> %c\n", from, to);
}
void hanoi(int n, char from, char to, char via) {
  if (n == 1) {
    do_move(from, to);
  } else {
    hanoi(n - 1, from, via, to);
    hanoi(1, from, to, via);
    hanoi(n - 1, via, to, from);
  }
}
int main() {
  hanoi(N, 'A', 'C', 'B');
}
```

先把 N 减一个圆盘整体抬起，放到另一根柱上，再移动一个圆盘，最后把那 N 减一个再移过去。这与递归程序的效果相同，道理上是容易理解的。
