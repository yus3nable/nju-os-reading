［现场打开的递归汉诺塔程序。］

```
#include <stdio.h>

int N = 4;
void do_move(char from, char to) {
  printf("%c -> %c\n", from, to);
}
void hanoi(int n, char from, char to, char via) {
  if (n == 1) {
    do_move(from, to);
  } else {
    hanoi(n - 1, from, via, to);
    hanoi(1, from, to, via);
    hanoi(n - 1, via, to, from);
  }
}
int main() {
  hanoi(N, 'A', 'C', 'B');
}
```

我就真的可以把 N 减一个抬起来，放到另外一个上面，这就是我要做的，相当于是这一段递归的效果，然后我再挪一个挪完以后再把N 减一个再挪过去，然后所以从道理上你是认同它的。
