所以恭喜大家上到了绝版的真人操作系统课，我就会从明年开始，我就没有这个 physical 的，因为本来一直以来，我的操作系统课都是一个非法的状态，就是你们是共享的课程号，但是是不同的考试题，这件事情本身在这个学校的系统里面，是非法的操作。所以终于有一个合法化的机会，我把操作系统课还给课程组。然后但同时我会试着。对吧，因为你已经看到 Vibe OS 了，我会试着让这个课永生，而且能够 keep up to date，就是我希望的是，我做的第一步就是，我的所有的 content 现在都是 code 了。

然后也许不是 code 也可以，然后我就可以持续地更新它，然后把它变成 public and open source 的一个，也许是你们每一个人喜欢它是什么样子，你就可以让 AI 把它变成什么样子，然后在下个学期我会开一门新课，本来应该叫 vibe coding 的，但是大家觉得vibe coding 这个很快就过时了。所以还是给它一个更正式的名字。所以我就取了一个叫 Generative Software Engineering，讲我预计的话应该会用一个一线的国产的模型。

就全部都是国产的模型，然后带大家去实现各种，你觉得会一开始可能会觉得很疯狂，但是等你实现出来的时候，发现你确实不需要多少 prompt 的，比较有趣的东西。
