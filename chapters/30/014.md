UNIX 采取了不同的方式。作为 Computer Science 学生，大家刚学 Linux 命令行终端时，可能会觉得害怕。后来有了 Claude，或者即使只借助网页版聊天工具，也渐渐不怕了。回想起初的困难：它只给你一个终端，却告诉你，整个世界都在这里。

它是 open source 的操作系统，提供了许多工具。可以用 apt 安装软件，例如先装 npm，再用 npm 升级自身，接触完整的 JavaScript 生态。但新手必须先理解许多概念。为什么要付出这些学习成本？
