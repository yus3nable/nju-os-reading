［AI 原题代码；waitpid 的声明依赖原图未展示的头文件。］

```
#include <stdio.h>
#include <unistd.h>
#include <fcntl.h>

int main() {
  int fd = open("test.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
  write(fd, "Hello", 5);
  int pid = fork();
  if (pid == 0) {
    write(fd, "Child", 5);
    _exit(0);
  } else {
    waitpid(pid, NULL, 0);
    write(fd, "Parent", 5);
  }
  close(fd);
}
```

对吧，然后这个是有一个唯一的，唯一的答案，如果 fork 之前加一句 close，然后父子各 open 有什么不同，UNIX 为什么选择让fork 继承文件描述符，这和 everything is a file 的哲学有什么关系，肯定很有意思的题目。对吧，我觉得这个还是，就如果你仔细在上课的时候思考过这些问题，你会觉得 OK，这个很自然，你会想到。
