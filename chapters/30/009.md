课堂内容主要围绕代码展示展开，也会解释原理的来龙去脉：例如 1970 年的设计思路，到今天为何不够用，又怎样用新的 API 满足需求。课堂上也有相应的 code demo。理解这些代码、基本原理、系统调用和概念，考试就不用太担心。

以前有同学评价，这门课的考试比较有确定性：只要确实理解概念，就能作答。我不会专门考偏僻细节；即使忘了细节，也可以沿着 first principles 推导，给出合理理由，我也会给分。

前提是把课堂代码理解好。我了解到，有些同学可能还没下载、运行过 Coding Agent；坐在这里的同学未必有这种情况。
