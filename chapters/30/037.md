［模拟器里的 CPUState；整数类型与 CSR\_COUNT 依赖同一头文件。］

```
struct CPUState {
  uint32_t regs[32], csrs[CSR_COUNT];
  uint8_t *mem;
  uint32_t mem_offset, mem_size;
};
```

CPU 的 state 包括 32 个寄存器、一组 CSR 和 memory。这些构成基础计算机模型，指令能执行，程序也就能运行。课程开头的复习，重新走过了数字逻辑电路和计算机系统基础中最重要的内容。
