［AI 原题的条件变量代码；mutex\_t、cond\_t 及其 API 依赖题目约定。］

```
mutex_t lk = MUTEX_INIT();
cond_t cv = COND_INIT();
int food_ready = 0;

void Philosopher(int id) {
  mutex_lock(&lk);
  while (!food_ready) {
    cond_wait(&cv, &lk);
  }
  printf("Philosopher %d is eating!\n", id);
  mutex_unlock(&lk);
}

void Waiter() {
  mutex_lock(&lk);
  food_ready = 1;
  cond_broadcast(&cv);
  mutex_unlock(&lk);
}
```

偶尔有一两年，我会出用信号量能很简单地解决的并发题。可以用万能同步方法稳妥地拿 20 分，也可以相信自己的能力，写出更精巧的并发控制。
