UNIX 也给了我们很多 API，fork、execve、exit、read、write，都是非常熟悉的 API，OK，但 Windows 也同样提供了很多 API，GetProcess，对吧，它是一个更符合软件工程规范的 API。但是好像一直以来，尤其是在开发者的口碑当中，Windows 的口碑一直都不如 Linux，甚至可能我在我上学的时候，还有一些经常有那种调侃这个 Microsoft，调侃 Windows 的图，虽然现在少很多了。为什么？因为操作系统不仅仅是那一个 API。

操作系统还有承载了那一个 API 上面的应用生态，而 Unix 的应用生态和 Windows 的应用生态，它在设计哲学上就有一个本质的区别，Windows 的应用生态，你想想想当你谈 Windows 的时候，Windows 上面的代表应用程序是什么。对吧。
