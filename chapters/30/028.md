进程地址空间几乎是必考内容。AI 抓住了我的思路：需要知道地址空间是什么、怎样改变它，于是通过编程例子提出这些问题。

［AI 原题中的地址空间例子。］

```
#include <stdio.h>
#include <stdlib.h>

int global = 42;
int main() {
  static int local_static = 100;
  int local = 7;
  int *heap = malloc(sizeof(int));
  *heap = 999;
  printf("main:   %p\n", (void*)main);
  printf("global: %p\n", (void*)&global);
  printf("static: %p\n", (void*)&local_static);
  printf("heap:   %p\n", (void*)heap);
  printf("stack:  %p\n", (void*)&local);
}
```

正式考试会出得更严肃些，不会用“计算机世界没有魔法”这样的说法。不过，学习时应该有这种认识：每当困惑，就提醒自己，计算机系统中的行为一定有原因。刚才那个奇怪的 Fork 例子，也能找到原因。
