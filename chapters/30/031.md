［AI 原题的 list\_find；保留原题持锁返回的错误，node 与互斥 API 依赖前文。］

```
struct node *list_find(struct node *head, int val) {
  mutex_lock(&head->lock);
  for (struct node *cur = head; cur; cur = cur->next) {
    if (cur->val == val) return cur; // 注意：没解锁！
    if (cur->next) mutex_lock(&cur->next->lock);
    mutex_unlock(&cur->lock);
  }
  return NULL;
}
```
