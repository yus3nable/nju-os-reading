这是高性能计算里面的并行编程，当然了，高性能计算是一个很大的产业，是一个很大的领域，真正困难的地方，包括你怎么搭建机房的网络，高速的网络，然后怎么中和机柜之间，节点之间的这种网络的不对称，你现在像比如说我现在，现在我写这个程序的时候，我假设的是我每一个 shared memory access 都是差不多代价的，对吧，我这样我才能让每一个线程的运行的速度，差不多快，基本上差不多时候能够结束。但是实际上是做不到这一点的，对吧，你们的 CPU 之间它访问内存的速度是不一样的，然后在多个计算机的集群里。
