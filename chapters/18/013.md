今天准备了 Mandelbrot set 的例子。虽然不属于操作系统内容，我还是想介绍这个分形 walkthrough。先看递归公式 xn 等于 xn\-1 平方，画在数轴上，再改变 x0。如果初值是 1/2，后面就是 1/2、1/4、1/16。

接着到 1/256，越来越小，轨迹不断向左跳。靠近 \-1 也类似，第一次会跳到正数，接近 1 的位置。

![图 30：实数轴上的平方迭代（00:41:27）。](/assets/images/18/0030.webp)

图 30：实数轴上的平方迭代（00:41:27）。

随后向 0 跳；到其他区域就发散。x0 大于 1，序列发散；在 \-1 和 1 之间收敛；x 小于 \-1 也发散。接着可以定义 Julia set，仍使用 xn 等于 xn\-1 平方的序列。

![图 31：复平面上的初始点与迭代公式（00:41:59）。](/assets/images/18/0031.webp)

图 31：复平面上的初始点与迭代公式（00:41:59）。

0 平方仍是 0，1 平方就来回跳。这次放在复平面上，复数乘法一部分是标量，一部分是旋转，平方也包含两者。画出轨迹，走到某处又回来。什么时候收敛、什么时候发散？

![图 32：复平面平方迭代的轨迹与发散（00:42:32）。](/assets/images/18/0032.webp)

图 32：复平面平方迭代的轨迹与发散（00:42:32）。

x0 只要在半径为 1 的单位圆里，序列就收敛。再加一个常数 c，还会收敛吗？将收敛区域画出来。

![图 33：加入常数 c 后的收敛区域与轨迹（00:43:05）。](/assets/images/18/0033.webp)

图 33：加入常数 c 后的收敛区域与轨迹（00:43:05）。
