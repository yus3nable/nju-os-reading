愿意花一分钟提个好问题，剩下的可以交给 AI。它开始读 ELF，趁它思考再问：thread\_local 支持初值，例如 thread\_local int x 等于 42，这个值由谁赋？它和数据区不同。

全局变量 x 等于 42，初值位于 ELF 的 \.data 中，loader load 时把内容搬进内存，不管是［听辨不清，01:11:18］，还是逐字节拷贝，都只需搬一次。局部变量 y 等于 42，则由编译器在函数头部生成指令。

例如 move，将 42 写入 y。计算机系统基础中看过这种汇编。thread\_local int x 等于 42，或者 z 等于 42，初值应该在 ELF 里，至少要存于某处。

但内存中的每个线程副本都要等于 42，因此每次创建线程，都得执行初始化。这带来一些麻烦，可以直接问 AI。若它没回答，就继续追问：创建线程时，究竟谁写入这个 42？课堂 flow 被等待打断。
