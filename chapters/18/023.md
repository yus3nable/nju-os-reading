thread\_local 确实起作用了，怎样实现？编译器知道每个变量的定义和 modifier，例如 const、volatile。全局 int x 用 IP、PC 相对访问；栈帧中的 Y 用 RSP 相对访问。

![图 56：全局、栈与线程局部变量的访问方式（01:09:10）。](/assets/images/18/0056.webp)

图 56：全局、栈与线程局部变量的访问方式（01:09:10）。

课件对三类变量的访问写法：

```
int x;  // x(%rip)

void foo() {
  int y;  // y(%rsp)
}

thread_local int z;  // z(%fs)
```

thread\_local 应相对于线程局部存储取 offset。全局变量相对于全局数据区，栈变量相对于当前栈帧，各自有偏移。x86 寄存器不够，就借用了 FS。编译演示代码后用 objdump，可以看到访问被翻译为相对 FS 加常数偏移的 load、store。
