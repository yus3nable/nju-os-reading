sum\+\+ 已经很简单，还能更快吗？可以放松其他线程看到更新的及时性。互斥锁提供 release acquire semantics：锁内 loadsum，例如等于 100，再 store 为 101。

release 后其他线程只要 acquire，就一定能看到 101。但修改立即对所有人可见需要代价。电路上，每颗 cpu 独立，有自己的 l1cache；没有缓存，访问内存会很慢。

每条指令都访问内存，cpu 就无法运行在 3GHz、5GHz。指令和数据来自附近的 l1sram 缓存，后面可能有共享 lcache，再往后才是 ram。store sum = 101 后若要让其他 cpu 看见，至少需要在总线上传播一圈，不同 cpu 有不同实现。

可能是环形，也可能用目录缓存；总要把 sum = 101 传播给其他 cpu。对同一地址，还可能需要额外协议通知别人这个内存地址被改过。这些都是开销，想加快 sum\+\+，可以采用另一种办法。
