机械化进入电气化，typewriter、打字机又发展出 teletypewriter，电传打字机。typewrite 是按 A、打印 A，电传打字机则能在导线另一端打印，距离可以横跨大陆。

![图 8：课件：电传打字机与五位编码（00:10:50）。](/assets/images/08/0008.webp)

图 8：课件：电传打字机与五位编码（00:10:50）。

原来打一张 A4 纸，要请邮差送到欧洲；电传打字机只需维护导线、中继站，再给每个字符编号。这里是 1920 年的 5bit code。

5bit 没有打字机那么多 fancy 功能，但也能用特殊编码切换 shift、大小写模式，从而容纳常用字母 ABCD、数字和特殊符号。这里没有美元符号，可见机器并非美国人设计。

Teletypewriter 在一处输入、另一处输出，开始接近计算机时代。链接有 Teletype Model 28 的 technical data sheet，1951 年的产品，值得让 AI 帮忙读。手册标准、规格写得很清楚。

再看计算机。最早机器码运行后，会通过机械装置打出二进制孔，作为输出。

![图 16：课件：VT100 视频终端（00:13:59）。](/assets/images/08/0016.webp)

图 16：课件：VT100 视频终端（00:13:59）。

寄存器、内存中的 bit string、01，可以送到机械部件戳孔，但对人很不方便。计算机快起来后，人们希望输出能直接阅读，输入也不用像第一次课展示的 Fortran 卡片，每写一行就戳孔。后来很长时间都用 teletypewriter，把编码的二进制数据交给打印机，直接打印字符。

再后来有 video teletypewriter，也是 tty 名称的由来。它仍保留 typewriter 的功能，从硬件、操作系统看，提供的接口就是 putchar。

计算机生成字符，通过类似 memory map 的 IO 端口写入，设备收到后显示。\\r 回行首，\\t 到下个 tab stop，也能接受其他规定字符。那时建立了许多标准。

比如 ASCII，把数字、二进制或十进制数，与字符对应。大写 A 是 65，对吗？总之在比较大的位置，小写 A 应该是 97。前面的编码是什么？这与 video teletypewriter 的设计有关。

1978 年 VT100 成为里程碑、事实行业标准，支持完整 ANSI escape sequence、Escape code，可以设置颜色、控制屏幕、滚动。像打字机滚纸，可以把屏幕想成无限长的纸。

今天终端也能上下滚动。80 × 24 字符成为标准 Terminal 布局，Windows 早期黑窗口默认也不大。显示器逐渐高清，TTY 并未消失。

Unicode 又增加了表现力。这里的三角形是字符组合，里面还有 emoji，可以表达情绪。有些表情用中文念不出来，要不要收进新华字典、怎样标拼音，也是个问题。它像词一样有含义，在 token space 里有自己的 embedding，却难直接说出。Unicode 有不同高度的矩形、线条、空心和实心图形，足够多字符能拼出各种形状，比如 Claude Code 小人，我们最近还做了 3D 打印放在 lab。

从钢琴式击弦机构，到 Unicode 终端，演化中每步改动很小，积累后成为今天好用的工具。比如定制 zsh 时常见的 Powerline status bar，用 Unicode、前景色、背景色组合出分段状态栏。

可以自己试，或让模型 vibe code 一个 ASCII——应该说 Unicode 图形。
