shell 支持控制流，命令 1 后接命令 2，也支持短路。c 的 and，左边 false、0，就不算右边，因为与任何值 and 都是 0；or 左边为 1、true，就不用算右边。命令也能如此组合，例如 ls 成功才执行右边。

and 表示成功后继续；失败时尝试下一工具，再试下一项，则可以用另一种组合。这里 Fish 又有不标准的地方。

Fish 好用，但课堂容易遇到这种差异。bash、标准 UNIX Shell 支持失败后执行下一命令，所以脚本常用 /bin/bash、/bin/sh，较少用 Fish 解释。

切换解释器后继续同一尝试：

```
$ fail || echo Fail
fish: Unknown command: fail
$ bash
$ fail || echo Fail
bash: fail: command not found
Fail
```

管道则用 pipe 创建读写两个描述符，fork 后双方继承。分别关闭不用的端口，再调整描述符，就能把一个输出接给另一个输入。

课件中的重定向片段：省略文件名、execve 参数与 status 声明：

```
int fd_in  = open(..., O_RDONLY | O_CLOEXEC);
int fd_out = open(..., O_WRONLY | O_CLOEXEC);

int pid = fork();
if (pid == 0) {
    dup2(fd_in, 0);
    dup2(fd_out, 1);
    execve(...);
} else {
    close(fd_in);
    close(fd_out);
    waitpid(pid, &status, 0);
}
```

代码仍有些繁琐：准备输入 FD、输出 FD，fork，再分别调整。已经算清楚的写法，用起来还是不够简洁。
