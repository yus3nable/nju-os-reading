今天讲日常使用的终端，以及它背后的整个世界。回到 1970 年代，没有高分辨率图形显示器，人们怎样完成今天这些任务？先从键盘的历史讲起。提到 keyboard，大家会想到笔记本上的键盘，但它的历史更久。

最早的 keyboard 可以追溯到公元前三世纪的 water organ、水风琴，后来还有声音很好听的管风琴。1500 年左右，这个小视频展示了钢琴的早期原型，有一根根琴弦。看它也许会发现，今天许多发明有历史上的来由。

钢琴是击奏弦鸣乐器，按下 keyboard 上的键，小锤击中琴弦，发出声音。这样的发明已经有 500 多年。

500 年前有这种键盘，更早的水风琴也有按键。继续改进机械结构，就能用弹簧在按键时蓄力，形成擒纵机构。

![图 4：课件：打字机的擒纵机构与 QWERTY 键盘（00:02:26）。](/assets/images/08/0004.webp)

图 4：课件：打字机的擒纵机构与 QWERTY 键盘（00:02:26）。

松键时，弹簧驱动机械结构，向右移固定距离。把击弦小锤改为字母模具，击打沾墨的色带，纸上就留下字符。色带可能是类似橡胶的材料，大家未必见过。所有键都打在同一位置，松开后擒纵机构再移一格，就能打字，想到什么就打什么。若同时或接近同时按两个键，两根字杆都往中间击打，就容易卡住。

为避免高速打字卡住，1860 年代出现 QWERTY。刚学时觉得排列奇怪，从 ASDF、第一排按键练起，直到形成肌肉记忆。这个布局是为了降低打字速度。我在 2000 年还用过真正的打字机，能看到色带。

色带有黑、红两色，可以上下切换。手指既要推动字母击中色带，也要提供移到下一位置的能量，按起来很费力，比今天轻便的键盘累。

终端继承了许多设计。我［听辨不清，00:05:19］回车，得到新终端。Shift 加 A 输出大写，直接按 A 是小写，Caps Lock 锁定大写。机械打字机按 Shift，会把整组字锤或字母位置抬高、错开一格。原来小写 A 的位置空开，换成上面的一个大写 A；字锤上下两个字母分别对应大小写。Caps Lock 就把档位锁在上面。Enter 回车也有来由，printf 中其实有两个相关特殊字符。

一个是 \\r，Carriage Return；另一个是 \\n，Line Feed。\\r 将打印头移回行首。打字时每个字右移，换行前手动把机械结构推回去，也是在给弹簧蓄力，一部分力来自手。看看 Print 的效果。

打印 Hello，中间放 \\r 会怎样？先打三个字符，再回到行首，后续字符覆盖原来的位置。对机械打字机，留下的墨迹不能消失。

Python 交互输入与输出：

```
>>> print('Hel\rlo')
lol
```

终端会用新字符覆盖旧字符。机械打字机打错，像纸上写错字，没法直接擦掉，于是有 space、backspace 等移动按键。退格为什么叫 backspace，不叫 delete？苹果键盘对应位置今天可能写 delete。

因为它与 space 互逆：space 右移一格，backspace 左移一格。打错可以连续退格，再用减号、斜杠划掉旧文字，继续打。老照片里能看到这种 typo 处理，还可以切到红色带划掉。键盘上还有 tab。

今天用 control 加 tab、Alt 加 Tab、windows 加 tab 切窗口。tab 原来是制表符，打字机上能设置 tab stop，按下后一直右移，到下个停止点为止，便于对齐。我猜可能用棘轮之类结构实现。

比如表格有 name、id，可以用 Tab［听辨不清，00:09:39］对齐，避免空格 padding。名字多长都没关系，按 tab 就去下个 tab stop。

这样打字机也能做整齐表格。它还留下 monospace、等宽字体，因为每次机械移动距离固定。今天 terminal 仍用等宽字体，也许可以尝试非等宽终端，做个 project，vibe coding 看看效果。至此，现代终端和键盘的多数按键已有雏形。
