每年操作系统课，我都会推荐 man sh、command line interpreter 手册。课堂讲得快，有些细节未跟上，也有很多功能没讲。

比如输出重定向到文件，还能 append standard output；编号二的 stderr 也能 append 到 file。为什么 AI 时代还要浏览手册？这节课的终端、job control、UNIX Shell，教科书没有覆盖。可以非交互式打印手册，再管道给 Vim 查看，或直接交给 AI agent，UNIX philosophy 仍在发挥作用。

![图 109：通过管道在 Vim 中阅读手册（01:32:23）。](/assets/images/08/0109.webp)

图 109：通过管道在 Vim 中阅读手册（01:32:23）。

让它 make a summary，在辅助下阅读，就能知道哪些事情能做、哪些不能。人很难创造想象不到的东西，扩展思路的方法之一，就是看设计者想过哪些需求。

![图 110：将手册通过管道交给 Claude（01:32:38）。](/assets/images/08/0110.webp)

图 110：将手册通过管道交给 Claude（01:32:38）。

将手册交给 Vim 和 Claude 的命令：

```
man -P cat sh | vim -
man -P cat sh | claude 'Make a comprehensive summary'
```

shell 设计者在同一套系统调用上，构建了许多功能。
