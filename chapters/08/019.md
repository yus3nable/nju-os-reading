课件中的重定向与管道表达式：

```
ls > a.txt | cat
```

不同 shell 结果不同。fish、bash 什么也看不到，zsh 却像 tee，既写文件，也显示标准输出。设计者各有自己的考虑。

课件中的权限错误：

```
$ echo hello > /etc/a.txt
bash: /etc/a.txt: Permission denied

$ sudo echo hello > /etc/a.txt
bash: /etc/a.txt: Permission denied
```

sudo 为什么对这里的重定向无效？回去可以想想，或让大模型解释。最后还准备了 freestanding、零依赖 shell，连系统调用都用汇编写，大家可以看。
