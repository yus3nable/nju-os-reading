进入第一个函数 \_start\_c 后，它有一个 long \*p 参数。上节课讲过，从这个指针可以 reverse 出初始进程栈。也可以让豆包 read crt1\.c，根据代码给出初始进程栈。

crt1\.c 中的入口片段：

```
hidden void _start_c(long *p)
{
    int argc = p[0];
    char **argv = (void *)(p+1);
    __libc_start_main(main, argc, argv, _init, _fini, 0);
}
```

p 指向栈，argc 等于 p\[0\]，argv 是 p 加 1，再往后应该有一些字符串。现在 argc 为 1，打印 argv\[0\]，数值正确。继续 step 进去，看到 envp 是 argv 加 argc 加 1，打印 envp 的 0，确实是环境变量。查看 env，还能看到一些 VS Code 相关环境变量。

libc\_start\_main\_stage2 中的一行：

```
exit(main(argc, argv, envp));
```

main 返回 1，然后执行 exit(1)。exit 会执行刚才看到的清理逻辑，［听辨不清，00:40:15］，包括 \_\_stdio\_exit，最后到 \_Exit，直接调用 syscall。libc 封装 system call，屏蔽其细节，上层无需了解底下是什么操作系统。
