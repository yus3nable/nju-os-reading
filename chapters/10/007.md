printf 实现很短，基本就是取出变参数。format 显示为 X=%d。有鼠标时查看更方便，把左边面板拖大就能直接看到 format string。printf 将 stdout 传给 vfprintf。

![图 59：printf 将参数交给 vfprintf（00:42:34）。](/assets/images/10/0059.webp)

图 59：printf 将参数交给 vfprintf（00:42:34）。

printf 的实现片段：

```
int printf(const char *restrict fmt, ...)
{
    int ret;
    va_list ap;
    va_start(ap, fmt);
    ret = vfprintf(stdout, fmt, ap);
    va_end(ap);
    return ret;
}
```

鼠标移到 stdout 上，可以看到 flag、buffer 等成员。buffer 现在为空，buf\_size 是 1024，fd 等于 1。stdout 是封装好的结构体，包含文件描述符、缓冲区及其他信息。step into 进入 vfprintf 后，它先调用一次 printf\_core，试探是否需要返回失败。检查通过后，再调用 printf\_core 实际输出，传入 f、format 和其他参数。f 还是刚才的结构体，fd 仍为 1，表示向 stdout 打印 x 等于百分号 d 这个 format 字符串。
