操作系统中的许多概念都能用模型检查器检查，这里准备了不少例子，先看一个。

![图 35：Python 模型：在操作之间让出执行权（00:47:36）。](/assets/images/14/0035.webp)

图 35：Python 模型：在操作之间让出执行权（00:47:36）。

```
# T_1 中举旗与礼让的顺序
heap.x = '🏴'
sys_sched()
heap.turn = '❷'
sys_sched()

# 观察与进入条件
t = heap.turn
sys_sched()
y = heap.y != ''
sys_sched()
if not y or t == '❶':
    break
```

这是 Peterson 算法的可执行 Python 代码。sys\_sched 表示这里可以切换到另一个线程，先举起 x，再把字条贴门上，随后观察。命令行运行后，会得到状态图数据，其中包含程序输出、共享内存状态和局部变量状态。它做的就是把黑板上从某状态让 Alice 走一步的过程，用程序执行出来。
