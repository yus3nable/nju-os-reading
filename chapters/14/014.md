```
# T_1 中举旗与礼让的顺序
heap.x = '🏴'
sys_sched()
heap.turn = '❷'
sys_sched()

# 观察与进入条件
t = heap.turn
sys_sched()
y = heap.y != ''
sys_sched()
if not y or t == '❶':
    break
```

Peterson 算法，大家可以忽略这个 sys\_sched，这个就代表在这个时候可以切换到另外一个线程执行，x 先举起来，然后把手上的字条贴到门上，然后开始观察这样的一个过程，就是一个真正的可以执行的 Python 代码，然后我可以在命令行里面，我可以直接在命令行里执行它。然后执行它以后，就会得到一个状态图，状态图，你看各种各样的状态图，状态里面有程序的输出，有共享内存的状态，有局部变量的状态，做的就是这件事，就是我在黑板上，我可以把从一个状态开始。
