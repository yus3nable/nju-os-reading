struct file\_operations 提供 read、write、mmap、flock 等操作，假设 file 设备对应字节流或字节序列。字符设备如终端，是字节流；磁盘是字节序列，可能可以 mmap。但打印机、显卡除了承载数据，还需要控制功能。

canonical device 有 status、command、data 三类寄存器，也就是状态、命令、数据。Everything is a File 主要对应 data：打印机要接收程序，gpu 要接收贴图和 kernel，数据的确是最主要的抽象。但怎样控制？比如让打印机停止或亮灯，难道还要像 ANSI escape code 那样，把特殊控制字符串硬编码后写进去？这就是 unix 世界比较 dirty 的地方。
