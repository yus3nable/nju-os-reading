ioctl 接口很稳定，承担着操作系统中的复杂功能。KVM 是 open 返回的 FD、文件描述符，对它执行 KVM\_CREATE\_VM 命令，就会在内核里创建虚拟机。创建后还可以分配内存。

在当前进程的地址空间里，用 mmap 分配内存，再通过 ioctl 命令 KVM\_SET\_USER\_MEMORY\_REGION，告诉 KVM 把这段内存给虚拟机。

![图 69：设置内存区域并创建 vCPU（01:16:32）。](/assets/images/22/0069.webp)

图 69：设置内存区域并创建 vCPU（01:16:32）。

KVM 内存区域和 vCPU 创建片段；依赖前文的内存、VM 文件描述符及常量。

```
struct kvm_userspace_memory_region mem_region = {
    .slot = 0,
    .guest_phys_addr = GUEST_ENTRY,
    .memory_size = GUEST_MEM_SIZE,
    .userspace_addr = (uint64_t)guest_mem,
};
ioctl(vmfd, KVM_SET_USER_MEMORY_REGION, &mem_region);
vcpufd = ioctl(vmfd, KVM_CREATE_VCPU, 0);
```

比如分配 128G——128 兆内存，把这 128 兆交给内核中的虚拟机。还可以创建一个 VCPU，或多个 VCPU，再做很多配置，具体就不展开了。
