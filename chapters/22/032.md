显卡还有 6PIN 和 8PIN 供电口。高速设备如 FPGA、显卡、网卡、NVMe，都连在 PCIe 总线上。基于 PCIe 物理层，还出现了 CXL，Compute Express Link，可以理解为数据中心里的下一代总线。它有三个 protocol：I/O、Cache、Memory。它的目标超出了连接显卡、打印机等设备。

在 Canonical Device model 中，设备可能较慢，或者负责物理交互，通过 Register 与 host，也就是 CPU 交换数据。CXL 希望直接共享内存，既能在本地与显卡共享高带宽内存，还能通过高速网络，共享另一台计算机的内存并传输数据。

这样就有了 Disaggregated Data Center。服务器 CPU 仍有本地内存，因为本地访问才足够快，但容量不用很大；远端可以有一块 16T 共享内存，每个位置都可寻址，像内存一样访问。

比如 allocate 4 个 T，这 4 个 T 就在自己的地址空间中。如果访问命中 memory hierarchy，可能直接走本地内存；访问远端则可能需要一次网络 round trip，有几百纳秒延迟。程序写得足够好，就能实现数据中心里的 disaggregated memory。这也呼应上节课的话：到了真实系统，会发现教科书上学过的东西都错了。

留下的是分析基本原理、面对问题和诊断故障的方法。以上这些 I/O 设备，在交换数据这一点上，与 LED 灯没有根本区别。有了数据交换，就能实现打印机、摄像头、总线等设备，让计算机系统发展起来。这些都是底层的内容。
