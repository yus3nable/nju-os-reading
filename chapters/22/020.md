这就是编程语言的力量。从 1950 年代为打印机设计语言，逐步发展到今天的 HTML、SVG，就能做很多事情。PostScript 本身是图灵完备的编程语言，可以循环、设置状态，有基于 stack 的 machine，通过图形状态机构造图形。

page\.ps 中的星点和交叉线片段；绘图颜色等状态由前文设置。

```
[
    [140 18] [250 16] [50 48] [330 20]
] {
    aload pop
    /sy exch def /sx exch def
    newpath
    sx sy 2 0 360 arc fill
    newpath
    sx 4 sub sy moveto sx 4 add sy lineto stroke
    newpath
    sx sy 4 sub moveto sx sy 4 add lineto stroke
} forall
```
