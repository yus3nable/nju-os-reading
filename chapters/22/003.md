计算机系统基础课会讲中断和 I/O。I/O 就是 input and output，输入与输出。输入输出设备连接计算机中看不见的部分与物理世界，模型很简单：一个能与 CPU 交换数据的接口或控制器。无论设备简单还是复杂，只要能与 CPU 交换数据，就能成为 I/O 设备。

输入、输出以 CPU 为参照，分别是向机器内输入、向机器外输出。从机器外部看，方向就反过来。设备让 CPU 获取系统外部的数据，也把计算结果送到系统外。everything is a state machine，NEMU 实验中就有 CPU state。

CPU state 本身不能干涉物理世界，它只是 register、memory 中具体的零和一。想影响外界，就需要设备。就像大脑封在颅骨里，要靠眼睛、耳朵感受世界，靠手脚改变世界；I/O 设备也相当于计算机的手脚。这也解释了，第一次使用电脑时，交互的其实是各种 I/O 设备。

I/O 设备的模型也可以很简单，叫 canonical device model。先从 CPU 中熟悉的寄存器说起。
