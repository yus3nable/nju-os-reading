那为什么它要叫输入输出设备呢？对吧，你们有没有想过想过因为你们在计算机系统基础课上其实也会讲叫中断和 I/O 那个部分，I/O 就是 input and output 输入和输出，而所谓输入和输出的设备它是整个计算机就是你看不见的那个部分和物理世界之间的一个桥梁，所谓的一个 I/O 设备它简单的甚至是我觉得是不能再简单了，它的模型就是一个能与 CPU 交换数据的接口或者一个控制器，也就是说任何一个你能够想象的它可能很简单也可能很复杂的一个东西，只要它能够和 CPU 交换数据它就能成为一个 I/O 设备。

然后 I/O 设备因为既然是 input and output 从当时站在 CPU 的角度看，你站在 CPU 角度上输入和输出是向机器内输入然后向机器外输出，但如果你站在机器的外面的角度的话，你又输入和输出就会反过来。所以它是按照从 CPU 的角度来看。然后这些输入和输出设备使得我能够获取来自系统外的数据，以及我可以把我 CPU 里面算出来的数据推到系统的外面，也就是说 everything is a state machine，我们在写 NEMU 实验的时候有一个 CPU state。

然后这个 CPU state 本身是不能干涉我们的物理世界的，对吧？它就是这里面一些 register 然后一些 memory 的具体的零和一，然后如果你的计算机想要能够干涉这个世界，有点像我们大脑对吧，我们的大脑是封在我们的颅骨里面的，如果我们想要感受这个世界，我们就需要用我们的眼睛啊耳朵啊。然后如果我们想要改变这个世界就需要用我们的手和脚。所以同样的也是的，I/O 设备就是计算机的手和脚，这也解释了为什么我们，我刚才说你们在第一次用电脑的时候，其实你看到那个电脑。

其实你跟它交互的是各种各样的 I/O 设备，然后 I/O 设备的模型呢也可以很简单啊，基本上你可以这样理解，这是一个叫 canonical device model，我们的首先 CPU 里面是有寄存器的，对吧。
