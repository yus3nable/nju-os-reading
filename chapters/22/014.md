类似的还有 ATA 控制器，Advanced Technology Attachment，连接 IDE 磁盘接口。装过电脑可能用过那根很宽的 40pin data 数据线。

图 20：ATA 磁盘控制器的读取代码（00:19:41）。

ATA 课件片段；依赖端口 I/O 函数、waitdisk、SECTSIZE 和整数类型定义。

```
void readsect(void *dst, int sect) {
    waitdisk();
    out_byte(0x1f2, 1);                    // sector count (1)
    out_byte(0x1f3, sect);                 // sector
    out_byte(0x1f4, sect >> 8);            // cylinder (low)
    out_byte(0x1f5, sect >> 16);           // cylinder (high)
    out_byte(0x1f6, (sect >> 24) | 0xe0);  // drive
    out_byte(0x1f7, 0x20);                 // command (read)
    waitdisk();
    for (int i = 0; i < SECTSIZE / 4; i++)
        ((uint32_t *)dst)[i] = in_long(0x1f0); // data
}
```

它也有两组映射到 x86 的端口：0x1f0 到 0x1f7、0x170 到 0x177。要读磁盘，先从 Status 寄存器判断是否 ready，等 ready 后，向相应寄存器写入正确值，包括读取多少个 sector，也就是小块，以及小块编号。最后向正确寄存器写入读命令，就能读数据。
