对吧，因为本质上 I/O 设备，我们说是 CPU 的手和脚，对吧？它是 CPU 的延伸，它要做一些 CPU 完成不了的事情，除了我们说可以和另外一个设备，交换数据一个协议之外，我们还可以干一件非常有趣的事，我希望的是我的一个设备，可以和我的 CPU 共享内存，也就是我的 Device 能不能也和 CPU，接在同一个内存上，这当然是可以的，这称为协处理器了。当然协处理器未必一定是这样，以共享内存的方式来接触的，比如说早期的时候，我们 CPU 里面是没有浮点数指令的，比如说 80386 是没有浮点指令的，然后它有一个 80387 的浮点指令。

然后你的浮点的协处理器上面有些寄存器，然后你可以用 CPU 去访问它，当然现在比如说今天，我们绝大部分的协处理器，都会更复杂一些然后它以共享内存的方式，接到内存里，然后这个早期的一个这样的设备，就是 DMA，DMA 叫 Direct Memory Access，你可以把它理解成。
