I/O 设备像 CPU 的手脚，是它的延伸，完成 CPU 自己做不了的事。除了通过协议与设备交换数据，还可以让 Device 与 CPU 共享内存，连接到同一块内存。这当然可以，称为协处理器。不过协处理器未必都通过共享内存连接。早期 CPU 没有浮点指令，比如 80386，通过 80387 提供浮点指令。

浮点协处理器上有寄存器，CPU 可以访问。今天绝大部分协处理器更复杂，通过共享内存连接。早期这样的设备之一是 DMA，Direct Memory Access。
