USB 键盘通过一根线连接。更早的 IBM PC 时代还没有 USB 总线，键盘控制器用的是这种接口。拆过老机器，或者从家里翻出老鼠标，可能见过它，有六根线。仔细看 USB 接口，也有引脚，应该是八根线。

PS/2 的六根线分别是 Data 数据、Clock、VCC、Ground，也就是时钟、高电平、低电平，以及两根预留线。预留线没有指定功能，厂商可以自行定义。Data 用来传输数据。PS/2 映射到 I/O 地址空间的两个端口，0x60、0x64，这应该是第一个 PS/2 接口。0x60 是 Data，0x64 是 status 和 Command。向 Command 写特殊字符，就能配置键盘、鼠标。

以前键盘与 TTY 比较像，按住 A 时，会每隔一小段时间发送一次 A 按键。这个行为可配置，间隔保存在键盘控制器中。当时 CPU 慢，希望尽量把功能放在设备上，减轻 CPU 负担。发送特殊字符串，就能配置键盘，比如控制 Caps Lock 灯亮灭，或改变按键重复延迟。

现在更多是直接把按下、松开的键发给软件，再由软件决定发送多少个按键序列，于是可以在操作系统中修改重复延迟。I/O 设备就是通过这些寄存器，与另一个电路设备收发数据，实现 input 和 output。
