一定程度上，所有同步访问都可以通过 ioctl 完成。今天借这些例子理解了操作系统对象：驱动实现 struct file\_operations，应用通过驱动访问实际设备的数据。再看 UVC 摄像头的演示。

运行 snapshot，就能从摄像头取一帧，保存到 capture\.jpg。jpg 数据确实有问题，应该是非标准 UVC 设备，但仍然捕获到了一些图形。

![图 75：摄像头抓帧后出现的图像异常（01:20:52）。](/assets/images/22/0075.webp)

图 75：摄像头抓帧后出现的图像异常（01:20:52）。

图中的 a 是大写 caps lock 锁定灯上的字，说明确实抓到了一帧，程序基本可以工作。接着可以问 AI。

![图 76：snapshot 保存 JPEG 并报告数据警告（01:21:14）。](/assets/images/22/0076.webp)

图 76：snapshot 保存 JPEG 并报告数据警告（01:21:14）。

抓帧输出与图像数据警告的片段：

```
$ ./snapshot
Format: 640x480 MJPG
Captured 7883 bytes
Saved capture.jpg
$ open capture.jpg
Corrupt JPEG data: premature end of data segment
```
