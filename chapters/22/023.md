课件中的 DMA 四通道执行模型，属于教学伪代码；channels 和通道结构未展开。

```
void T_i8237() {
    while (1) {
        for (int i = 0; i < 4; i++) { // Channel
            struct channel_t *ch = &channels[i];
            if (ch->count-- > 0) {
                if (ch->mode == READ)
                    ch->io = ch->mem[ch->addr++];
                else
                    ch->mem[ch->addr++] = ch->io;
                break; // Priority
            }
        }
    }
}
```
