UART 课件片段，依赖 inb/outb 和 AM 的收发结构；\.\.\. 保留初始化省略。

```
#define COM1 0x3f8
static int uart_init() {
    outb(COM1 + 2, 0);       // 控制器相关细节
    outb(COM1 + 3, 0x80);
    outb(COM1 + 0, 115200 / 9600);
    ...
}
static void uart_tx(AM_UART_TX_T *send) {
    outb(COM1, send->data);  // 写寄存器
}
static void uart_rx(AM_UART_RX_T *recv) {
    recv->data = (inb(COM1 + 5) & 0x1) ? inb(COM1) : -1;
}
```

这和操作系统联动，然后在你们的电脑上其实都是有终端的，像你们的 PC 上面有一个叫 COM1 的东西，有 COM1 的东西，UART，Universal Asynchronous Receiver/Transmitter，然后在我的树莓派上也有一个/dev/ttyS0，我这儿没有，对，那就在这个ttyAMA10。这是一个 TTY，这个串口是绑到我的 GPIO 的接口上的，就跟这样的一个开发板上一样，我就不把我的树莓派抬起来了，就绑在这样的一个非常细的针脚上面的两个引脚上。

然后在 PC 上面理论上说你也是用类似的方式来访问的，它有好几个 register，然后这是 x86 的代码，x86 和像 ARM RISC\-V 不一样。
