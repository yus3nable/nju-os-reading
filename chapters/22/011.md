UART 课件片段，依赖 inb/outb 和 AM 的收发结构；\.\.\. 保留初始化省略。

```
#define COM1 0x3f8
static int uart_init() {
    outb(COM1 + 2, 0);       // 控制器相关细节
    outb(COM1 + 3, 0x80);
    outb(COM1 + 0, 115200 / 9600);
    ...
}
static void uart_tx(AM_UART_TX_T *send) {
    outb(COM1, send->data);  // 写寄存器
}
static void uart_rx(AM_UART_RX_T *recv) {
    recv->data = (inb(COM1 + 5) & 0x1) ? inb(COM1) : -1;
}
```

这些功能会与操作系统联动。PC 上有 COM1，也就是 UART，Universal Asynchronous Receiver/Transmitter。树莓派上也有 /dev/ttyS0，我这台没有，实际是 ttyAMA10。这是一个 TTY，串口绑定到 GPIO 接口，就像开发板上那样，连在很细的针脚中的两个引脚上。我就不抬起树莓派了。

PC 理论上也是通过类似方式访问，它有几个 register。这里是 x86 代码，和 ARM、RISC\-V 不同。
