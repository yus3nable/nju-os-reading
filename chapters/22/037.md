所以它就是一段非常普通的内核代码，比如说一个 mmap 或者一个 read 或者 write 的实现，如果你们去看 Linux source code 里面的，像/dev/null，它其实就是实现了一个 null\_read 和 write，它都是直接返回，它会实现一个 read。然后这个 read 直接返回 0，因为你从那个空设备里面读不出任何的数据。所以它就直接返回 0。然后对于这个/dev/null 的 write，它就会直接返回 nwrite。对吧。write 系统调用。write 系统调用里面有一个 count，然后你写了多少个字节，它就会返回给，作为系统调用的返回值返回出来，然后如果你要实现一个 /dev/null 的话，它就不会执行任何实际的数据处理的操作，而是直接返回一个你给我多少数据我就认为我都写了。但是写了以后这些数据都消失了，就实现了一个数据黑洞的这样的设备。对吧，它是一个伪的设备。
