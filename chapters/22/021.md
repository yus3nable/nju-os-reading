我在上课的时候可以做演示，我就这个 prompt，然后它就给了我这个一个 page\.ps，大家猜猜这是什么呢？大家不需要猜，我们有很多工具，比如说我可以用，ps2pdf，把这个 ps 变成一个 PDF，然后我就可以打开它，它帮我生成的一个确实还是很不错的PostScript，它有文字，它有文字。

图 30：ps2pdf 将 page\.ps 转为 page\.pdf（00:30:04）。

终端中的转换命令：

```
$ make
ps2pdf page.ps
$ ls
Makefile  page.pdf  page.ps  README.md
```

page\.ps 中设置字体、颜色、位置并绘制标题的片段：

```
/Times-Bold findfont 28 scalefont setfont
0 0 0 setrgbcolor
200 470 moveto
(POSTSCRIPT) dup stringwidth pop 2 div neg 0 rmoveto show
```

然后字号是 28 号，然后 set font 完了以后，我会移到把这个打印头，移到某一个位置上，然后打印头，移到这个位置上，你用某一个字体，去打印一个 title，对，那个 PostScript 的字，在很长一段时间里面，PostScript 都是，打印界的事实标准。然后直到PDF，成为它的继任者。
