我就用这样的 prompt，它给了我 page\.ps。里面是什么？用工具就能看到，比如 ps2pdf，把 ps 转成 PDF 再打开。它生成的 PostScript 中包含文字。

![图 30：ps2pdf 将 page\.ps 转为 page\.pdf（00:30:04）。](/assets/images/22/0030.webp)

图 30：ps2pdf 将 page\.ps 转为 page\.pdf（00:30:04）。

终端中的转换命令：

```
$ make
ps2pdf page.ps
$ ls
Makefile  page.pdf  page.ps  README.md
```

![图 31：转换后的 PostScript 图形（00:30:11）。](/assets/images/22/0031.webp)

图 31：转换后的 PostScript 图形（00:30:11）。

同时也有图形，能够精确描述矢量图，无限放大仍然精确，用于高质量印刷。PostScript 长期是打印界的标准。打印文字时，可以用命令指定字体。

page\.ps 中设置字体、颜色、位置并绘制标题的片段：

```
/Times-Bold findfont 28 scalefont setfont
0 0 0 setrgbcolor
200 470 moveto
(POSTSCRIPT) dup stringwidth pop 2 div neg 0 rmoveto show
```

这里字号是 28 号，set font 后，把打印头移到指定位置，用所选字体打印 title，也就是 PostScript 这几个字。PostScript 长期是打印界的事实标准，后来由 PDF 接替。
