课件中的 PCL 控制序列示意；&lt;ESC&gt; 表示 ESC 字符，二进制图像数据未展开。

```
<ESC>*t300R          // Set resolution to 300 DPI
<ESC>*r1A            // Start raster graphics
<ESC>*b100W          // Set width of raster data (100 bytes)
<ESC>*b0M            // Set compression mode (0 = uncompressed)
<ESC>*b100V          // Send 100 bytes of raster data
<binary raster data> // Actual image data
<ESC>*rB             // End raster graphics
```

所以就很自然的会有像 PCL，有 PostScript 这样的语言被发明出来，你们如果装过打印机的话，比如说你们的实验室的打印机，比如说我们的实验室的打印机，就是一个叫 PCL6 兼容的打印机，然后在 PCL6 之前。比如说 PCL5 或者之前，它的打印的命令，就是长左边这个样子的，它每一次都，就相当于你可以往这个data 的寄存器里面送一个程序。然后这个程序，每次都是什么 Escape，一个 ESC。然后一个命令。然后打印机支持各种各样的命令。比如说设置打印的 resolution。

然后设置打印的模式，设置这个打印的宽度，然后各种各种配置，然后你可以把图像，一个 binary 的图像送过去，然后 binary 图像，它收到以后，它就可以直接打印了，然后为了方便大家，更好的交换这种，可以打印的文件，我们就有了 PostScript，我这里也有一个 PostScript。
