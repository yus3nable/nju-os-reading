课件中的 PCL 控制序列示意；&lt;ESC&gt; 表示 ESC 字符，二进制图像数据未展开。

```
<ESC>*t300R          // Set resolution to 300 DPI
<ESC>*r1A            // Start raster graphics
<ESC>*b100W          // Set width of raster data (100 bytes)
<ESC>*b0M            // Set compression mode (0 = uncompressed)
<ESC>*b100V          // Send 100 bytes of raster data
<binary raster data> // Actual image data
<ESC>*rB             // End raster graphics
```

于是自然出现了 PCL、PostScript。装过实验室打印机可能见过，我们实验室的就是 PCL6 兼容打印机。PCL6 之前，比如 PCL5 或更早的命令，就像左边这样，向 data 寄存器送入程序，每次是 Escape，一个 ESC，再跟一个命令。打印机支持设置 resolution 等命令。

还可以设置打印模式、宽度等，把 binary 图像送过去，打印机收到就能打印。为了更方便地交换可打印文件，又有了 PostScript，我也准备了一个例子。
