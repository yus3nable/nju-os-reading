LED 循环片段；running、brightness\_fd 和 interval\_ms 来自外层程序：

```
int state = 1;
while (running) {
    char val = state ? '1' : '0';
    if (write(brightness_fd, &val, 1) < 0) {
        perror("write brightness");
        break;
    }
    state = !state;
    usleep(interval_ms * 1000);
}
```

所以我可以直接运行这个程序，然后现在我的这个灯其实就已经开始闪了，它确实在闪，对吧？然后我现在可以把这个程序关掉，它就不动了，然后如果我可以把它的频率调成，比如说 1000，你看它闪的速度就变慢了，大家不要在意这个显示效果的问题，至少。
