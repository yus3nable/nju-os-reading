可以通过写文件来控制它：用 write 系统调用向 brightness\_fd 写一个值，就能让 LED 闪烁。

![图 12：用 write 写 brightness 并切换状态（00:11:28）。](/assets/images/22/0012.webp)

图 12：用 write 写 brightness 并切换状态（00:11:28）。

LED 循环片段；running、brightness\_fd 和 interval\_ms 来自外层程序：

```
int state = 1;
while (running) {
    char val = state ? '1' : '0';
    if (write(brightness_fd, &val, 1) < 0) {
        perror("write brightness");
        break;
    }
    state = !state;
    usleep(interval_ms * 1000);
}
```

运行程序，现在灯确实在闪；关闭程序，就停止变化。把频率调成比如 1000，闪烁就变慢了。先不在意显示效果的问题。

![图 13：以 100 ms 间隔启动 LED 程序（00:11:36）。](/assets/images/22/0013.webp)

图 13：以 100 ms 间隔启动 LED 程序（00:11:36）。

终端中的启动命令和输出：

```
$ make
gcc -Wall -g led-blink.c -o led-blink
$ sudo ./led-blink 100
Blinking PWR LED every 100 ms. Press Ctrl-C to stop.
```
