树莓派的拓扑与大家的机器不太一样。x86 系统上，USB 总线挂在 PCI 总线上，PCI 的一部分连接 USB 控制器，USB 还能逐层连接。用 lsusb \-t 可以得到树状列表。

![图 44：lsusb \-t 显示 USB 拓扑（00:45:22）。](/assets/images/22/0044.webp)

图 44：lsusb \-t 显示 USB 拓扑（00:45:22）。

现在打开摄像头，就能看到 Port001 上出现设备。我把摄像头插在最右边的接口，打开后就有了这样的条目。

![图 45：启动摄像头后出现 Video 与 uvcvideo 接口（00:45:45）。](/assets/images/22/0045.webp)

图 45：启动摄像头后出现 Video 与 uvcvideo 接口（00:45:45）。

lsusb \-t 输出中新增的 Video 接口片段：

```
|__ Port 002: Dev 003, If 0, Class=Video, Driver=uvcvideo, 480M
|__ Port 002: Dev 003, If 1, Class=Video, Driver=uvcvideo, 480M
```

Class 是 Video，Driver 是 uvcvideo，传输速率 480 兆。总线支持发现设备，也能提供标识。比如扫描 PCI 总线，能从设备读取设备号，通过设备号知道厂商，加载相应驱动，让它正确工作。总线本身也很复杂。
