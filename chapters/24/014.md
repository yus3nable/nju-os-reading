需要一个什么样的 API 呢？比如说我说我 U 盘上面有一个目录树，或者我的网络上面有一个目录树，我希望要把这个目录树要放到我们的文件系统里，对吧，就像你插 U 盘以后，你会 U 盘就在桌面上有一个目录了，然后你希望把这个文件系统上的，这就是文件系统，一个文件系统，一个目录树整个就放到操作系统，或者说整个操作系统，根 namespace 上面的某一个地方。

ISO 9660 主卷描述符的字段片段；字段之间及尾部仍有未展开内容：

```
struct iso9660_primary_descriptor {
    uint8_t type;          /* ISO9660_VD_PRIMARY */
    char standard_id[5];   /* 必须是 "CD001" */
    /* 中间字段未展开 */
    char system_id[32];    /* 系统标识符 */
    char volume_id[32];    /* 卷标识符 */
    /* 后续字段未展开 */
};
```

然后这个地方你可以通过一级一级一级的索引。
