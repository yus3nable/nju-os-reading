这个 API 要能把 U 盘或网络中的目录树放进当前文件系统。像插 U 盘后桌面出现目录，就是把整棵文件系统目录树，放到操作系统根 namespace 的某个位置。

ISO 9660 主卷描述符的字段片段；字段之间及尾部仍有未展开内容：

```
struct iso9660_primary_descriptor {
    uint8_t type;          /* ISO9660_VD_PRIMARY */
    char standard_id[5];   /* 必须是 "CD001" */
    /* 中间字段未展开 */
    char system_id[32];    /* 系统标识符 */
    char volume_id[32];    /* 卷标识符 */
    /* 后续字段未展开 */
};
```
