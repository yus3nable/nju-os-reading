可以看 man 7 的 extended attribute。它为每个文件维护 key value，像 a\.txt 有一个框，能写 json，记录它的实际 type。

![图 73：Extended Attributes 与向量索引（01:10:43）。](/assets/images/24/0073.webp)

图 73：Extended Attributes 与向量索引（01:10:43）。

课件中的扩展属性接口声明；系统类型与 value\[\.size\] 标记沿用课件写法：

```
ssize_t fgetxattr(int fd, const char *name,
                  void value[.size], size_t size);
int fsetxattr(int fd, const char *name,
              const void value[.size], size_t size, int flags);
```

也能加 icon，内容可以自定，就是 key value。即便不知道机制细节，也能让 AI 为 a\.txt 设置 extended attributes，它会说明具体命令。
