内存可以看作 byte array。主板上插两条 8G 内存，就有 16G，物理地址空间可能从 0 到 16G。实际总线通常采用 burst 传输，连续发送多个字节，所以内存的访问特性也有点像 block device，虽然与 SSD 的 16KB page 不同。

CPU 一般通过 memory hierarchy 访问物理内存，经过缓存、虚拟内存等。DRAM 之上，CPU 里的 MMU 让每个进程、线程看到虚拟地址空间，像戴上配置好的 VR 眼镜。

MMU 能把任意物理页映射到虚拟页，也能在两个进程间共享页面映射。在平坦的进程虚拟地址空间上，再构建 malloc、free，进而构建 list、set 等 data structure。

Python 的 list、set、dictionary 基本也基于 malloc、free。这条抽象路径已经走过一次，块设备之上的文件系统，同样是一个数据结构。
