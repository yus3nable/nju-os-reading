这给 system implementation 带来复杂性，但机制很好用。我先立个 flag，觉得它迟早会流行，只是不知道现在为何还没流行。除 extended attribute，还有更复杂的 access control。用户、同组用户、其他用户的读写执行权限，粒度仍然粗。

比如希望所有用户都能看文件，唯独 JYY，或者爸爸不能看，用用户、组表达就麻烦，需要专门建组。

课件中的 ACL 设置和查看命令：

```
setfacl -m u:jyy:- file
getfacl file
```

Linux 还有 access control list 扩展，能做 fine\-grained access control。
