新知识太多，以前单靠读手册，很难这样了解。AI 识别出当前插着 Win98 光盘，文件系统格式是 ISO9660，按特定结构组织，比如 struct iso9660\_primary\_descriptor，要求某个位置有 CD001。

![图 18：Agent 识别外置 DVD 驱动器和 Windows 98 光盘（00:24:59）。](/assets/images/24/0018.webp)

图 18：Agent 识别外置 DVD 驱动器和 Windows 98 光盘（00:24:59）。

识别正确，这里 0x8000 位置确实有 CD001。这是数据结构标识。内存中的数据结构会有 root node 根节点，可能带 left、right 指针；设备同样是 byte array。

![图 19：光盘数据中的 CD001 标识（00:25:23）。](/assets/images/24/0019.webp)

图 19：光盘数据中的 CD001 标识（00:25:23）。

cdrom 字节序列中的 CD001 字符串，让程序在正确位置读到相应数值后，辨识数据结构，调用代码解析为目录树，接入文件系统。要使用它，就可以 mount。
