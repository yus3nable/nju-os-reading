Linux、Unix 还有 eject 命令，用来弹出光盘。按驱动器按钮可以弹出，合上后在命令行运行 eject，也有同样效果。

![图 25：用 eject 弹出光盘的实物演示（00:30:22）。](/assets/images/24/0025.webp)

图 25：用 eject 弹出光盘的实物演示（00:30:22）。

现在确实自动弹出了，甚至可以利用反复推拉做个小玩具。它用什么系统调用？也是 ioctl。先 open /dev/sr0，再 ioctl 控制 cdrom eject。

![图 26：eject 的 CDROM\_LOCKDOOR 和 CDROMEJECT 调用（00:30:52）。](/assets/images/24/0026.webp)

图 26：eject 的 CDROM\_LOCKDOOR 和 CDROMEJECT 调用（00:30:52）。

eject 跟踪中的设备控制片段；省略其余调用：

```
openat(AT_FDCWD, "/dev/sr0", O_RDWR|O_EXCL|O_NONBLOCK) = 3
ioctl(3, CDROM_LOCKDOOR, 0) = 0
ioctl(3, CDROMEJECT, 0) = 0
close(3) = 0
```

操作系统的行为都能用明确的 API 解释：有的由驱动处理，比如 eject；有的是块设备读写。组合起来，就能从初始文件系统出发，通过 mount 得到新的目录树。
