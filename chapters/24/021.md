好，这是光盘，最后还有一个有意思的，我们的 Linux，Unix 还有一个命名叫 eject，然后 eject 的效果，就是把这个光盘给推出，所以你知道你按这个按一下这个键，这个光盘就会推出，但我把它合上以后，同样的我可以在这里，运行一个命令行工具叫 eject。

它也推出了，自动的推出，然后你甚至可以用 eject 来做一个可能往复推拉的一个小的玩具都是可以的，然后 eject 用的是什么系统调用呢？对吧，答案也是 ioctl，你看它打开了，用 open 打开了/dev/sr0。然后用 ioctl 去控制这个 cdrom eject。

![图 26：eject 的 CDROM\_LOCKDOOR 和 CDROMEJECT 调用（00:30:52）。](/assets/images/24/0026.webp)

图 26：eject 的 CDROM\_LOCKDOOR 和 CDROMEJECT 调用（00:30:52）。

eject 跟踪中的设备控制片段；省略其余调用：

```
openat(AT_FDCWD, "/dev/sr0", O_RDWR|O_EXCL|O_NONBLOCK) = 3
ioctl(3, CDROM_LOCKDOOR, 0) = 0
ioctl(3, CDROMEJECT, 0) = 0
close(3) = 0
```

然后它就 eject，所以这就是你看到的，就操作系统里面其实没有任何魔法的，甚至某种意义上来说，做的所有事情都是简单的，都是有一些 well defined 的 API，要么就是比如说是驱动帮你 take care 的，对吧，这种 eject，要么就是这种块设备的读写，这些。然后这些东西加起来，就变成了你在操作系统里面看到的一切，从无到有的一个目录树，一个 mount 的系统调用。好。然后。
