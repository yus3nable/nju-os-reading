对吧，我可以 mount /dev/cdrom，把这样的一个块设备，系统调用上是要求一个块设备，但是在这里可以不用，然后它会把一个设备映射到文件系统当中，好，现在成功，你看它花了一些时间，而且它告诉我，再试一次。

![图 20：第一次挂载失败后重试（00:26:23）。](/assets/images/24/0020.webp)

图 20：第一次挂载失败后重试（00:26:23）。

好，这次成功了，它给了个 warning，它说 write\-protected，mounted read only，这一个光盘是没有办法写入的，对吧，它不是一个这样的 block device，它是一个只读的设备。所以它也是 read only mount 的，然后我可以在这个目录里看一下，诶，有了，你看它有 autorun\.inf，有这个文件，这个文件就意味着，Windows 看到这个文件，它就知道你的光盘是可以自动播放的，这个特性使得你在，比如说发售游戏的时候。

![图 21：只读挂载成功、路径输入纠正与 autorun\.inf（00:26:53）。](/assets/images/24/0021.webp)

图 21：只读挂载成功、路径输入纠正与 autorun\.inf（00:26:53）。

挂载重试和目录输入纠正的终端片段：

```
$ sudo mount /dev/cdrom /mnt
mount: /mnt: wrong fs type, bad option, bad superblock on /dev/sr0, missing codepage or helper program, or other 
error.
$ sudo mount /dev/cdrom /mnt
mount: /mnt: WARNING: source write-protected, mounted read-only.
$ cd/mnt
fish: Unknown command: cd/mnt
$ cd /mnt
$ cat autorun.inf
[autorun]
OPEN=CDSAMPLE\AUTORUN\AUTORUN.EXE
ICON=CDSAMPLE\AUTORUN\WIN98CD.ICO
```

你把游戏光盘插入计算机，然后那个光，你把这个光驱合上的时候。
