文件只有执行位时，普通用户运行脚本的结果：

```
$ ls -l
---x--x--x 1 root root 24 May 26 11:36 a.txt
$ ./a.txt
/bin/bash: ./a.txt: Permission denied
```

strace 显示直接在 open 系统调用失败，返回 EACCES、permission denied。这就是权限管理，也是文件属性的一部分。

![图 68：openat 以 EACCES 拒绝读取文件（01:03:03）。](/assets/images/24/0068.webp)

图 68：openat 以 EACCES 拒绝读取文件（01:03:03）。

跟踪中的打开文件失败：

```
openat(AT_FDCWD, "a.txt", O_RDONLY) = -1 EACCES (Permission denied)
```

文件属性影响操作系统行为，比如执行权限决定能否通过 execve 处理它。
