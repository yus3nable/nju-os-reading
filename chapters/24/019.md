合上光驱，读到配置后，就能自动运行 autorun\.exe。再 cat readme\.txt，因为这是中文版 Windows，Win98 当时用中文编码，在我的 UTF8 系统中显示乱码。需要 iconv 做编码 convert，从 GBK 转成 UTF8。

![图 22：以当前编码查看中文文件出现乱码（00:27:23）。](/assets/images/24/0022.webp)

图 22：以当前编码查看中文文件出现乱码（00:27:23）。

现场转换编码并查看文件的命令：

```
iconv -f gbk readme.txt | less
```

![图 23：转换编码后可读的 Windows 98 自述文件（00:27:32）。](/assets/images/24/0023.webp)

图 23：转换编码后可读的 Windows 98 自述文件（00:27:32）。

转换后就是 Win98 自述文件。查看目录树，会发现这些计算机系统概念一直沿用到今天。mount 的完整写法还可以带 \-t，指定文件系统。这里的 /dev/cdrom 是符号链接，后面会讲。
