然后，所以你删除文件的时候，你用的系统调用不是 remove，而是 unlink，对吧，当这个文件有链接的时候，每一个文件都需要有一个引用计数，现在是有三［指板书中三个目录项的例子］，当你用 rm 删除 c\.txt 的时候，这个文件的对象，它的数据其实不能回收的，因为还有别的数据指向它。

![图 40：解除链接与引用计数（00:44:19）。](/assets/images/24/0040.webp)

图 40：解除链接与引用计数（00:44:19）。

对吧，还有别的文件指向它，所以你每一次，虽然你调用的命令是 rm c\.txt，但实际上你调用了 unlink 的系统调用，然后 unlink 的系统调用会把这个链接指针给去掉，并且把它的 reference count 减一，只有当 reference count 减到 0 的时候，这个文件才真正的相当没有人指向它了，它才能被文件系统给回收掉。这是链接的作用。所以你不能用链接来链接目录，不然很容易形成一个环，形成一个环以后它的引用计数就不起作用了。对吧。

引用计数在一个环形的引用的时候，每一个文件都有一个引用，但是它们这个环已经从整个目录树里面 detach 了。
