先只读打开文件，探测文件系统，这是 mount 命令的工作。系统调用要求明确给出文件系统类型，操作系统不负责探测，认为格式不合法就直接拒绝。这里由应用探测，确定是 VFAT。

Agent 在画面中列出的 loop 设备配置顺序；结构参数仅转录可见字段：

```
openat("/dev/loop-control", O_RDWR)
ioctl(3, LOOP_CTL_GET_FREE) = 0
openat("M5-frecov.img", O_RDWR)
openat("/dev/loop0", O_RDWR)
ioctl(4, LOOP_CONFIGURE, {
    fd=3,
    lo_flags=LO_FLAGS_AUTOCLEAR,
    lo_file_name="M5-frecov.img"
}) = 0
```

再分配 loopback device：以读写方式打开 /dev/loop\-control，调用 ioctl，命令是 LOOP\_CTL\_GET\_FREE。之前说“操作系统创建 loopback device”，具体过程就在 Trace 里。第一次 Getfree 可能返回 0，之后返回 1,2,3,4。

失败返回 \-1。可以创建多个 loopback device，每个有唯一编号。返回 0 就能访问 /dev/loop0，返回 1 就是 Loop1。系统里如果没有 Snap 或者什么［听辨不清，00:36:47］，lsblk 可能会显示很多 loop device、loopback device。后面还会绑定镜像文件描述符。

有了 loopback device，就能执行真正的 Mount，把这个块设备的文件系统挂上去。这就是整个系统调用流程，不明白的细节还可以问 AI。
