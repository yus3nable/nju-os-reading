比如 /usr/bin/python，不仅可选 Python3 binary，也能选择不同版本 library。这就是 nix 的思路。通常 apt 修改是 in\-place，install 新版本要卸旧版本，再 run post\-install script。

nix 是 functional package manager，有些只增不减的意味。前面讲 random read、append\-only write，可以构建任意 persistent data structure。修改二叉树时，保留旧树，创建新根，把要修改的路径复制一份，其他指针仍指向原节点。

这样追加就能构造新结构。理论上也能删除东西，但持续增加不会影响已有软件，原环境仍在，随时可以回滚旧版本。
