把初始设备的根挂载，再通过 pivot\_root 系统调用或 switch\_root 命令切换根，这些之前展示过，就得到了目录树。树上自然需要增删改查 API，比如创建、删除、遍历目录。运行 strace mkdir 1，就能查看调用。

课件中的目录操作接口声明；系统类型来自相应头文件：

```
int mkdirat(int dirfd, const char *pathname, mode_t mode);
int unlinkat(int fd, const char *path, int flag);
ssize_t getdents64(int fd, void *dirp, size_t count);
```

这里是 mkdirat，当前目录下创建 1，返回 0。这就是增删改查接口。还有 \*\*/\* 这样的语法糖，可以查找符合通配符的文件。
