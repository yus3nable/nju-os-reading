然后在 Linux 里面更简单了，你插上 U 盘以后，你会发现桌面上可能多了一个目录，然后你双击那个目录，然后就正好是 U 盘的目录，所以 Linux 还很有意思，对吧，它是比如说 Home 下的什么什么下，有个 Desktop，那 Desktop 的话，你 U 盘插进去以后，你 U 盘的对应的那个目录，直接就放上，一下子就放到这个目录上。所以这些其实也都是操作系统完成的，比如说我以 Windows 为例，Windows 其实有很多你们看不见的特征。比如说 Windows 实际上有一个所有操作系统对象的根。

叫 \\，但这个 \\ 你是 cd 不进去的，如果你在 PowerShell 里面 cd \\，你会得到 C 盘的根目录，或者就当前工作盘的一个根目录，但是实际上这个 \\，就 Windows 里面如果你用 API 来访问的话，这个 \\ 就是所有操作系统对象的根。比如说你可以有一个叫\\Device\\HarddiskVolume1。对吧，有一个\\Device\\HarddiskVolume1。然后也可以有一个\\Driver\\Ntfs，它可以用 \\ 来一级一级一级的引用。

所有操作系统 Windows 操作系统里面的对象，然后这里面有好多好多的神奇的东西，比如说有个叫 \\\\，你们可以通过 \\\\ 来访问网络，比如\\\\192\.168\.3\.1，你可以访问另外一台网络上的计算机，\\\\server\\share。然后它会被转移成一个\\Device\\LanmanRedirector\\server\\share。
