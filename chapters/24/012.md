Linux 里，插 U 盘后，桌面可能多出目录，双击就进入 U 盘。比如 Home 下的 Desktop，U 盘对应目录直接出现在里面，由操作系统完成。Windows 还有许多平时看不到的机制，比如所有操作系统对象共有一个根。

它叫 \\，但不能用 cd 进入。在 PowerShell 执行 cd \\，到达的是 C 盘或当前工作盘的根。通过 Windows API 访问时，\\ 才指向操作系统对象根。比如 \\Device\\HarddiskVolume1、\\Driver\\Ntfs，都能用 \\ 逐级引用。

这里还有网络路径。比如 \\\\192\.168\.3\.1、\\\\server\\share，通过 \\\\ 访问网络计算机，最终会转换为 \\Device\\LanmanRedirector\\server\\share。
