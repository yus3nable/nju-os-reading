商人要出售服务，光隔离还不够，还要控制用量。前面的 OSID 只让进程看不到、不能通过 Syscall 访问其他 OSID 的对象，进程仍由原有操作系统实现。让 XV6 通过 vibe code 加 Namespace，调度器并没有改，仍从全部进程中轮流选取，进程看起来公平执行。有了 OSID，需求变成按组计算 cost，比如每组一个 CPU COST，组内进程每消耗一单位时间，就累计到本组 CPU COST；另一组也单独累计。

这样就能控制用量。比如把一个 CPU 均分成十份，或限制最多用 CPU 的 20%；十个组按 CPU share 均分，才能实际虚拟化资源。
