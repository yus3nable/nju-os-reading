我可以 chroot 到一个这样，我可能需要 sudo，好，我现在在这个地方，然后我现在可以，可以 chroot 到 /tmp/vibe，试一下，好，然后你看，它给我失败了，为什么呢？因为它试图，运行一个 shell，我 chroot 完了以后，它运行一个 shell。但是那个，根文件系统已经没有了，我的这个目标里面，就没有/bin/bash 了。

![图 38：chroot /tmp/vibe 失败：缺少 /bin/bash（01:03:19）。](/assets/images/29/0038.webp)

图 38：chroot /tmp/vibe 失败：缺少 /bin/bash（01:03:19）。

［现场 chroot 命令与失败结果。］

```
root@rpi500:/tmp/vibe# chroot /tmp/vibe
chroot: failed to run command '/bin/bash': No such file or directory
```

所以你需要为它，构建一个完整的，比如说有/bin/bash，有/home，有完整的东西的，一个文件系统，然后你才可以，可以做这样的，chroot。
