讲一个黄金时代，到今天其实我们已经不太，不太提起那段历史了，叫虚拟机，你们有没有同学用过那个 vmware，你们现在已经不会去，比如说大学，入学以后，说我们要学 linux 了，要学 linux，现在的标准答案应该是，装一个 windows subsystem for linux。对吧，你可以直接在 windows 的应用商店里面，装一个 ubuntu。然后你就可以直接获得一个 linux 体验，在 windows terminal 里面，得到几乎完整的 linux 体验。

好，但是这个不是我，比如说我上学的时候，那个标准版本的答案，我上学的时候会装一个 vmware，这样的软件，然后 vmware 就可以在你的 windows 里面，模拟出一个，比如说你是 x86，你会模拟出一个完整的 x86 的裸机，一个 bare metal，一个完全的裸机。然后这个裸机，你可以，比如说从网上，下一个 linux 的光盘镜像。然后你把这个光盘镜像插入，假装插入到虚拟机里。然后它就会像 firmware，它会有 firmware，那个 firmware 开始执行。

然后你可以在里面装一个在 windows 里面装一个 windows，或者在 windows 里面装一个 linux，并且它的性能其实还是相当好，可以过得去的。
