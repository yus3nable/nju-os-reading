今天已经很少提起那段历史。有没有同学用过 vmware？现在入学后学 linux，标准办法应该是 windows subsystem for linux，在 windows 应用商店安装 ubuntu，打开 windows terminal 就能获得几乎完整的 linux 体验。

我上学时的办法是装 vmware，在 windows 里模拟完整的 x86 裸机，bare metal。再从网上下载 linux 光盘镜像，假装插入虚拟机，里面的 firmware 就开始执行，可以在 windows 里面装 windows 或 linux，性能也相当好，过得去。
