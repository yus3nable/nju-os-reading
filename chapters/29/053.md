所以你可以看到人类的历史就是这样，大家做的那个决定，在那个时间点，做的那个决定，未必就是全局最优的决定，比如说 PID，在 UNIX 时代，是一个非常好的设计，简单干净，但是当你数据中心里面，有无穷多的进程的时候，它就变成了一个leaky abstraction。然后我们的虚拟化也是的，这样的，就在操作系统里面，为每一个对象，增加一个 OS ID，是有非常大好处的，对于黑心资本家来说，是绝对愿意要的，就是它是极致的性能，你只给每一个对象。加了四个字节的一个 field。

然后你在写代码的时候，你需要考虑这个隔离，然后你就在一个操作系统，共享的资源池里面，共享出了所有的操作系统，你要这样想，如果你开一个虚拟机，你要说你给它分配，4GB 还是 8GB 的内存，如果你是这样的，所有的对象，它的 allocation 都是共享的，对吧，你想你们实现了一个memory allocator。然后这个 memory allocator，所有的，就不管是 OS ID 等于 1，还是 OS ID 等于 2，它想要分配一个对象。想要分配一个进程的对象。

它都可以去同一个池子里面，对吧，同一个池子里面申请，只是到它申请过来以后，它再给那个对象上面，打一个 OK，OS ID 等于1，还是 OS ID 等于 2，好，就是这样，所以这是一个简单的，不能再简单的想法，甚至，也不是它第一个提出来。
