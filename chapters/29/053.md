历史上某个时间点的决定，未必全局最优。PID 在 UNIX 时代简单、干净，但数据中心里有海量进程，就成了 leaky abstraction。虚拟化也是如此。给每个操作系统对象增加 OS ID，有很大好处，黑心资本家会愿意要：只多四字节 field，就能有极致性能。

写代码时考虑隔离，就能从一个操作系统共享的资源池中划出多个系统。虚拟机通常要预先分配 4GB 或 8GB 内存，这里所有对象的 allocation 都共享。比如 memory allocator，无论 OS ID 是 1 还是 2，要分配对象、进程，都到同一个池子申请，随后给对象标记 OS ID 等于 1 或 2。想法很简单，也早已有人提出。
