指令中会留一个 placeholder，四个字节的 0。程序能编译但不能链接，因为对应外部符号还未知。比如加上 mov R1、EBX，再有 mov EBX、R1，R1 也可能通过 memory dereference 访问。这三条指令未必刚好十二个字节，但无论多长，都可以复制过来，再根据二进制文件中的 relocation 重定位。比如要加十六，模板中该做 relocation 的地方就 patch 为实际立即数十六，其他部分保留指令二进制序列，完成轻量级编译。第一次预编译时，先把 C 代码编成本地 native 的 arm 或 x86 汇编片段。它用来复制到 basic block 的编译结果中，再重定位、patch 立即数。得到译码后的 basic block 后，每条指令只需一次 memory copy 就完成编译，实际编译已经提前做过。复制后只要 patch 一到两个数字，最多一个数字，就能写出指令行为，模拟效率很高。
