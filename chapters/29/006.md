就是如果你每一个 basic block 都要经过一次外部的 GCC 的调用，这个性能你是不能接受的，对吧，你肯定不愿意每一个 basic block，甚至这个 basic block 是只运行一次，比如说你这个程序启动的时候，那个启动部分的代码，这个代码它只执行一次，它就这辈子再也不会执行了，但你还需要为它绕一次 GCC 可能就要 100 毫秒，100 毫秒再回来。所以你不愿意为了一个 basic block 做这件事。
