寄存器访问的宏展开为 CPU state 的 register，便得到合法 C 代码。把它交给 GCC，编译成 \.so，再用 dlopen 加载到地址空间，就像你们做过的实验。加载后代码进来，符号正确解析，可能还要处理 relocation，因为 CPU state 的位置只有进程运行时才知道。relocation 完成后，直接调用这个 Just\-in\-time 函数，就执行了 basic block。它可以是 highly optimized code，比如立即数已硬编码进指令，省去了每次 decode 后的 load 操作。

这种代码无须再从 decode 结果里取出立即数。这种 Just\-in\-time 编译的性能会好很多。学过操作系统，就能实现，但有没有觉得哪里不太对？
