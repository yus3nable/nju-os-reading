生成一个 C 程序，把 NEMU 中对应的 C 代码复制出来。比如已知指令是把 1 mov 到 EAX，它的行为就是 register of EAX 等于 1，再有 register of EBX 等于 2。解释执行时，每次都需要访问 CPU state 指针。

![图 7：板书：两条 mov 对寄存器状态的效果（00:03:41）。](/assets/images/29/0007.webp)

图 7：板书：两条 mov 对寄存器状态的效果（00:03:41）。

［板书中的两次寄存器赋值，是基本块对应的状态变化。］

```
R(EAX) = 1;
R(EBX) = 2;
```

通过该指针找到 eax，再从 decode 结果里找出立即数 1，完成赋值。这个基本块也可以写成一个 Just\-in\-time function。
