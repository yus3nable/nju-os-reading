Linux 进程要改地址空间，必须通过 mmap 等系统调用。劫持这些调用，就能模拟进程，就像 Windows Subsystem for Linux。

![图 24：板书：Ring 0 的 cli 与死循环（00:42:44）。](/assets/images/29/0024.webp)

图 24：板书：Ring 0 的 cli 与死循环（00:42:44）。

内核则能直接修改 CR3。页表是内存中的数据结构，虚拟内存像 VR 眼镜，配置虚拟地址到物理地址的映射。比如 Virtual Frame Number 1234 对应 Physical Frame Number 123，可能只有三页，每页有读写执行权限。一、二、三级页表，以及两级页表的第一级、第二级索引，都是 PTE Entry 等数据结构，计算机系统基础讲过。内核能直接用 load、store 修改内存里的页表，改变某个地址，映射就变了。

这些修改不会立即生效，还要把某个地址 mov 到 CR3，相当于先调整 VR 眼镜设置，再换上新的 VR 眼镜。这些操作有破坏性，不能直接放到 CPU 执行，必须模拟。
