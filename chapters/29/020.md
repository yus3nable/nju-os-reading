［课件中的 Y combinator 与阶乘。］

```
def Y(f):
    def wrapper(*args):
        return f(wrapper)(*args)
    return wrapper

factorial = Y(lambda f: lambda n: 1 if n < 2 else n * f(n - 1))
```
