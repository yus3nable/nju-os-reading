跟你们的支付宝，支付宝是一样的，支付宝是说我先用 if 判断，判断一个条件是不是满足，然后这个条件如果满足的话，我就可以做了，对吧，如果我身上的余额大于，大于那么多钱，我要扣掉的钱，我就可以把这个钱扣掉了，就像这个如果我的这个指针不是空，我就可以往这个指针里面写东西，结果，哪怕是你上着锁，你有一个有一个别人把资源释放掉了，你这个就是一个 crash。然后这样的 ABA 型的问题，其实很多，它不仅出现在，像，像这种 data race 的情况，还有什么呢？你可以 use\-after\-free。

你有另外一个线程，比如说你把这个指针，交给别的线程了，然后别的线程，或者说你的整个系统认为，这个指针再也不会访问了，它就把它安全的 free 掉了，free 掉了以后，这里面就变成 use\-after\-free，它去读一个读一个已经 free 的内存。

检查与使用 proc\_info 的片段，其余语句省略：

```
if (thd->proc_info)
{
  fputs(thd->proc_info, ...);
}
```

这是非常危险的，因为你可能会读到不属于你的数据，你就可能有隐私泄露，内核里面有很多这种，use\-after\-free 的，这种严重的安全，安全漏洞，当然如果你 free 的时候，同时把这个指针，清掉了。比如说改成 NULL 了。那这个程序也可能，发生一个crash，这样的问题，不仅在你的程序里会发生，在你的系统里面，也会发生。
