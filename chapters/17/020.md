今天讲实际问题，再讲一个伤人性命的并发 bug。我们说 race condition 会造成 undefined behavior，含义与 C 里的 Undefined Behavior 有些不同。这个故事叫 killed by a machine：大概在 1985 到 1987 年，能发射高能 X 射线的放射治疗仪 Therac\-25 发生了事故。

![图 50：Therac\-25：课堂引入的放射治疗事故（01:02:46）。](/assets/images/17/0050.webp)

图 50：Therac\-25：课堂引入的放射治疗事故（01:02:46）。

它用多束光聚焦，可以精准选择身体内部的位置，在不伤及其他组织细胞时把目标位置烧穿。这台治疗仪有一个事件驱动的并发 bug，导致至少六个人死亡，是很有名的例子。图不太好，我来说明：Therac\-25 有两种模式，低剂量照射模式先帮助定位。

![图 51：Electron/X\-Ray 模式、beam flattener 与安全断言（01:03:26）。](/assets/images/17/0051.webp)

图 51：Electron/X\-Ray 模式、beam flattener 与安全断言（01:03:26）。

```
assert mode in [Electron(Low), XRay(High)]
assert beam_flattener in [On, Off]
assert not (mode == XRay(High) and beam_flattener == Off)
```

低剂量可以拍片，高剂量模式用于实际灼烧。高剂量时有一个 beam flattener，我把它叫反射镜，但不确定具体是什么。它通过机械移动到射线源下面，控制进入人体的辐射剂量。如果没有这个部件，大剂量射线直接照射人体，患者说会瞬间感到很强的灼烧感。照射可能持续不久，却因剂量过大导致逐渐死亡。
