Python 可以在只创建一个线程时维护多个执行流，语法特性叫 generator。这里创建所谓一百万个线程，用 T\_worker 定义。它确实像线程，有从 I 等于 0 开始、不断 I 等于 I 加 1 的死循环。

![图 18：generator\.py：一百万个 generator 与随机调度循环（00:26:29）。](/assets/images/19/0018.webp)

图 18：generator\.py：一百万个 generator 与随机调度循环（00:26:29）。

generator\.py 的画面代码；使用 Python generator 与随机调度。

```
import random
import resource

THREADS = 1_000_000

def T_worker(name):
    i = 0
    while (i := i + 1):
        yield f"[{name}] i = {i}"

threads = [T_worker(i) for i in range(THREADS)]
count = 0
while count < 10_000_000:
    current = random.choice(threads)
    res = current.send(None)
    print(res)
    count += 1
```

如果顺序程序中写的是 Print I，调用 T\_worker 后永远不会返回，一次只能执行一个。但第九行用了 yield，每次交出线程名和 I 的值。第十一行创建一百万个执行流。

调用 T\_worker 时只创建，还没运行。之后做千万次调度，每次 random choice 一个 thread 对象，记作 current，再 current\.send 告诉它可以跑。send 类似函数调用，将控制流交给某个 T\_worker。

它执行第七、第八行，到第九行 yield 时暂存当前函数状态，再返回调用者。
