现场 fetchData 代码；请求地址保留画面中的字面量 \{token\}，未改写成变量插值。

```
async function fetchData(token) {
  const response = await fetch(
    `/api/submissions/?token={token}`
  )
  return response.json()
}
await Promise.all([fetchData('1234'), fetchData('5678')])
```

async 定义 asynchronous 异步函数，编译器包装它，创建并 return promise。fetchData 就成了返回 promise 的函数，通常可以通过 await 使用它。

await 1、await 2、await 3 也可以。非 promise 值直接返回，例如 await 1 得到 1，await "hello" 得到 hello；也能 await Promise\.、任意 promise，以及 await fetchData，等待异步函数完成。
