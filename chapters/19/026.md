现场 fetchData 代码；请求地址保留画面中的字面量 \{token\}，未改写成变量插值。

```
async function fetchData(token) {
  const response = await fetch(
    `/api/submissions/?token={token}`
  )
  return response.json()
}
await Promise.all([fetchData('1234'), fetchData('5678')])
```

这是一个 asynchronous 的异步的函数，然后所谓的异步的函数，我们的编译器会干什么呢？会把这个函数包装一下，它会创建一个新的 promise，就这个函数就不再是，当我实现一个 async 的时候，它就会做一个 return promise。然后它会把它改写成是fetchData，相当于 function，它会返回一个 promise。然后这个时候这个 fetchData 就不能直接，就直接用起，一般你就不直接用了，而是你可以 await。你可以 await 一个 promise 点。

这样的话，我就可以 await 1，await 2，await 3，当然这也是可以的，如果 await 的东西不是 promise 的话，你可以在网页里面直接看到比如说我可以直接 await 1，它就会返回 1。对吧，我 await "hello"，它就会返回 hello，我可以 await Promise\.,await 任何一个 promise 都可以。所以我也可以 fetchData。对吧。我可以 await fetchData，我可以 await 异步完成的函数完成。
