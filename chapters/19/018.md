Go 主函数片段；依赖 worker、nthread、sync 等已有定义，其余初始化省略。

```
var wg sync.WaitGroup
for i := 0; i < nthread; i++ {
    wg.Add(1)
    go worker(i, nthread, &wg)
}
done := make(chan struct{})
go func() { wg.Wait(); close(done) }()
```

如果计算图创建很轻，无需考虑开销，想并行十个任务就 go 十份。for 循环 i = 0、i &lt; n、i\+\+ 中 go worker 即可。还可以 go 一个 monitor，通过管道通信；主线程也是 Goroutine，根据收到的消息处理。

select 的画面片段；依赖 ticker、done、renderPreview 与 writePNG，其他输出语句省略。

```
for {
    select {
    case <-ticker.C:
        fmt.Print("\033[H")
        renderPreview()
    case <-done:
        writePNG("mandelbrot.png")
        return
    }
}
```

收到的是时间 tick，或任务 done。最后一个线程结束时收到 done，就写 mandelbrot\.png。用终端演示一下。
