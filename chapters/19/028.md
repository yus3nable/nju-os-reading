因此模型灵活，能做很多事情。新标准 javascript 甚至可用 javascript 写的 transpiler 转成老版本，比如将 async/await 翻译为旧写法，兼容所有浏览器。上面逐渐有了完整生态：早期 Angular、Bootstrap，后来 express、next、nest。人们发现网页好用，又用 electron 把网页变成桌面应用，出现 vscode；再用类似 react、网页的方式写命令行应用，产生 ink。

Claude Code 界面就用 Ink。还有人想在浏览器中解释执行汇编、机器指令，从而运行 C、C\+\+，与 JavaScript 互相调用。这种发展像操作系统：从 Linux 系统调用 API 到 LibC、高级语言 C\+\+，再到 JavaScript。

浏览器、JavaScript 抽象上长出了巨大应用生态，既能连接 C、C\+\+，也有画图的 Mermaid、TensorFlow\.js、Three\.js。AI 熟悉 Three.js，可以帮忙构建 3D 应用。学 JavaScript 遇到 async、await 等困难时，可以重走并发机制发明、治理的过程。

从线程、Data Race，到互斥、同步，再考虑语言设计者和使用者怎样方便地描述计算图。今天 Go 与 JavaScript 代表两条路线：轻量化线程，以及在语言中描述计算图。
