课件中的 jQuery 用法；依赖已加载的 jQuery。

```
$(document).ready(function(){ /* code */ });
$("#myElement").text("新内容").css("color", "red");
```

这项技术后来叫 Ajax，Asynchronous JavaScript and XML。今天网页和大模型 API 传输的通常是 JSON，当时则用 XML，因为 Java 后端广泛使用它；从远程 HTTP 服务器取回 XML。

这让网页能后台刷新。HTTP1\.0 时代，网页完全静态，加载完就固定；点超链接会从零加载另一页。异步 XMLHTTP request API 加上可修改文档元素的 JavaScript，改变了这一点，就像前面的浮动框。

修改浮动框绝对位置 XY，它就移动；也可以添加或删除元素。一方面能向后端不断请求，询问用户请求是否结束、后台是什么状态；另一方面能改变图形界面，理论上应用程序能做的网页也能做。后来又有好用的 API。

例如 JQuery 的 Dollar，是 Dom query language。现在浏览器也内置类似 document\.querySelector 的能力。document\.ready 可以注册文档加载后运行的代码，Dollar 可选中特定 ID、类型的 element；整个界面就是一棵树。

DOM tree 中，可以用类似查询字符串的方式选择一个或多个节点，修改样式、文本，乃至塞入新 HTML，浏览器负责渲染。这样就能更新界面，理论上可以做任何事，包括把刚才的旧式页面改成现代页面。
