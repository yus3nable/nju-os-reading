并发有许多 subtle 的地方，reason about 这类程序是 NP\-complete 的。只有一个 producer、一个 consumer 时，行为确实正确，双方来回唤醒。

![图 41：pc\-cv\.c 中的 if 等待和 cond\_signal（00:50:32）。](/assets/images/15/0041.webp)

```
void T_consume() {
    while (1) {
        mutex_lock(&lk);
        if (!CAN_CONSUME) {
            cond_wait(&cv, &lk);
        }
        printf(")");
        depth--;
        cond_signal(&cv);
        mutex_unlock(&lk);
    }
}
```

有两对就出现复杂行为，连我刚才也弄错了。记住通用方法：始终用 while 循环等待同步条件。

循环退出，就能断言条件满足且持有锁，此时安全。状态改变、可能满足其他等待条件时，broadcast 唤醒所有人，同样安全。两者结合就能实现各种同步。为什么推荐这种方法？
