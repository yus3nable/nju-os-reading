因为实际会遇到各种奇怪的同步问题。这里是我曾在期中测验出过的题，来自 LeetCode 组装水分子的原题：有许多释放氢原子的线程，也有释放氧原子的线程。两个氢、一个氧组合成水分子。

每个线程像一台挤出原子的机器，顺序可以是氢氢氧、氧氢氢或 HOH。但一组中已有两个 H，就不能再放氢，否则不是水。也能用桌子模型理解：两类物品苹果、香蕉，各有线程负责放。

![图 45：两个氢和一个氧：苹果、香蕉的同步条件（00:52:46）。](/assets/images/15/0045.webp)

图 45：两个氢和一个氧：苹果、香蕉的同步条件（00:52:46）。

桌上每凑齐两个苹果、一个香蕉，就一起取走，再开始下一组。我把原题改得更麻烦：三类线程分别打印左尖括号、右尖括号和下划线，用 ASCII code 画朝左、朝右的鱼，要求用条件变量同步。下节课讲的信号量实现生产者消费者比较容易，面对人为构造的任意同步问题却很困难。条件变量只需回答，何时能打印左尖括号、右尖括号、下划线？

需要维护全局状态。画出状态机，问题就简单了。从初始 A 打左尖括号到 B，一旦这样开始，就必须完成一条朝左的鱼。

![图 46：fish\.c：字符与状态之间的转换规则（00:54:43）。](/assets/images/15/0046.webp)

图 46：fish\.c：字符与状态之间的转换规则（00:54:43）。

```
enum { A = 1, B, C, D, E, F, };
struct rule {
    int from, ch, to;
} rules[] = {
    {A, '<', B},
    {B, '>', C},
    {C, '<', D},
    {A, '>', E},
    {E, '<', F},
    {F, '>', D},
    {D, '_', A},
};
int current = A, quota = 1;
```

A 到 B 后，打右尖括号到 C，再打左尖括号到 D，形成朝左的鱼。A 若先打右尖括号，就到 E，再左尖括号、右尖括号，沿 AEFD 形成朝右的鱼。ABCD 是朝左，AEFD 是朝右；最后 D 打下划线回 A。处于 A 时允许不确定选择。

打左、右尖括号的线程都能被选中，交给操作系统选择，相当于各二分之一概率决定朝向。一旦选定，就必须按确定顺序打印，到了 D 再回到起点。

在程序中维护这个状态机即可。每次打印字符前，套用同步模板。

![图 48：can\_print 与 fish\_before：状态允许且 quota &gt; 0（00:56:07）。](/assets/images/15/0048.webp)

图 48：can\_print 与 fish\_before：状态允许且 quota &gt; 0（00:56:07）。

```
static int can_print(char ch) {
    return next(ch) != 0 && quota > 0;
}

void fish_before(char ch) {
    mutex_lock(&lk);
    while (!can_print(ch)) {
        cond_wait(&cv, &lk);
    }
    quota--;
    mutex_unlock(&lk);
}
```

条件未满足就 cond\_wait。允许进入后，还必须保证任意时刻只有一个线程打印，所以用 quota 充当许可，初始为 1，进入时减减。fish\_before 返回后才能打印，随后 fish\_after 更新状态机的 current。

![图 49：fish\_after 更新 quota 和 current 后广播（00:56:41）。](/assets/images/15/0049.webp)

图 49：fish\_after 更新 quota 和 current 后广播（00:56:41）。

```
void fish_after(char ch) {
    mutex_lock(&lk);
    quota++;
    current = next(ch);
    assert(current);
    cond_broadcast(&cv);
    mutex_unlock(&lk);
}
```

令 current 等于 next(ch)。例如 a 打左括号到 b，打右括号到 e，再 broadcast，问题就解决了。条件是当前线程能打印自己的字符：a 可打左、右括号，b 只能打右括号，c 只能打左括号，d 只能打下划线。

还要保证当前无人打印，也就是下一个允许字符正好由自己打印，且打印者只有一个。条件想清楚，问题就能直接解决。打印 1000 个，确实看到符合要求的鱼。

这就是条件变量的通用同步方式。生产者消费者、H2O 两个苹果一个香蕉，都只需记录苹果、香蕉数量，写出条件。更奇怪的题目也一样：作为线程、作为人，何时能继续？把这个条件写进模板，系统就能正确实现。
