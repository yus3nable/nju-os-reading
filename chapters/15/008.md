还有个有趣的想法：everything is code，content is code，理论上 coding agent 就能生成世界上的一切。能否用程序写音乐、创作？可以，也有很多人尝试。例如 LilyPond，可以用代码写乐谱。

乐谱还能播放。我直接让 AI 通过合成波形生成音源，完全没管代码，都是 vibe code 出来的。notes 中有多个声音文件，例如 C4，听着还不错。

![图 15：notes 目录中的 C4 合成音源（00:20:08）。](/assets/images/15/0015.webp)

图 15：notes 目录中的 C4 合成音源（00:20:08）。

C7 的高音不太像真实乐器，不过也算电子乐。若同步正确，不释放拍子就没有声音；按一次回车，大家开始工作，再停下，所有线程又等待。演奏不太齐，因为树莓派速度较慢、处理器也少，可能受到调度影响。

![图 16：每按一次回车，指挥释放一拍（00:20:46）。](/assets/images/15/0016.webp)

图 16：每按一次回车，指挥释放一拍（00:20:46）。

所以这里能听出不齐；在更多、更快处理器的 PC 上，感受不到这点延迟，就会觉得齐。
