```
import sys

limit = int(sys.argv[1])
count, n = 0, 65536
while True:
    for ch in sys.stdin.read(n):
        if ch == "(": count += 1
        if ch == ")": count -= 1
        assert 0 <= count <= limit
```

然后我看到左括号就加 1，看到右括号就减 1，然后我要判定的是，我在任何时候，我的桌上的苹果的数量对吧，都是正常的，就这样的一个简单的 check 就可以帮我们检查，对吧，至少我可以让它运行很长的时间 check\.py，运行很长时间，它都没有出问题，那我可以一定程度上认为这个程序实现的是有一定正确性的，如果我去用更小的，对吧，我说桌上只有一个苹果，检查 check\.py 1 的话，它会给我报错，这就是生产者消费者。
