再抄一遍这个重要模板，期末考试值 20 分：先加锁，lock、unlock 配对；等某件事发生，就 while (\!condition)，调用 cond\_wait。它给人的效果像整个区域都受同一把锁保护、是 atomic 的。中间虽然会解锁，但返回前一定重新 acquire、lock。

获得锁后才能从 cond\_wait 返回。这里必须用 while，换成 if 很可能不对，因为返回后要再次检查 condition。此时已持锁，若条件仍未满足，就再次睡眠。例如收到不相关的唤醒，或者两个线程竞争同一件事。

等待条件若是桌上有苹果，想拿走它，唤醒后苹果可能已被别人拿走，必须继续等。若条件满足，走出循环时可以保证两件事：当前持有这把锁，且 condition 满足。后者来自 while 的语义。

外部加锁和条件变量一起保证当前持锁，于是得到一个可以理解的全局同步状态：持有锁的同时，同步条件满足。这就实现了同步。

```
while (!(current_beat < conductor_beat)) {
    assert(!(current_beat < conductor_beat));
    cond_wait(&cv, &lk);
}
assert(current_beat < conductor_beat);
```

加上这两个 assert：进入 while 时，已持锁、同步条件未满足，随后原子地释放锁并睡眠，让别人有机会改变状态；退出循环时，可以 assert 条件满足。再编译运行，不按回车就不动，按回车后正确同步。

```

// 线程 2
mutex_lock(&lk);
while (!sync_cond()) {
    cond_wait(&cv, &lk);
}
// ... 执行后续操作
mutex_unlock(&lk);
```
