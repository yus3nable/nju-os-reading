最终低权限用户却获得 root shell，这个程序就可以被利用。这里我模拟了一些古早的编译器行为。现在有 stack protector，也有栈不可执行、位置无关代码、地址空间随机化等机制。栈和代码加载到随机地址，都会让攻击很困难。

［现场 make 输出的编译命令。］

```
x86_64-linux-gnu-gcc -static -fno-stack-protector \
  -z execstack -no-pie -g -m64 -o vulnerable vulnerable.c
```

这里有一个 exploit，可以让 AI 解释这段奇怪代码。现在栈默认不可执行，要用编译选项打开，才比较容易做这种攻击。
