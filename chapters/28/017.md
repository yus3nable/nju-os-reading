可以想象世界上有很多狗，共同维护这个链。任何狗想向数据结构 append，就把一个独一无二的随机骨头扔到随机位置，再向全世界广播。其他狗听到后，只能随机去找，逐处检查有没有骨头，one way function 保证它们没法用其他办法。

基本上，谁花时间多，谁就能捡到。one way function 还确保捡到的骨头对应足够小的 hash value。这叫 proof of work：证明投入了时间，找到了骨头。找到后，按协议记录在哪里找到、骨头是什么，所有内容都签名。借助 one way function 和 proof of work，其他人都能验证这是合法、正确的 append。
