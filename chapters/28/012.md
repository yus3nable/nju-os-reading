这个函数逆向却很难算。比如课上用过的 sha1sum，可以把任何文件或字符串变成另一个数字。它与 Java、Python standard library 的 hash function 有区别。后者更多是把字符串当成 256 进制数，再取模等。

这样末尾字母从 A 变 B，hash value 就加 1，比较 predictable。密码学 hash function，比如 MD5、SHA\-256，首先要求很难逆向：fx 等于 y 时，正向容易，像 sha1sum 可以处理很大的文件；但给定 y，比如一串随机数字，求一个 x，恰好满足 fx 等于 y，就很难。同时，也很难找到两个输入碰撞到同一个 hash value，几乎只能暴力随机尝试。f 虽然是 deterministic 函数，输出却看起来像随机数，x 对应一个随机的 y。
