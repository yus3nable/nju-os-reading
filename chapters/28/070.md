如果保护不到位，就可能被偷 key。有了 repository 权限，攻击者便能长期潜伏。Axios 攻击先创建一个恶意 NPM package，名字 plain\-crypto\-js 很有迷惑性，看起来像加密解密库，提供一些可以 vibe code 出来的功能，里面隐藏 malicious 行为。这次手法比较低劣，包 release 大概一分钟、一两分钟，就被安全扫描机构发现，阻断较及时。它利用 NPM install hook，每次安装时会运行脚本。这本来很正常，因为安装可能需要编译生成内容，apt install 也有 install hook。
