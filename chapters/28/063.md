历史上的经典文章里，有人用天线隔着三层石膏板、十米距离，窃取射线管显示器的图像。做任何事都会产生噪音。刚才用程序观测 timing side effect，也可以用物理设备，比如天线观测：显示器发射电子，少量穿过墙壁，传感器感知后，就能还原屏幕图像。还可以观测 CPU 的电磁信号，窃取 private key。

当时的 Proof of Concept 藏在一个饼里。想象你在这里打开电脑，开始 SSH 登录，旁边同学悄悄放一个饼，就能偷走 private key。这叫 physical key extraction。还有更直接的办法：眼下内存是 volatile memory。前面提过，未来 nonvolatile memory 可能成为主流。
