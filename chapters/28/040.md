可以像构建虚拟世界一样，把禁止访问的对象从它眼中抹去，让它永远看不到其他部分，类似虚拟化。这是 access control 的一种思路。顺着权限表，还能想到直接写 access control function，可以针对用户，也可以针对程序。监控的程序或用户每次通过操作系统 API 访问对象时，都额外调用一个 function，甚至把它编译进内核，由这段程序决定接受还是拒绝。这种机制也存在。
