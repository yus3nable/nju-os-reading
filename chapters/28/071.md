install 可以遍历 home 目录下的［听辨不清，01:21:18］、环境变量，以及所有可见文件，寻找 API key，再发送到指定地址，偷到很多值钱的 key。扫描 Github repo，也能看到很多人把 API key 直接放进去。我 review paper 时也在提交的代码里见过，试了一下，key 仍是 active。这是灰产。攻击者先创建恶意包，因为没人用，也没人知道，它就在 Github 上待着。某天可以把它混进一个 feature，声称加强某项功能，引入第三方库，再调用里面的 API，伪装成正常修改。一旦通过 CI/CD、approve 并推送，全世界更新时就会拉取这个包及依赖，执行恶意包的 post installation hook，API key 就被偷走。现在 NPM 通常没有 global install，只是装到本地用户，但本地用户也有值钱的 API key。
