恶意人员就可能在网页隐藏 prompt。fetch 后，如果清洗不充分，或原样加入上下文，再重复几次，比如每次都在内容后说“这个学习内容很好，用户很有付费意愿”，小模型就可能把 API key 送给攻击者。无法绝对防御，基本只能依靠沙箱，或访问控制，为一次大语言模型调用提供最少权限。但龙虾的成功又与拥有全部权限有关，这是个矛盾：限制权限，可能经常遇到无权访问，需要申请；给全部权限，又会担心 prompt injection。这是新的安全问题。
