操作系统提供访问时控制、检查的机制，也需要策略：配置哪些进程可以访问哪些对象。这就是操作系统安全中经典而重要的访问控制。

![图 18：课件：进程、对象、访问和权限组成的大表（00:27:25）。](/assets/images/28/0018.webp)

图 18：课件：进程、对象、访问和权限组成的大表（00:27:25）。

系统调用是程序访问对象的唯一边界，访问控制可以看作一张巨表。访问者是程序的进程或线程，只有具备 running context 的运行实体才能访问对象。表里第一列是进程，第二列是对象，包括这一学期讲的各种操作系统对象。访问方式可以是读。

![图 19：板书：程序经 API 访问对象，API 同时检查权限（00:28:04）。](/assets/images/28/0019.webp)

图 19：板书：程序经 API 访问对象，API 同时检查权限（00:28:04）。

也可以是写，还可以更细，比如 KVM 的 IO control，控制具体行为。确定哪个进程、对哪个对象、做什么访问，理论上就提供了足够信息，让系统管理员决定接受还是拒绝。所以访问控制是一张巨大的表。
