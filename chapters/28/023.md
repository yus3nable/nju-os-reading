但你可以看到是，操作系统确实提供了这样的一个机制，它有两个，一个是机制，访问时候的控制和检查，还有一个是策略，你需要为你的系统配置，谁哪些进程，可以访问哪些对象，所以这个就是操作系统安全里面，最重要的一个也是最经典的访问控制，就是内容叫访问控制，什么是访问控制呢？

![图 18：课件：进程、对象、访问和权限组成的大表（00:27:25）。](/assets/images/28/0018.webp)

图 18：课件：进程、对象、访问和权限组成的大表（00:27:25）。

就是因为系统调用，是程序访问对象的唯一的边界，所以本质上，访问控制就是一张巨大无比的表，访问对象的实体是程序，是进程或者线程，对吧，进程或者是线程，是一段，可以运，只有运行，只有 running context 的东西，它才可以访问对象。然后那这个表里面的第一列就是进程，第二列就是对象，操作系统里面可以有各种各样的对象。对吧，就是我花了一整个学期，跟大家讲的，各种各样奇奇怪怪的对象。然后操作系统，应用程序对对象，它可以有访问，可以有读。

![图 19：板书：程序经 API 访问对象，API 同时检查权限（00:28:04）。](/assets/images/28/0019.webp)

图 19：板书：程序经 API 访问对象，API 同时检查权限（00:28:04）。

可以有写，然后可能有更细的，比如说我对一个 KVM 那个 IO control，那我可以控制它的，非常细致的行为，当然行为，访问的行为可以读，可以写，然后以及，当你确定了哪一个进程，哪一个对象，做的什么访问的时候，其实，你作为一个人，你就知道这件事情是可以，还是不可以了。对吧，你作为这个系统的管理员，理论上说，这就提供了足够的信息，让你决定应该接受这次访问，还是不接受这次访问。所以，访问控制就是一张巨大无比的表。
