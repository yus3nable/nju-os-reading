程序还可能存在时间复杂性漏洞，有一种攻击叫 Algorithmic Complexity Attack，算法复杂性攻击。比如 Hash Table 有很多 slot，字符串 Hello 经过 Hash Function，被送到某个 slot。平均而言，Hash Operation 是 O(1)，数据均匀分布在 Hash Table 里。但如果精心构造很多字符串，都经 Hash Function 映射到同一个地址，无论用开放寻址还是链表，Hash Table 都会退化成线性时间的数据结构。一个办法是换成二叉树等 worst case 比线性好的结构，受到攻击也不至于那么糟。后来 Standard Library 应该做过这种调整，数据大到一定程度就换成树。这个漏洞很早就有，后来才修。比如攻击 Apache，像刚才对 DeepSeek 的攻击，这类攻击不需要一万台肉机。
