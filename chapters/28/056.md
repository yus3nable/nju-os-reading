［课件片段；i、correct\_pass 和省略部分依赖原上下文。］

```
int check_password(__user char *given_pass) {
  /* ... */
  for (i = 0; i <= strlen(correct_pass); i++)
    if (correct_pass[i] != given_pass[i]) {
      sleep(3);
      return EACCESS; // access denied
    }
  return 0;
}
```

比如这个密码是 1234，后面还有 \\0。用户空间指针指向给出的 password，比如 4567。先比较 correct\_pass 的 0 和 given\_pass 的 0，1 不等于 4，比较结果不一致。

![图 53：板书：内核密码与用户提供的密码（01:03:02）。](/assets/images/28/0053.webp)

图 53：板书：内核密码与用户提供的密码（01:03:02）。

比较结果不一致时，就睡三秒，再返回 access denied。sleep 三秒还能防止不停尝试密码。但操作系统的各种组件都能相互关联，API 只允许用户提供 password，无法通过这个 API 做其他事。
