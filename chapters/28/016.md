大致知道有一种神奇函数，能实现无人可破坏的完整性和机密性，就可以继续看它能用来做什么。它可以实现一个神奇的数据结构。

又是 append only，数据结构课的含金量还在上升。如果有一个每次能 append 字符串的 append only 数据结构，由全世界共同维护共识，就可以用它记账。虽然叫 blockchain，区块链，可以把每个块理解为字符串，对它计算 hash，也就是用刚才的 one way function 计算所有前缀的 hash，确保每个块都签过名。全球共同维护唯一一份 append only 数据结构。实际实现用的是树状结构，二叉树可以快速维护全部前缀 hash，这些细节不重要。
