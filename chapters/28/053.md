仍然有很多办法减少攻击面，比如 stack protector、地址空间随机化、Canary。Canary 是金丝雀。以前矿井里会有一氧化碳泄漏。

![图 49：课件：ASLR、Canary、NX、CFI 与 auditd（00:58:05）。](/assets/images/28/0049.webp)

图 49：课件：ASLR、Canary、NX、CFI 与 auditd（00:58:05）。

矿井还可能因瓦斯泄漏而爆炸。矿工会带金丝雀，正常空气下它不停叫，但对一氧化碳比人敏感，人还没感觉时它就不叫了，提醒气体泄漏，应该赶快跑。Canary 牺牲自己保护人，代码里的机制类似。在 return address 前放一个进程启动时生成、攻击者猜不到的随机数字。如果 buffer overrun，就必须覆盖它。返回前检查 Canary，便知道栈已经 corrupted。

![图 50：板书：返回地址之前的 canary（00:59:19）。](/assets/images/28/0050.webp)
