但课上学到的概念是：访问控制是巨大矩阵，确定每个运行程序对每个对象执行各个 API 调用的 yes 或 no。最细粒度可以对每次访问运行一个 turing complete、图灵完备的程序检查，乃至调用大语言模型决定接受或拒绝。追求效率时，则只关注常用部分，比如 AppArmor 的想法，为应用构建虚拟世界，抹去它不该看到的东西。这个想法可以用图灵完备程序实现，也可以用更高效的方式实现，在系统中做 trade off。
