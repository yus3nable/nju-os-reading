文件权限分为同一用户、同一组、其他人三类，分别设置访问控制权限。这样，大表就化成每个文件的几个字节，再配上一张用户和组的表。这里涉及一个重要文件 /etc/passwd，普通用户也能打开。密码可以先通过 one way function 得到 hash。

［课件中的 /etc/passwd 七字段格式。］

```
username:password:uid:gid:comment:home:shell
```

把这个 hash 放进文件，就能支持用户登录。普通用户对它只读，无权修改密码，只有 root 能修改，这样就是安全的。还可以让 AI 帮助理解这个文件。
