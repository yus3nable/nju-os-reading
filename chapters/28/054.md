现在生成的 x86\-64 代码里，经常能见到 endbr64。这套机制叫 Control Flow Integrity，控制流完整性。return oriented programming 在许多 gadget 间跳转，改变了原有执行逻辑。程序正常逻辑可能没有问题：

先复制内存，再检查内容、用户名、密码，最后返回。严格遵循写好的逻辑就没问题。CFI 的想法是只允许程序规定的控制流，其他跳转都拒绝。endbr64 标记分支跳转目标，跳过去时，如果目标是 endbr64 就允许；否则，控制流非法。只有预先写下的跳转被允许，中途截入不行。这样就解决了 Return Oriented Programming：想跳到 POP RSI 再 Return，但那里不是合法跳转位置。
