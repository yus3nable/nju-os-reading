我们的栈是从高地址，向低地址，高和低其实无所谓，那就有一个 stack frame 对吧，当我执行一个 call 指令的时候，我会首先会push 一个 return address，然后接下来会，这个栈帧是属于你的，比如说 main 函数的栈帧，或者任何一个函数的栈帧。

［课堂展示的 vulnerable\.c：先打印缓冲区地址，再读取并回显字符串。］

```
#include <stdio.h>

int main() {
  char buf[64];
  printf("%p\n", buf);
  fflush(stdout);
  scanf("%s", buf);
  printf("Got: %s\n", buf);
}
```

好，这个时候它会在这里面，allocate 一个 buffer，注意低地址在这，也就是说这是 buffer 的 0，这个是 buffer 的 63，OK，然后你们都知道，buffer overflow 是 undefined behavior，它是一个未定义行为，未定义行为就意味着，我的 buffer，如果你给它一个很长的字符串，什么 a，buffer 就会写上 a，不断的 a 再往后写，因为它是从低地址往高地址写，如果你有个 memory copy，它会。

![图 41：板书：缓冲区、栈帧与高地址的返回地址（00:52:26）。](/assets/images/28/0041.webp)

它会把什么，它会把你的返回地址给覆盖掉，把返回地址给覆盖掉，是一个非常危险的事情，因为指针就飘飞了，对吧，你给一个，比如说你输入一个奇怪的字符串，然后这个奇怪字符串，在机器地址的意义上，是没有意义的，然后它会跳转到一个不存在的页面。然后跳转到一个不存在页面，以后它就 crash 了。
