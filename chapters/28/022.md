操作系统控制着这个入口。应用程序可以自由计算，访问对象时则必须经过操作系统 API，因而可以实现访问控制。API 一方面有具体行为，比如 fork 复制程序、Map、read/write、Mount 文件系统；另一方面还承担访问控制。应用调用 API 时，比如 Open 文件，操作系统知道应返回指向明确对象的文件描述符，也有权拒绝访问。拒绝越权的读，就能实现 Confidentiality：操作系统认为程序无权读取这个对象，就拒绝 API 请求。如果程序请求写入，操作系统认为没有修改权限，就通过拒绝实现 Integrity。如果资源管控和对象访问足够公平，也能提供一定程度的 availability。当然，可用性很复杂，还有 denial service attack、complexity attack 等问题。
