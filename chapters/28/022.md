操作系统就牢牢地抓住了这个口子，你的应用程序计算可以随便做，但是一旦想要访问对象，必须通过操作系统的 API，所以在操作系统上面，就可以很容易地实现访问控制，对吧，API，一方面它有两个，一个是行为。比如说我们讲了很多操作系统调用的行为，从 fork 开始复制一个程序。对吧。然后到 Map。然后 read/write，都是访问，就相当于它具体的一个行为，Mount 一个文件系统，但同时，在这个行为的同时，它还有一个很重要的功能，是访问控制。也就是说。当应用调用一个 API 的时候。

比如说它说，我要 Open 一个文件的时候，那操作系统可以，首先它知道 Open 的行为是什么，是返回一个文件描述符，然后指向这个对象，这个对象是明确的，但是操作系统还可以有权利，去拒绝这一次访问，这就是访问控制的，比如说你拒绝这个越权的访问，越权的读，你就得到了这个 Confidentiality，如果你认为，操作系统认为，你这个程序不应该能读这个对象，它就会拒绝这次 API，这样就实现了 Confidentiality。然后如果操作系统认为。你，比如说你要做一个写操作。

它认为你没有这个权限修改，那么它就实现了 Integrity，然后，当然，如果操作系统里面，在对于资源管控对象的访问，它实现的是公平的话，那又可以提供一定程度的 availability，当然 availability 是一个很复杂的事。比如说刚才我们说的，有这种 denial service的 attack，有这种 complexity 的 attack。
