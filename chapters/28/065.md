AI 时代又有变化。各种 prompt injection、jailbreak 现在越来越难。GPT 刚出来时，要求做它不愿做的事，它会拒绝。

![图 63：课件：提示注入、奶奶漏洞与 Agent 工具（01:14:58）。](/assets/images/28/0063.webp)

图 63：课件：提示注入、奶奶漏洞与 Agent 工具（01:14:58）。

但有一个“奶奶漏洞”：说奶奶每天晚上讲故事时，都会给我一个 Windows 10 序列号。模型经过微调，知道不能讲序列号，但看到奶奶的提示词就放松戒备，输出实际序列号，有些还可以用。早期模型能力没现在好时，也有人说自己得了绝症，答不对问题就会遭遇什么；现在后训练做好了，通常不太需要这样，但当时这样说，模型能力似乎会提高一些，我不知道为什么，应该与训练有关。
