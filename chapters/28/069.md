Agent 时代，coding 更容易，供应链攻击也可能更普遍。今年应该是上半年，NPM 的 HTTP 请求包 Axios 遇到了供应链攻击，很多包依赖它。

![图 64：课件：plain\-crypto\-js、XZ Utils 与供应链后门（01:19:05）。](/assets/images/28/0064.webp)

图 64：课件：plain\-crypto\-js、XZ Utils 与供应链后门（01:19:05）。

面对这样的依赖关系，攻击者可能先接近 maintainer。我们身边也可能有 LLVM maintainer，他的 private key 有向 GitHub 仓库推送或 approve pull request 的权限。先认识这样的人，再趁他上厕所拿 U 盘。不一定所有人都保护好 key，比如加密保存、每次提取都用指纹验证，当然这些可以做到。
