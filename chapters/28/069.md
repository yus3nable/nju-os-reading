然后就被供应链攻击了，然后如果你想要供应链攻击，你怎么攻击呢？你最好是跟一个 maintainer 走得比较近，比如说这种包的，其实我们身边也有一些隐藏的，可能就有一些隐藏的什么，LLVM 的 maintainer，然后他就有那个 GitHub 仓库的 key，就他的那个，他的 private key 是有权限，向那个 GitHub 仓库，推送的东西，或者 approve pull request 的，你首先要认识一个这样的人，第二个。你在他去上厕所的时候。拿一个 U 盘。他未必就，就不是所有的人都把这个 key 管得很好，比如说都有一个指纹验证，他以加密的方式存储，然后每次提取的时候，都有一个指纹验证，当然这件事情是可以做到的。
