早期计算机系统可以说毫无安全可言。比如一台 8086 的 real mode PC，CS 和 IP 都是 16 位，有 20 位地址空间，计算地址时，先把 CS 左移 4 位。

图 2：课件：8086 实模式、加壳和 BBS 的无保护时代（00:00:59）。

然后给这个结果加上 IP，得到 program counter 地址，可以寻址一兆空间。8086 CPU 没有任何保护，可以 patch 任何程序的任何指令。系统调用通过 int 指令完成，类似函数调用：执行 int x，就算出 x 乘以 4 的地址，从地址空间最底部的中断向量表中取出目标地址，做长跳转，调用 firmware 中的只读代码。这就是 16bit 时代的系统调用。firmware 中的代码改不了，但可以任意修改其他程序地址空间的内存，无须操作系统 API，也没有监管审计。
