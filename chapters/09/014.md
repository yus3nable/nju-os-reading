程序仍然从 \_start 开始运行，它也是 libc 的一部分。\_start 是一小段汇编代码，会跳转到 \_start\_c。后者接收 long \*p，从第一格读出 argc，也就是参数数量；argv 则是 P 加 1。

System V ABI 手册规定了 Initial Process Stack 的初始布局。那一小段汇编会找到正确的 SP，也就是 Stack Pointer，传入这个指针。

![图 94：\_start\_c 从初始栈取得 argc 和 argv（01:21:28）。](/assets/images/09/0094.webp)

图 94：\_start\_c 从初始栈取得 argc 和 argv（01:21:28）。

crt1\.c 中的 \_start\_c

```
hidden void _start_c(long *p)
{
    int argc = p[0];
    char **argv = (void *)(p+1);
    __libc_start_main(main, argc, argv, _init, _fini, 0);
}
```

![图 95：初始进程栈中的 argc 和 argv（01:21:28）。](/assets/images/09/0095.webp)

图 95：初始进程栈中的 argc 和 argv（01:21:28）。

取出参数数量和全部参数后，代码调用 \_\_libc\_start\_main，再调用刚才的 \_\_init\_libc。环境变量通过 argv 加 argc 加 1 算出，与手册中 Initial Process Stack 的图完全一致。

![图 96：\_\_libc\_start\_main 计算 envp 并初始化 libc（01:21:52）。](/assets/images/09/0096.webp)

图 96：\_\_libc\_start\_main 计算 envp 并初始化 libc（01:21:52）。

\_\_libc\_start\_main 中的初始化片段

```
char **envp = argv+argc+1;
__init_libc(envp, argv[0]);
```

最后进入 \_\_init\_libc，执行刚才给 environ 赋值的代码，没有魔法。这些代码叫 C Runtime，简称 CRT。刚才的文件名是 crt1\.C，其中 RT 就是 Runtime。让大语言模型展开整个编译过程，还会看到 crtbegin\.o、crtend\.o、crtn\.o 等，都是 Runtime 相关的内容。

libc 提供 Free Standing 环境：setjmp、longjmp，整数长度定义和整数打印等；在此基础上封装系统调用，处理文件描述符、进程乃至错误编号。此外，libc 还提供必要的运行代码，其入口写在 ELF 头中。

计算机系统基础课应该用 readelf 看过二进制文件。这里是 Arm64 的 ELF，Entry Point Address 为 0x400168。这个值由链接器最终填写：它找到 \_start 符号，把地址填进 ELF 头，这对应 crt1\.o 中的代码。

libc 包含各种定义和宏，以及最初的初始化代码，例如设置 environ；也处理 main 返回后的工作。\_\_libc\_start\_main 会调用 stage2，也就是 libc\_start\_main\_stage2，最终看到调用 main 并退出的这一行。

![图 99：libc\_start\_main\_stage2 调用 exit(main(\.\.\.))（01:24:27）。](/assets/images/09/0099.webp)

图 99：libc\_start\_main\_stage2 调用 exit(main(\.\.\.))（01:24:27）。

libc\_start\_main\_stage2 结尾

```
char **envp = argv+argc+1;
__libc_start_init();

/* Pass control to the application */
exit(main(argc, argv, envp));
return 0;
```

它以 argc、argv、envp 调用 main，再把返回值交给 exit。main 之前的初始化在这里完成，之后的工作在 exit 中完成。exit 会调用 atexit handler，代码里是 \_\_funcs\_on\_exit、\_\_libc\_exit\_fini。

![图 100：exit 的清理调用与 \_Exit（01:24:52）。](/assets/images/09/0100.webp)

图 100：exit 的清理调用与 \_Exit（01:24:52）。

exit 结尾的清理与退出

```
__funcs_on_exit();
__libc_exit_fini();
__stdio_exit();
_Exit(code);
```

随后 flush buffer，最后调用 \_Exit。它会通过 syscall 进行系统调用，musl 在这里假定系统是 linux。这就是一个 C 程序的完整运行过程。
