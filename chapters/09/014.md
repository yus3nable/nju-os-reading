crt1\.c 中的 \_start\_c

```
hidden void _start_c(long *p)
{
    int argc = p[0];
    char **argv = (void *)(p+1);
    __libc_start_main(main, argc, argv, _init, _fini, 0);
}
```

libc\_start\_main\_stage2 结尾

```

```
