freestanding 环境之上，还可以实现一些适合作练习的函数，例如 memcpy、memmove、strcpy，大家刚学 C 或 C\+\+ 时应该做过这样的课后习题。random 也可以实现，不过它并不随机：seed random 需要给定 random 的 seed，也就是 randomseed。

randomseed 相同，每次运行程序生成的随机数序列就完全相同，所以它是数学上的函数、随机数生成器，seed random generator。还有 atoi，涉及整数与字符串之间的转换，以及 qsort。有人用过 C 的 qsort 吗？它的函数参数不好用，这也是受 C 的限制；C 是高级汇编语言。在实际程序中实现 quicksort，一般可以定义一个结构体，在要排序的 element 中带一个 compare function。

现场草写片段，类型声明与结尾尚未补全

```
struct Element {
    int (*cmp_fn)(Element *e1, Element *e2);
}
```

自己定义时可以放入任何需要的内容，写出合适的代码；C 提供的语法机制有限，要在标准库实现通用 quicksort，就只能这样做。它并非完全不能用，但最后代码的可读性会比 c\+\+ 差一些，比 Python 更差。Math 数学库中的 sine、cosine 等函数也可以实现，不过数学库有很多复杂问题。例如，有没有一个数 a，使 a 大于 a、a 小于 a、a 等于 a 都为假？在整数域和能合法表示的数域中，这样的数不存在。1 或一个 IEEE 754 能合法表示的浮点数都应该等于自己，1 等于 1，2 等于 2。什么东西不等于自己？数学中专门有 not a number。浮点数及其数学运算有很多细节，刚才的代码示例里就有 not a number。

nan\.c 的比较与打印片段

```
float a = NAN;
volatile int x = (a > a);
volatile int y = (a < a);
volatile int z = (a == a);
printf("x = %d, y = %d, z = %d\n", x, y, z);
int result = !(x || y || z);
```

定义三个变量 xyz，再把它们打印出来，就能检查 a 大于 a、a 小于 a、a 等于 a 是否都为假。运行 not a number，确实能看到结果是 1。
