用这种 happens\-before 实现 join，和计算图类似：main 等全部线程结束再继续。每个线程对应一个完成信号量，T1、T2、T3 结束时，分别把玩具放到自己的桌上。假设有四张桌子，每个线程结束后，在相应桌上放一个玩具。

main 先 P T1 的信号量，从第一桌取一个，再从第二桌取一个，依次收齐全部玩具，就完成 join。代码也这样：线程结束时 V 自己的信号量，join 则逐个 P。

![图 19：join\-1\.c：每个线程分别使用一个完成信号量（00:27:45）。](/assets/images/16/0019.webp)

图 19：join\-1\.c：每个线程分别使用一个完成信号量（00:27:45）。

```
sem_t done[16];
int count = 0;

void worker_init(int T) {
  count = T;
  for (int i = 1; i <= T; i++) {
    SEM_INIT(&done[i], 0);
  }
}
void worker_done(int id) {
  V(&done[id]);
}
void worker_join() {
  for (int i = 1; i <= count; i++) {
    P(&done[i]);
  }
}
```

信号量支持多个玩具，其实只用一张桌子也够。main 知道创建的线程数，每个线程结束后，就往同一张桌上放一个。main 用一个循环收集。

创建四个线程，就必须收四件玩具才继续。放和拿可以交错，先拿一个、两个、三个，直到最后线程 V 第四个，main 才能取齐。信号量适合这种计数资源：泳池最多 N 人、停车场 N 车位、餐厅 N 桌。

等 N 个线程也属于计数。信号量初始为 0，没有玩具，各线程结束都 V，向同一张桌放一件。

```
int count;
sem_t done;

void worker_init(int T) {
  count = T;
  SEM_INIT(&done, 0);
}
void worker_done(int id) {
  V(&done);
}
void worker_join() {
  for (int i = 0; i < count; i++) {
    P(&done);
  }
}
```

join 先知道要等多少线程，再 P 多少次，收齐后返回，更省空间。这两份代码应该都能正确实现 join。main 创建多个 Worker，各自 sleep 一秒。

![图 21：主线程创建四个 worker，并等待全部结束（00:30:07）。](/assets/images/16/0021.webp)

图 21：主线程创建四个 worker，并等待全部结束（00:30:07）。

```
void T_worker(int id) {
  printf("Thread %d start.\n", id);
  sleep(1);
  printf("Thread %d end.\n", id);
  worker_done(id);
}

int main() {
  worker_init(4);
  for (int i = 0; i < 4; i++) {
    spawn(T_worker);
  }
  worker_join();
  printf("Workers joined.\n");
}
```

随后 join，再打印 Workers joined。运行能看到一二三四 Start、结束，之后才 join。两种方式都正确实现了线程 join。
