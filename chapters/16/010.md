join 的两种方法都可推广到任意计算图。每个线程各用一张桌子，对应计算图的每条边设置一个信号量。

![图 23：按边和按节点计数：从 join 推广到计算图（00:30:33）。](/assets/images/16/0023.webp)

图 23：按边和按节点计数：从 join 推广到计算图（00:30:33）。

节点要等待几个前驱，就像 join 它们。前驱完成，在相应桌上放钥匙；集齐这三个桌上的三把钥匙，当前线程才能执行。另一种方法是集中计数。

![图 24：计算节点等待前驱完成，再通知自己的后继（00:31:31）。](/assets/images/16/0024.webp)

图 24：计算节点等待前驱完成，再通知自己的后继（00:31:31）。

需要四个玩具时，可以把桌子放在节点上。这里举例，节点需要三把钥匙，就 P 三次；三个前驱各完成一次，各 V 一次，三个 P、V 配好，就能继续。下面准备的是每个节点放信号量的实现。

![图 25：每个计算节点对应一个 vertex\_sem（00:32:20）。](/assets/images/16/0025.webp)

图 25：每个计算节点对应一个 vertex\_sem（00:32:20）。

信号量 count 初始为 0，每个节点创建一个线程。第 25 行遍历入边，有几条就对同一个 vertex\_sem 执行几次 P，收集对应数量的钥匙，不关心放入顺序。第 35 行计算完成后，遍历每条出边，对应后继节点的桌子。

只要别人依赖自己，完成后就向对方桌上放一把钥匙。这样同步，再运行能看到 0、1、2、3、4、5 按依赖执行。

![图 26：计算前 P 入边次数，计算后 V 各个后继（00:33:24）。](/assets/images/16/0026.webp)

图 26：计算前 P 入边次数，计算后 V 各个后继（00:33:24）。

```
for (int i = 0; i < LENGTH(edges); i++) {
  if (edges[i].dst == tid) {
    P(&vertex_sem[tid]);
  }
}

printf("Computing node #%d...\n", tid);
sleep(1);

for (int i = 0; i < LENGTH(edges); i++) {
  if (edges[i].src == tid) {
    V(&vertex_sem[edges[i].dst]);
  }
}
```
