Dijkstra 提出信号量，一定程度上是为了解决哲学家吃饭这样的难题。每位哲学家是线程，围桌而坐，各有一份饭，必须同时拿到左右两把叉子才能吃。一共五人、五餐、五把叉子。筷子更符合“两根才能吃”的设定，不过提出问题的人不习惯吃中餐，用的是叉子。

每个人可以吃，也可以思考，吃完放下叉子，思考时别人就能吃，希望实现这种 synchronization。先忽略注释掉的同步代码，这里有 N 位哲学家。

创建 N 个 philosopher 线程，各有左右手叉子。右手编号为线程号 ID，左手为 ID\-1。环上取 mod N，所以 \-1 可写成 \+N\-1。

![图 41：左右手叉子的编号及等待位置（00:50:20）。](/assets/images/16/0041.webp)

图 41：左右手叉子的编号及等待位置（00:50:20）。

```
int lhs = (id + N - 1) % N;
int rhs = id % N;
```

各线程循环执行，需要在相应位置加同步，确保同时取得左右叉子后才吃，吃完释放，让其他人继续。考虑 A、B、C、D、E 五个人，叉子编号 1、2、3、4、5。A 能吃的条件是什么？

编号 1、2 都空闲，且检查后要一起拿走，使它们变成占用状态，然后才能吃。
