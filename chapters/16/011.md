我觉得它的 killer application，是简洁、对称地实现生产者消费者。建 empty、fill 两个信号量，T\_produce、T\_consume 两类线程。

![图 28：empty 与 fill 的对称操作和全局不变量（00:34:46）。](/assets/images/16/0028.webp)

图 28：empty 与 fill 的对称操作和全局不变量（00:34:46）。

```
sem_t empty = SEM_INIT(depth);
sem_t fill = SEM_INIT(0);

void T_produce() { P(&empty); printf("("); V(&fill); }
void T_consume() { P(&fill); printf(")"); V(&empty); }
```

生产者至少需要一个空槽位，才能拿到生产许可，打印左括号。生产后不能 V(empty)，因为此时别人可以消费，需要 V(fill)，将 fill 信号量加 1，往 fill 桌上放一个玩具。代码很对称。

两张桌分别叫 empty、fill，另有 buffer。生产往 buffer 放东西，消费从里面 POP。容量为 4，最初 empty 桌上有 4 把钥匙，只有 Producer 能通过 P(empty) 取走。

empty 每件玩具对应一个空槽位，有几件，就有几个空位；fill 每个球对应一份可取数据。初始 fill 为空，SEM\_INIT 中 empty 的 depth 是括号深度，也就是缓冲区大小。

此时任意线程 P(fill)，都无法成功。
