我觉得比较 killer 的 application，其实是优雅的实现生产者和消费者，我要建两个信号量，一个叫 empty，一个叫 fill，然后我们的有两个线程，一个叫 T\_produce，一个 T\_consume，生产者和消费者。

![图 28：empty 与 fill 的对称操作和全局不变量（00:34:46）。](/assets/images/16/0028.webp)

图 28：empty 与 fill 的对称操作和全局不变量（00:34:46）。

```
sem_t empty = SEM_INIT(depth);
sem_t fill = SEM_INIT(0);

void T_produce() { P(&empty); printf("("); V(&fill); }
void T_consume() { P(&fill); printf(")"); V(&empty); }
```

那我们的生产者，他需要的是什么呢？需要的是，我至少要有一个空的，对吧，相当于我的缓冲区有一个停车场里有一个空位，或者说有一个空格可以让我生产，那我才能拿到这个生产的这个玩具，然后我就可以生产一个打一个左括号，但是呢？我不是 V(empty)，因为我是生产者，当我把打印出左括号，以后就意味着别人可以消费了，别人可以消费意味着我要把 fill 的那个信号量里面，要给它加 1，要往那个袋子里面放一个桌上放一个玩具，有个什么感觉呢？这个代码对吧。很优雅。特别优雅。极为对称。

你可以想象它有两个桌子，一个桌子叫 empty，一个桌子叫 fill，好，empty 和 fill，然后呢？假设我们还有一个 buffer，那如果我们生产的话，就会往 buffer 里面放一个东西，然后如果消费的话，就必须从 buffer 里面 POP 一个东西。好，那如果 buffer 的容量是4。那我们最开始的时候，在这个 empty 的桌上就有 4 个钥匙或者 4 个玩具。那这个时候谁可以把这个玩具拿走呢？只有 Producer可以，Producer 是 P(empty)。

它需要从这个 empty 的桌上拿走，empty 桌上的每一个玩具，其实都对应了这个 buffer 里面的一个空位，就是说我这里有几个玩具，就说明我的 buffer 里面有几个空位，然后我现在这个 fill，fill 里面有几个球，就意味着这个 buffer 里面有几个地方是有数据我可以取的，但我现在 fill 是空的，这个桌子是初始的时候，大家看到这个 SEM\_INIT 的时候是 depth，是我的括号可以嵌套的深度，或者说我缓冲区的大小。所以任何线程我现在 P(fill)。

我现在任何线程 P(fill)，我都是失败的。
