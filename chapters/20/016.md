讲 GPU，还要回顾另一段改变人类命运的历史。时间回到 1972 年，Magnavox 推出了 Odyssey，这是世界上第一台发售的游戏主机。它已经有今天游戏主机的雏形；用过 Xbox 或 PS5，就会发现外形有些相似。

![图 24：1972 年的 Magnavox Odyssey 游戏机（00:41:27）。](/assets/images/20/0024.webp)

图 24：1972 年的 Magnavox Odyssey 游戏机（00:41:27）。

玩家可以用类似手柄的设备操纵它。这是很早期的产品，没有声音，画面只是光点。这样的画面能做什么游戏？比如乒乓球：控制一个挡板上下移动，来回击球。这台游戏主机卖得还可以，产业也就发展起来了。

课件中的逐像素绘图片段；H、W 和函数 f 的定义未列出。

```
for (int y = 0; y < H; ++y) {
  for (int x = 0; x < W; ++x)
    putchar(f(x, y) ? '*' : ' ');
  putchar('\n');
}
```

1983 年，出现了 Nintendo Entertainment System，也是我这个年代中国人的童年回忆。比如 1986 年发售的第一代《塞尔达传说》，已经有精美的图形、平滑动画和交互界面。今天不讲塞尔达的玩法，要看的是这个界面背后隐藏的计算危机。
