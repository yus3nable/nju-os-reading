另一种延续下来的方案，就是刚才说的简化 CPU。大而复杂的 CPU 靠复杂动态流水线加快指令执行；不断简化 CPU，就能放入更多 CPU，指令调度代价也可以接近零。假设每个 CPU 都是你们实现过的最简单的单周期 CPU，就不必浪费电路。每个 CPU 确实运行得慢，但几乎没有浪费的电路。

每次逻辑门翻转，几乎都用于译码、执行、load、store 这些有意义的事情。设想 CPU0、CPU1 都是实验中最简单的单周期 CPU，暂时不谈缓存。今天讲的 CUDA，也就是显卡里的技术，还会进一步让 CPU 的一部分共享，只为必须独立的部件，比如执行单元，保留多个副本。

ALU 必须每个 CPU 各有一份，译码器却可以由多个 CPU 共享。指令集越复杂，译码器占用的电路越多，共享就有价值。这个思路引出了今天人工智能时代的明星：GPU。
