课件中的两种索引写法；map 和 t 的定义省略。

```
map[row * 1920 + col] = t;
map[row + col * 1080] = t;
```

课件中的分支分化教学片段；A、B、X、Y、Z 为未展开的操作，保留图中的写法。

```
if (threadIdx.x < 4) {
  A;
  B;
} else {
  X;
  Y;
}
Z;
__syncwarp()
```

刚才 Row 乘 1920 加 column 的写法能生成连续 Store，获得最佳性能。稍改一下，内存访问就可能全部不连续，性能立刻变差，内存控制单元要一个 word 一个 word 地写，耗费更多时间。CUDA 程序的分支也很麻烦：SIMT 只有一个 Program Counter，怎样实现不同线程的分支？

对于 if A Else B，这里的 CUDA C 编译结果没有这种二选一分支，可以有无条件跳转或循环指令。if A Else B 会先计算一个条件，也就是 Condition，将结果放进寄存器。

根据条件寄存器的值，就能 disable 不满足条件的线程。执行 if Condition 时，将 not Condition 的线程屏蔽，生成对应的汇编；另一段同样用 disable 控制哪些线程参与。
