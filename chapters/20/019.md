课件中的 sprite 属性位；坐标、tile 和 attr 合为一个 sprite。

```
Sprite = (x, y, tile, attr)
256-byte Sprite RAM (64 sprites)

76543210
||||||++- Palette
|||+++--- Unimplemented
||+------ Priority
|+------- Flip horizontally
+-------- Flip vertically
```

除此以外，还要指定小精灵用哪个 tile、哪个调色板。它有一个 8bit 的 attribute，其中两位选择调色板，几位未实现，一位是 priority，相当于 Z 轴的顺序，还有两个 bit 分别表示水平翻转和垂直翻转。利用这个机制可以做很多事。比如画一个圆，无须四个 tile，只用一个 tile，先垂直翻转，再分别水平翻转，就能拼出整个圆。

Super Mario Brothers 中碰到就会死的蘑菇，也是这样实现行走动画的。蘑菇两只脚一长一短，通过对两个贴块做镜像翻转，交换两只脚的位置。

for (int row = 0; row < lines; row++) {
  #pragma omp parallel for
  for (int i = 0; i < 64; i++) {
    struct sprite *s = &SPRAM[i];
    if (s->y <= row && row < s->y + 8) {
      // 绘制 sprite
    }
  }
  display_row(row);
}
