编程时，我们也用过类似的思路。指令集引入一种寄存器，把它当成四个 16bit 整数；实现 bitset 时，我们把一个 32 位整数当成 32 个 1bit。比如维护一个集合，它存储 0 到 32 的某个子集，假设有 01267 这些元素。

当然可以用 set&lt;int&gt; 实现，也可以直接用 uint32\_t，也就是 u32。从右往左，对应元素 0 的位置开始，如果元素在集合里，就把对应的 bit 写成 1，比如 110 等等。这样就用一个 32 位整数表示了集合。还可以建立整数数组，用 array 的 0、array 的 1 等位置扩展成更大的 bit vector。

查询 x 是否属于集合时，假设用的是 8bit 字符数组，就先用 x 除以 8，找到对应格子，再找到格子里对应的位，根据这一位判断元素是否在集合里。
