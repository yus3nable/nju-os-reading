凸出的部分会遮挡凹陷部分，这种遮挡无法由法线反映出来，法线只能在光照上产生效果。远景中，这种技术可以节省多边形。我也准备了一个 shader program，但今天相关依赖没能装完，就不运行了。可以知道的是，这样的程序甚至能保存成字符串，交给图形库编译。

编译后，让程序作用于每个 pixel，就能修改每个像素的颜色。OpenGL 教程通常先教画一个带渐变色的三角形，就是用这样的办法实现。这是一种受限的编程语言，无法调用操作系统的 system call，否则会产生编译错误；但可以做计算、分支和条件判断。

还可以 load、store，访问贴图的法线向量等数据。到这一步，我们已经有了一个 program，为每个对象执行一次，也就是 for each。

main\.c 中保存 GLSL 程序的字符串片段；依赖 OpenGL 环境，原课因依赖未装完而未运行此示例。

```
static const char *frag_src =
  "#version 330 core\n"
  "uniform vec2 u_resolution;\n"
  "uniform float u_time;\n"
  "out vec4 frag_color;\n"
  "void main() {\n"
  "    vec2 uv = gl_FragCoord.xy / u_resolution;\n"
  "    float d = length(uv - 0.5);\n"
  "    float c = 0.5 + 0.5 * sin(d * 20.0 - u_time * 3.0);\n"
  "    frag_color = vec4(vec3(c * uv, 1.0 - c), 1.0);\n"
  "}\n";
```
