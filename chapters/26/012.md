因此文件系统也要缓存，像 Memory Hierarchy 的一、二、三级缓存，在内存留一份数据。对外看 bread、bwrite 在操作 disk，内核实际会管理缓存。Linux 称为 buffer cache，这个历史名称我觉得不好，它就是文件系统 cache。

bread 可以类比内存 load，bwrite 类比 store。load 先查 cache，miss 再找设备；若设备又有虚拟层，就继续转发到 loopback device、文件。

写操作与 memory hierarchy 略有不同：已经按整 block 写，可以直接覆盖 cache 中旧内容，下次 reader 就从 cache 读取。原理仍是 locality。常一起访问的数据结构尽量放同一块，读到一个，下次访问邻近结构就能 hit，减少设备访问和放大。不过只写一个字节等场景，明显的读写放大仍难避免。
