Systems 的思路常是，系统能用、好用，先不处理小问题，出事后再修电脑、File System Check。但后果可能严重。快速格式化后仍能恢复数据，比如摄影师事件里，修电脑的人最后被判八个月有期徒刑，可能是大家出生前的事。

这也 inspire 了 fsrecov 实验。Unix 长期在 crash 后做 File System Checking。老 Windows 机房里，可能见过开机扫描文件系统、报告坏簇并修复。
