做 system 的人常是先挣钱后还债。系统 crash 后，可能丢数据、坏目录。比如要写 2，inode region 写到一半，读写头已开始写，RAM 突然断电，甚至可能把 Block 抹掉，得到 corrupted file system。

当时我在美国 lab，他们做了小面包板，从 VGA 送信号，能编程控制 SSD 物理断电。实验发现，不少 SSD 内部系统有大问题，crash 后整盘可能再也读不出数据。

SSD 恢复很复杂，HDD 还可拆盘，SSD 基本无法修。这个工作促使厂商修复一批固件，后来就再找不到这些问题。
