可以把 block device 简化为三个接口。实际会更复杂，比如通过队列提交请求、得知完成状态。先类比并发程序的共享内存：内存是按字节寻址的字节序列，memory hierarchy 隐藏 L1、L2、L3、memory 及更多层级，程序通过 load、store 访问。

block device 则是 block array，按整块读写，大小可能是 4K，软盘上是 512 字节。并发中，两个线程同时读写同一个 memory location 会有 data race 风险，可能需要互斥锁。块设备也有类似 barrier 的 block sync，等待所有 ongoing、在途写入落盘后才返回，像把并行执行变成串行。

用这三个操作，可以实现任意数据结构，就像用 load、store 实现内存数据结构。
