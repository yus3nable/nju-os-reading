先看简单易懂的 file allocation table，硬盘、软盘都能用。5\.25 英寸单面软盘只有 160kb，每 block 512 字节，总共 320 个 block、sector。

这么小的设备，重点是省空间。复杂 fancy 数据结构会额外占用空间，虽然可能换来查询效率，但这里不想付出这个代价。file allocation table 就采用很简单的结构。
