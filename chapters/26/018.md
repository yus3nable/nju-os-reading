OK，那既然你知道这是一个数据结构以后，你就可以开始设计它了，那第一个比较容易理解的很简单的设计，是 file allocation table，file allocation table 它可以在硬盘上面用，也可以在软盘，像比如说 5\.25 英寸的软盘单面是 160kb，也就是说 160kb 就意味着，它软盘是一个 block 是 512 个字节，它总共只有 320 个 block，只有 320 个 sectors，只有 320 个块。你想只有 320 个块。

你要在这个块上面构建文件系统，你的设计思想是什么，你的设计思想肯定不是什么 fancy 的数据结构，去维护这个任何你在数据结构里面增加的复杂性，都浪费了空间，某种程度上你会牺牲一点点多余的空间去换，换可能更高的查询效率。但是你不想做这个事，你想要的是极致的空间的节约。所以 file allocation table，它就是这样的一个设计，就是一个非常简单的数据结构的设计，首先它有一个。
