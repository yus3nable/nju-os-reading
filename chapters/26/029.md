我们的目录项里面，就是目录实现也是一个文件，就它也是一个数据，它也是靠这个 next，比如说你的目录里面有好多好多好多项，就是 1 万个文件，它这 1 万个文件就是不停 next，next，next，next，就它这个数据结构也是一个线性的线性表。然后这个线性表，第一，它是一个好多好多个这种 struct 的这个 directory 的 entry，叫 dentry。叫目录项，directory entry。然后这个 directory entry 就是我刚才在这里展示的这个样子。

对吧，它有一个名字，它有一个 attribute，这里告诉你，它的最低位是代表是不是 readonly，然后第二位代表是不是 hidden，是不是 system，VOLUME\_ID，是不是目录。对吧，你看 0x10，你可以知道这个文件到底是不是目录。所以这个是文件的 metadata，它的名字，它的 attributes，还有一些别的 file size，这个是非常重要的数据结构的字段。然后这样每个目录里面就存了它目录下的所有的文件。所以你看到这个文件系统是不支持链接的，就是一个最简单的实现。

然后你怎么遍历目录呢？你作为一个文件系统的实现者，你怎么遍历目录呢？你就把这个目录文件当普通的文件给读出来，然后读完了以后，它就变成好多好多个这个数据结构的拼接，对吧，好多好多数据结构的拼接，然后它去遍历这个数据结构，它就知道这个目录里面有哪些文件。

指针指向了文件的第一个 cluster，然后这个 cluster 它的 next 就是它的第二块，再 next 就是它第三块，继续 next，你就可以把整个文件的所有的内容都给遍历出来。这个就是 file allocation table，没有任何神秘，它就是一个数据结构。
