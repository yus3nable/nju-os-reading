下面概览已有设计。文件系统一般实现在某个 partition 上，比如 /dev/ 下的 mmcblk0p1，也是 block 序列。存储数据结构，首先要有入口。

链表有 head，二叉树有 root。文件本身也可能是数据结构，比如 bitmap。Mandelbrot Set 演示中，我用 printf 输出 \.ppm 图片，浏览器就能看到，很适合课堂 demo。

ELF 也有 header、magic number，帮助 file、加载器识别格式，结构中记录 entry、文件大小、program header 数量。这些都类似一个 root，指向某个 block，通常放在开头。GUID partition table 也一样。

但 GPT 并非从整个设备第一个 block 开始，第一个通常保留兼容 MBR，后面才是 GPT data structure，也就是分区表、整个磁盘的 root。磁盘尾部还会再放一份 GUID partition table。

保留两份，是因为分区信息丢失后恢复麻烦，虽然仍可能恢复。前面损坏，就能从尾部找备份。每个分区开头又有自己的入口，叫 superblock，是文件系统的重要 block。如果只破坏一个 block，却想给使用者造成最大麻烦，就抹掉 superblock。
