按序 replay 全部 shared memory write，就能还原任意数据结构，因为它们最终都通过 memory write 实现。实现 crash consistency，就同时保存两部分：原数据结构，以及它的修改记录，形成 1 加 1 大于 2 的效果。

磁盘上仍有 inode bitmap、struct node 数组等 UNIX 结构，另外开辟 journal 区域。

![图 52：把树操作记为内存写入序列（01:05:08）。](/assets/images/26/0052.webp)

图 52：把树操作记为内存写入序列（01:05:08）。

每次 bwrite，先以 append\-only 写进 journal，确认日志已保存，再写真实数据结构。真正写完，相关日志就可丢弃；未完成前，日志始终 on disk。若中途 crash，磁盘结构可能不一致，reboot 后却能 replay bwrite。它叫 write\-ahead log、redo log。我更喜欢 redo log，因为就是用来重做。

这样可以实现任意数据结构的 crash consistency。
