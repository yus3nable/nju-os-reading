第 09 课 · C 标准库原理

从 C 到指令集：函数调用与 FFI

原片 00:09:10—00:14:02

讲 libc 之前，先复习 C 编程语言。

课件中的退出程序

void _start() {
    __asm__("mov $60, %eax\n" // syscall: exit
            "xor %edi, %edi\n" // status: 0
            "syscall");
}

还记得 SimpleC 吗？任何 C 语言程序都可以改写成简单形式：赋值时，等号左边是一个变量，右边只有一个操作；if 和循环也可以写得很简单。SimpleC 基本可以直译成汇编语言。看到一段 SimpleC，甚至可以手写出对应的汇编指令，无论目标是 x86、ARM，还是 RISC-V。只要有跳转、寄存器腾挪和 LoadStore 等指令，就可以完成编译。指针、数组、结构体、函数调用都对应内存和寄存器的直接操作。但 SimpleC 只定义了 C 语言中与计算相关的部分，包括 LoadStore，尚未覆盖完整的 C 语言。所有编程语言都有跨语言调用的能力，称为 Foreign Function Interface，简称 FFI，大家可能会在各个语言中用到。

例如，Python 中有一个 mmap 模块，可以做内存映射。mmap 以后，它会给你一个类似 Handle 的东西，用来访问这个字节对象。背后一定有 mmap 系统调用，但 Python 本身没有系统调用这个概念，也没有系统调用函数；平时是用 pathlib open 一个东西，或者用 Print 打印。所有编程语言在设计时都会提供这样的接口，允许在适当的时候访问其他语言写的文件，例如二进制文件或直接用汇编写的文件，不过这样的访问一般不会很多。CPython 用 C 实现，自然可以与 C 互相调用：在 Python 中调 C，也可以在 C 中调 Python。感兴趣的同学可以让 AI 写一段代码试试。C 是比较底层、可以写任何东西的语言，它提供了与汇编或二进制代码连接的能力。这里有两种方式，一种是直接连接用汇编实现的函数。函数对应一个符号，汇编写的函数也是符号。可以直接声明 void foo，表示外面另一个地方有一个 foo，带有 int x 和 y 两个参数。汇编只要遵循 Application Binary Interface，就能与 C 互相调用。计算机系统基础课里讲过这样的约定。

例如，在 x86-64，也就是 64 位的 X86 上，汇编代码会认为 X 放在 RDI 寄存器里，Y 放在 RSI 寄存器里，以此类推，这叫 Calling Convention。调用到汇编时，它知道当前栈的布局，例如栈上有一个返回地址，也知道参数在哪里，可以用指令直接访问。Application Binary Interface 规定调用规范，让 C 与汇编能够互相调用。C 能调用汇编实现的函数，就可以进行系统调用了。Pipe、Fork 这些函数背后最终可能会进入汇编实现的代码，但也不绝对。另一种 FFI 方式是 Inline Assembly，即内联汇编。现在的 C 可以定义 Register、ASM 变量，将变量强制绑定到某个寄存器，由编译器处理。

也可以直接写一段汇编。例如，这段代码在 X86 上启动进入 _start 后，会把系统调用号和 ExitStatus 写入正确的寄存器，再执行 syscall 指令，可以正确编译并退出。这段汇编会原封不动地交给汇编器，意味着在 ARM 上尝试编译时，汇编器会因找不到对应指令而拒绝，报编译错误。
