第 09 课 · C 标准库原理

回顾：进程、地址空间与文件描述符

原片 00:01:27—00:09:10

我们花了好多次课讲操作系统，从最早只有一个名叫 _start 的函数、连退出都做不到的最小程序开始。在 _start 里写一个死循环，它就可以无限运行。用 ld、as 这套工具链把它变成 a.out，它就能在操作系统上执行。汇编代码可以使用系统调用相关的指令，访问操作系统及其中的对象。

我们讲过 fork、execve、exit 等 system calls：复制进程状态，reset 进程状态并选择一个可执行文件执行，或者用 exit 将整个进程状态从世界上消灭掉。无论用 C 还是汇编，进程都有指针和内存地址的概念。通过 mmap、munmap、mprotect，可以改变进程的地址空间；向操作系统申请后，原本无法访问的一些内存就可以访问了。unix 还提供了访问操作系统中各种对象的能力。例如，我的 fish 进程号是 6587，查看 proc 下 6587 下的 maps，就能看到它的地址空间。

这里列出了进程实际的地址空间：从哪一个地址到哪一个地址，分别映射了什么。还有一个叫 mem 的文件，位于 -proc 下的 pid 下。文件是很大的字节序列，是操作系统中的对象；这个文件恰好对应进程的内存。

我可以通过它读写内存，实现 hacking，例如游戏修改器，也可以实现调试器。以前操作系统一直很难教，大家觉得其中琐碎的内容很多。前面讲过 PTS，也就是终端，它有很多细节。4 号手册中的 PTS 介绍了 Pseudo Terminal 的 Master Slave；要创建一个新的 Pseudo Terminal，终端模拟器该怎么做？

我先让 AI 生成了一段代码，大家可以在 AI 辅助下阅读。也可以用命令把 PTS 手册完整打印到标准输出，再通过管道把输出交给 AI，这就是 UNIX philosophy 的用法。

终端中的命令

man -P cat 4 pts | claude Summarize

我要求 AI 给一个 summary，它读完手册后会生成总结。手册和总结都会留在上下文里，之后就可以继续对话。例如，我还不清楚 Pseudo Terminal 怎样创建，或者想用这个功能实现一个 Pseudo Terminal，该怎么写？

无论要求伪代码还是真实代码，它都可以给出，并且可以继续讨论。类似地，也可以读 5 号的 Proc 手册，其中有很多有用的信息；还有前面讲过的 7 号 Pipe 手册，介绍怎样创建匿名管道。

管道还涉及文件描述符的腾挪，以及很多复杂细节。例如，读者或写者消失时，可能会向持有另一端的进程发送信号。课堂上无法事无巨细地交代这些内容。并非所有同学都对底层 IPC 细节感兴趣；感兴趣的同学可以借助 AI 读手册。刚才一闪而过的内容中还有 non-blocking 选项，可以配置管道的行为。

例如，可以让管道在没有数据时不再等待。其他类型的进程间通信也可以这样查。昨天备课时，我直接让 AI vibe code 了一个工具，把所有手册以树状形式展示出来。我可以随便浏览，［听辨不清，00:06:24］，记得当时有五万多个手册，也可以搜索关键字。用现代工具，一行 shell script 就可以遍历所有手册。在 AI 前时代，必须自己花时间阅读；现在需要知道有哪些东西，并找到正确的方法，快速提取所需内容。UNIX 世界的系统调用基本讲完了，这三大类系统调用已经能实现应用世界里看到的所有东西。例如，要实现浏览器，需要知道操作系统有一个能画像素的 API。像 TTY 也能支持 Terminal 中的浏览器，Lynx 就是这样的浏览器。

在终端里也可以上网。要实现浏览器，需要通过类似 Open 的系统调用打开与网络远端的连接。AI 会告诉你，得到远端连接需要 Socket。有了连接，就能获取 HTML 网页，再解析和渲染。大部分工作都是普通计算，类似解析表达式或程序：写一个 HTML 解释器，在必要时向终端输出。

理论上，已经可以用这些系统调用实现任何东西。不过，整个应用软件生态并非完全直接构建在这些底层 API 上。写 Python 时，大家会喜欢用 pathlib，也会用 C++。今天要讲的，就是怎样从 C 和 Unix 这组很小的 System Call 接口出发，逐步构建出开发者满意、便于开发的生态。第一个入口就是 libc。对于底层的汇编程序来说，它一方面可以执行指令，另一方面可以使用系统调用，但这两种方式都很难用。打印一个字符串，需要用 Write 逐个字符或逐个 Buffer 输出；所有代码都手写会很麻烦，需要复用机制。libc 就是第一个这样的机制。C 和 libc 之上后来发展出了完整的应用生态，包括 C++、Python；Python 又发展出了今天的人工智能世界，而人工智能的一部分基于 CUDA C。
