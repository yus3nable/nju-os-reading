第 22 课 · 输入输出设备和驱动

lspci、lsusb 和即插即用

原片 00:45:00—00:46:15

现在在我的树莓派上它的拓扑 会和你们不太一样，比如说说在 x86 的系统上面，我们的 USB 的总线是挂在 PCI 总线上的，它有，上面 PCI 总线有一部分接了一个 USB 总线的控制器，然后 USB 还可以再接，再接一层一层一层往后接。然后我们也同样可以比如说 lsusb -t。然后你可以得到一个树状的 USB 的列表。

然后我现在把这个摄像头打开以后，打开以后应该就可以看到这个对，看到一个你看我的 Port001 上，我确实插在最右边的那个接口上，我在最右边的接口上插了插了这个摄像头，然后并且我把它打开，打开以后就有了这样的一个设备。

lsusb -t 输出中新增的 Video 接口片段：

|__ Port 002: Dev 003, If 0, Class=Video, Driver=uvcvideo, 480M
|__ Port 002: Dev 003, If 1, Class=Video, Driver=uvcvideo, 480M

对吧，Class 等于 Video，Driver 等于 uvcvideo，然后有 480 兆的传输速率，对，这是总线，总线它支持设备的发现，也可以有一些名字，比如说你扫描 PCI 总线的时候，你可以从那个设备上面得到一个设备号。然后那个设备，你可以通过那个设备号，知道它是哪一个厂商生产的，然后你可以加载相应的驱动，你就可以把这个设备给正确的运行起来了。然后当然了，总线其实是一个非常复杂的东西。
