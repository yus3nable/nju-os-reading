CXL 与分离式数据中心

原片 00:50:00—00:52:58

有 6PIN 和 8PIN 的供电口，OK，然后我们现在的这些真正高速的设备，像 FPGA 显卡，网卡，NVMe，都是连在我们的 PCIe 总线上，然后基于 PCIe 总线的物理层，还诞生了一种更夸张的协议，叫 CXL，叫 Compute Express Link，你可以认为它是下一代的，另一种数据中心里面常用的一种总线，它有三个 protocol，一个是 I/O，一个是 Cache，一个是 Memory。所以你看到它的野心，就是它不再是把这个像显卡。或者我们说的打印机这样的设备。

对吧，这种 Canonical Device 的 model，Canonical Device 就说，我的设备，本质上我是一个可能是一个比较慢的东西，或者是一个它和物理世界交互的东西，然后它通过 Register 和我的 host，就是我的 CPU 交换数据。然后但是它的野心在于，它希望有一个总线，可以直接在远端和我共享内存，它允许，首先它可以在本地和一个显卡共享，共享一个高带宽的内存，以及它最夸张的feature 是，它可以共享另外一台计算机上的内存。然后它们有一个高速网络互联。

来实现数据的传送，这就很离谱了，你就可以得到这个Disaggregated Data Center，就是你一个服务器，我一个 CPU，然后我这个CPU 本地当然肯定是有内存的，因为你只有本地的内存访问才够快，但我本地不需要那么大的内存。但是我在远端可能只有 16T 的一个共享的大的内存。然后这个 16T 的内存对我来说每一个内存都是可以寻址的，都可以像内存一样访问的，我甚至可以把这个整个16T 的内存。比如说我分配多少。比如说我 allocate 我要 4 个 T 的内存。

然后这个 allocate4 个 T 内存就在我的地址空间里，虽然我访问的时候如果比如说我的 memory hierarchy 命中的话，可能直接在我本地的内存就可以去走了，但是如果我是一个远端内存，它可能会有一次网络的 round trip，就可能会有几百纳秒的这样的延迟，但只要你的程序写的够好，你就可以实现这种数据中心里面的 disaggregated memory，也是非常离谱的事情，你可以想象就是，所以我上节课说，你去了真正的系统里面以后。你就会知道你教科书上学的所有东西都错了。

所以你能够留下来的就是你分析这些问题的基本原理，它们是什么，然后你应该怎么面对它们，出了问题以后你应该怎么诊断这些事情，这是总线，所以我们就讲了一些很有意思的 I/O 设备，对吧？到底来讲，它们都跟一个 LED 都没有本质的区别，就是交换数据。但是你只要能交换数据，我们就可以实现很多更有趣的东西，比如打印机，摄像头，总线。对吧，这样各种各样，真正使我们能够，计算机系统世界能够繁荣起来的，各种各样的 I/O 设备。好，那这都是底层的。
