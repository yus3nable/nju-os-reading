第 22 课 · 输入输出设备和驱动

PCIe 插槽与设备发现

原片 00:43:00—00:45:00

生态会不断扩大。常见总线包括插显卡的 PCIe，我先把显卡拔下来。英特尔 CPU 有一些 PCIe lanes，这是 PCIe 插槽。把显卡对准插到底，就完成了设备寄存器与总线上相应寄存器的连接。

插入后，设备与总线还会进行几轮通信，再由总线管理。CPU 可以通过 memory map 的 I/O 访问，无论显卡、网卡，都会建立寄存器数据通路，由总线把 CPU 的数据转发给对应设备。刚才访问磁盘、PS/2 的 PortIO、Portbase I/O，也是一种总线。总线是计算机的重要设计。USB 设备同样如此，插上接口，就完成类似连接。CPU 能询问总线上有哪些设备，比如 lspci，也就是 list PCI，大家也可以在自己系统上查看。
