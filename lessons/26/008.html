Hello 和 World 落到了哪里

原片 00:08:45—00:10:11

现在有 P1、P2 两个目录，虽然属于 root，也可以访问。向 P1 的 a.txt 写 hello，向 p2 的 b.txt 写内容。它们最终都会经过回环设备，落到 disk1.img、disk2.img 等文件。做 sync，确认写入已经落到这些文件，再查看结果。

Hello、World 会在哪？刚才在 P1 写 Hello，在 P2 写 World，具体哪个文件系统我不记得了。a.txt、b.txt 的数据被正确路由到两个镜像。［在镜像目录中查询两个字符串；保留现场结果。］

grep -n Hello *.img
# grep: disk1.img: binary file matches
grep -n World *.img
# grep: disk5.img: binary file matches

GUID partition table 把前半段作为 P1 文件系统、后半段作为 P2，数据确实落在这些虚拟磁盘文件中。
