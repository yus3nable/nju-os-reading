第 12 课 · 从零开始构建 Linux 应用世界

在模拟器中运行 Minix

原片 00:11:37—00:18:19

今天准备了一个 Minix。有爱好者完整存档了这个项目，下载这份代码后，直接 make minix2 就能从 GitHub 下载源代码，包括 Minix 1 和 Minix 2。里面有编译脚本，环境配置正确，Makefile 能正常执行时，就可以生成镜像。

Makefile：

MINIX := minix-1.7
# MINIX := minix-2.0

run: minix2
    cd minix2 \
      && ln -s -f images/$(MINIX)-hd-*.img hd.img \
      && ./runqemu

minix2:
    git clone --depth 1 --single-branch -b master \
      https://github.com/davidgiven/minix2
    cd minix2 \
      && ./mkall \
      && gunzip images/*.gz

.PHONEY: minix2

images 目录会生成多个镜像，包括 Minix 1.7 和 Minix 2.0 各自的 64 兆镜像。今天看很小，当时却已经很大。软件世界有很多随手可得、开源免费的工具，这次又能用模拟器。直接 make run 即可。我用的是一台 ARM 树莓派。

这台像小霸王一样的树莓派设备，把整个计算机系统放在键盘里，也能毫不吃力地运行 Minix 1.7.5。这是随书附送的代码，购买 Andy Tanenbaum《操作系统：设计与实现》教科书的人都可以使用。

Minix 也是 Linux 实现的原点。看日志，它找到了 HD0，即 QEMU hard disk，是 QEMU 中的磁盘。memory 部分还有一句 Minix executing in 16-bit protected mode，表示运行在 16 位保护模式。16 位意味着什么？大家没用过、也没在 16 位机上写过程序，但这是如假包换、与 Unix V7 兼容的 Minix 1.7。Minix 2.0 还兼容 POSIX，使用体验几乎和 Linux 一样。时间回到 1987 年、198 几年，就已经能得到几乎完整的 Unix 体验。例如 vi 编辑器，早就有了。它从 ex 演变而来；ex 是基于命令的编辑器，每条命令指定把光标移到哪里、将某行换成什么，逐行输入命令。

vi 则成为 visualized 的编辑器，可以用来编辑 C 文件。为证明机器确实是 16 位，可以写代码打印 sizeof(x)。这些 Unix 工具都能正常使用，但 shell 不支持用上下键重复上一条命令。可以 cat a.c，再通过管道交给 word count。

这么早的系统就已经有这些功能了。

a.c：

int main() {
    int x;
    printf("%d\n", sizeof(x));
}

今天大家日常在 zsh、fish 等现代 shell 中使用的管道命令，从那个时代起就有了。我现在还经常把输出管道给 claude -p。用 cc 编译，会生成 a.out。有没有 file？有。file a.out 显示它是 a.out 格式、Minix pc16bit 的 executable，接着就能运行。

a.out 打印出 2，是完整的 UNIX 体验。还可以用 man 看手册，竟然有颜色，今天 Linux 的手册也长这样：man1 是 user command，man2 是 syscalls，man3 是 library routines。

终端命令：

cat a.c | wc -l
cc a.c
file a.out
./a.out

还可以 man -k，不过没有 less，只有 more。系统提供了很全的工具、系统调用和库函数，还有 /bin，连完整源代码也包含在内。我不确定能不能找到——哦，可以，整个 Minix 世界的源代码都在这里。

不必在 Minix 里查看这些内容，也可以直接在 Minix1.7 的 usr、src 中找到源代码，包括内核、所有工具，以及刚才用的 vi、cc。它是完整可用的操作系统，UNIX v7 兼容确实有具体含义。

它能连接物理终端。今天没有那些设备，只能在模拟器里运行；在 1987 年，找一台支持的机器、接上终端，看到的就是这样。可以在系统中编辑源代码，Minix 也能编译自己。修改内核、操作系统功能，或增加一个系统调用，都可以在 Minix 里编译，再把内核镜像烧录到磁盘。它包含完整的启动加载器，firmware 加载后，系统就能运行，修改后的系统也能运行。这个体验很完整，能用它做各种事，例如生成文档、连接打印机，再把文档打印出来。
