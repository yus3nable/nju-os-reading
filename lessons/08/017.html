然后以及管道上一节课我们讲的，我们可以通过 pipe 系统调用，创建出两个文件描述符，一个指向管道的读口，一个指向管道的写口，然后这两个文件描述符，在 fork 以后也是继承的，这样我就分别把一个进程的读口关掉，一个进程的写口关掉。然后腾挪一下文件描述符，我就可以实现，把一个程序的输出，接给另外一个程序做输入。

课件中的重定向片段：省略文件名、execve 参数与 status 声明：

int fd_in  = open(..., O_RDONLY | O_CLOEXEC);
int fd_out = open(..., O_WRONLY | O_CLOEXEC);

int pid = fork();
if (pid == 0) {
    dup2(fd_in, 0);
    dup2(fd_out, 1);
    execve(...);
} else {
    close(fd_in);
    close(fd_out);
    waitpid(pid, &status, 0);
}
