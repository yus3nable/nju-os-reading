就要说一说，一个概念叫做确定性，这个词有点，对吧，有点拗口，你们有接触过这个概念吗？有没有说过什么，你们在哪一门课学哪一个概念的时候，学过这个确定性这个词，算法？计算复杂性？OK，你学过计算复杂性，确定性，所谓的确定性，这个字面的含义还是我很喜欢的，数学就是这种确定性，就绝对明确，没有分歧，没有别的可能性，只有一种可能性，这叫确定性。所以数学的确定性来自什么呢？数学确定性来自于函数的定义，你们在学离散数学的时候都觉得函数的定义是一个为什么要这样定义。对吧。你们至少花了一些时间去适应函数的定义。

然后你回头想数学里面的函数，这个对吧，f(x) = x² + 1，这个东西就是有确定性的，它就是一个 existence，它存在在哪，然后它确定下来了，你给一个 f(1)，它永远是同样的值，这个就是确定的，你不管在什么时间什么地点，调用这个函数 f，它总是一定产生唯一的，而且是确定的函数值，这就是数学的确定性。然后这个确定性使得我们研究数学，全世界的人研究数学的时候，可以都说同样的数学语言，大家达成共识，这个数学才能发展，计算机科学才能发展。然后程序的确定性和数学的确定性。

但是你在理解并发程序的时候，你去回到这个视角，我觉得有的时候还很有用，然而确定性就给了我们一种可控的感觉，对吧，这个程序你不会今天运行它是对的，明天它就不对了，至少这个测试用例，你这代码不改，你今天是 pass 的，你明天这个作业交上去，它还是 pass 的，对吧，总是可以重复的，这也是我们喜欢 functional programming 的原因，如果你们学过 SICP 的话，functional programming 它就要求你把所有的东西都写成是 function，是这样的数学意义上的 function。pure function，pure function 它就是一个绝对的 deterministically reproducible 的东西，这是我们喜欢的原因，但是引入了并发，彻底摧毁了这一点，我觉得完全是引入了一个魔鬼。
