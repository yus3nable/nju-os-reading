哲学家就餐：同时得到左右两把叉子

原片 00:48:30—00:51:30

它提出信号量，它一定程度上为了解决这样的一个困难的问题，叫哲学家吃饭问题，他说哲学家，你就想像每一个哲学家都是一个线程，然后他们围成一圈，然后围成一圈以后，他们其实筷子是一个更合适的模型，因为你需要凑齐一对筷子才能吃饭，但这个问题提出的时候，他们并不喜欢吃中餐，他们就想像的是每一个人面前都有一份饭。但是他如果要吃，他就要同时得到他手边的两个叉子。对吧，一共五个人，五份餐，五个叉子。然后他必须要，每一个人必须要得到他自己左手和右手边的两个叉子，他才能吃饭。然后他每一个线程。

他可以吃，也可以思考，然后在思考的时候，别人可以吃，所以他会把叉子放下来，吃完以后他会把叉子放下来，他希望能够实现这样的全局的一个同步 synchronization，我这里有一个这样的代码啊，大概是这样的，你可以忽略掉同步的、注释掉的代码，我系统里面有 N 个哲学家。

然后你们忽略掉我这些同步的代码，我们就创建 N 个线程是 philosopher，而这 N 个 philosopher，他们每一个线程都有一个左手有一个右手，对吧，右手的编号就是它自己的线程号，然后我的左手就是右手的叉子的编号-1。然后-1 相当于是+N-1。对吧，在 mod N 的意义上，其实就是-1，你就理解成是 ID，一个是 ID-1 编号的叉子，一个是 ID 编号的叉子。

int lhs = (id + N - 1) % N;
int rhs = id % N;

然后每一个哲学家都是一个死循环，他们会首先会试图，他们需要插入一些同步，比如说前面这是我插入的同步代码，你可以忽略它，中间我需要插入同步代码，使得我同时获得了左手和右手的叉子以后，我才能吃饭，然后吃饭完了以后，我又把这个叉子释放。然后使得其他的哲学家可以来吃，可以来吃。好。所以我们来想一想，哲学家吃饭，他能够吃的条件是什么，我有 A，B，C，D，E，有五个人。好，我有这个 1，2，3，4，5，5 个叉子，每一个哲学家吃饭的条件。比如说 A。他能吃的条件就是他左手的叉子和右手的叉子。

编号为 1 和编号为 2 的叉子，都是处于空闲的状态，并且他要把这个空闲的状态，如果他检测到这个 1 和 2 是空闲的状态，那么他就要把这两个叉子一起拿起来，他就变成不空了，这样他就可以吃了。
