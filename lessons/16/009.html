线程 join：多张桌子和一张桌子

原片 00:26:35—00:30:32

怎么样来用这种 happens-before 来实现一个具体的同步，比如说像线程的 join，线程 join 其实本质上和计算图是一样的，对吧，我的 main 线程要等到所有的线程都执行完，它才能继续。所以我可以为每一个线程的执行结束，都设置一个信号量，我 T1 有一张桌子。然后我结束了我就会把这个玩具摆到桌子上。然后 T2 线程他结束了，他把他的玩具摆到桌上，T3 结束了他把他的玩具摆到桌上。所以我有四张桌子。然后每个桌子上都有一个玩具，那我线程结束以后把玩具放到桌上。

然后我有的 main 函数我会从第一个线程开始，我先 P T1 的那个信号量，就相当于我在第一张桌子上我首先要拿走一个玩具，我才能继续，然后我在第二张桌子上可以拿走一个玩具再继续，拿走一个玩具再继续，等我把所有的线程的这个玩具都收到手里的时候，我就完成了一次线程的 join，这里面有一个代码，对，在每一个线程结束的时候我都对对应的那个信号量，向桌子上放一个玩具。然后我到这个 join 的时候我就把所有的玩具都收过来，那我就可以实现线程的 join。

sem_t done[16];
int count = 0;

void worker_init(int T) {
  count = T;
  for (int i = 1; i <= T; i++) {
    SEM_INIT(&done[i], 0);
  }
}
void worker_done(int id) {
  V(&done[id]);
}
void worker_join() {
  for (int i = 1; i <= count; i++) {
    P(&done[i]);
  }
}

但是呢，我没有说信号量它是可以支持多个玩具的，所以其实刚才那个过程你完全不需要为每一个线程设置一张桌子，你只需要一张桌子就够了，一张桌子就够了，是意味着我现在不，因为我的 main 主线程知道我创建了多少个线程，所以每一个线程它结束的时候只要往同一张桌子上放一个玩具就可以了。对吧，我现在还不确定能不能放……放不住。第一个线程结束了放一个，然后第二个线程结束了再放一个，对吧，第三个线程结束了再放一个，然后我的 main，我的 main 做什么呢？我的 main 就是一个循环。

我知道我创建了四个线程，那我就需要从桌上拿走四个玩具我才能继续，所以放和拿我都是，它都是无所谓的，直到我，但是我的线程只有我，主线程只有拿走了四个玩具我才能继续，所以我的主线程现在可能就拿了，对吧，拿走一个拿走两个，拿走三个，但只有第四个线程，在最后一次把玩具放到桌上，执行一个 V 操作的时候，这个我的 main 才把它拿走。所以信号量其实最合适的应用场景，就是管理这种计数型的资源，像游泳池里的人不能超过 N 个，停车场里面只有 N 个车位，餐厅只有 N 桌。

我要等 N 个线程，一旦是你，你是这种数数的，你就比较方便的使用信号量来完成，所以如果你要用信号量来实现 join 的话，就还有另外一个另外一个办法，初始的时候这个信号量是 0，相当于没有玩具，然后我的每一个线程在结束的时候都会 V，相当于把玩具放到桌上。

int count;
sem_t done;

void worker_init(int T) {
  count = T;
  SEM_INIT(&done, 0);
}
void worker_done(int id) {
  V(&done);
}
void worker_join() {
  for (int i = 0; i < count; i++) {
    P(&done);
  }
}

然后我的主线程如果我想要 join 的时候，我就知道，首先我要知道我要等多少个线程结束，然后我直接 P 多少次就可以了，每 P 一次我就要拿走一个直到我把所有的玩具都拿走，我就返回了，所以这也是一个其实是更节省空间的实现方法。对吧，这两个代码应该是都没有问题，可以正确的实现 join 的，我们看一下 main 函数，main 函数就是创建若干的 Worker，他会在里面 sleep 一秒钟。

void T_worker(int id) {
  printf("Thread %d start.\n", id);
  sleep(1);
  printf("Thread %d end.\n", id);
  worker_done(id);
}

int main() {
  worker_init(4);
  for (int i = 0; i < 4; i++) {
    spawn(T_worker);
  }
  worker_join();
  printf("Workers joined.\n");
}

然后执行 join，然后再打印一个 Workers joined，如果我们运行的话，你会看到确实是一二三四 Start 结束，然后 join，两种实现的方法都是正确，可以实现线程的 join，好。

这是使用信号量的方式。
