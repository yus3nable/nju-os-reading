第 14 课 · 并发控制：互斥

用原子交换实现自旋锁

原片 01:04:47—01:07:51

这里叫 spin lock，用法和 mutex lock 一样，spin lock、spin unlock 对应 mutex lock、mutex unlock。要实现它，计算机中没有直接可表示的钥匙，需要用变量编码。

可以用两个不同值，想象手里拿张写着 0 的纸，桌上另一张纸画着钥匙。

typedef int spinlock_t;
#define SPIN_INIT() 0
#define FREE 0
#define LOCKED 1

void spin_lock(spinlock_t *lk) {
    while (1) {
        int status = __atomic_exchange_n(lk, LOCKED, __ATOMIC_ACQ_REL);
        if (status == FREE) {
            break;
        }
    }
}
void spin_unlock(spinlock_t *lk) {
    __atomic_exchange_n(lk, FREE, __ATOMIC_ACQ_REL);
}

原子操作有很多种，除了 atomic 加 1，还有原子交换两张纸上的内容。手中是空白的 0，桌上写 1、代表钥匙。原子 exchange 后，0 写到桌上，钥匙到手里。只要 exchange 像 stop the world 一样不可分割，无论多少人竞争，只有最先交换的人能拿到钥匙。

后来的人都拿白纸来换，只能得到先前留下的 0。这个指令还有变体 compare exchange，先比较，相等才交换。也就是先看是否为钥匙，是才换过来。

没有钥匙时只读、不写，就能省一次内存写入，性能更好。atomic exchange 会由编译器生成 X86、ARM、RISC-V 对应代码，这是 built-in 能力。这里还用了更强的 acquire-release 内存模型。代码把 LOCKED 换进去，取出原值；若原值为 free，就能进 critical section。用法与 Mutex lock 完全相同，中间十次循环都做 sum++，确实能在多处理器上正确完成一加一，相当于手工实现 Mutex lock。
