用休眠线程测量资源开销

原片 00:16:31—00:19:08

也没有同学跟我反映过，其实我们可以问，也可以问这个问题，Linux 底下的一个线程到底要占多少资源，那我们有很多办法去回答它，比如说我们可以让 AI 去阅读 Linux 源代码，然后告诉我们，那我们也可以直接做一个实验，如果我想知道一个线程，你创建一个线程到底会在系统里面引入多大的开销，那我只要一个这个最简单的程序就行了，因为这个程序就几乎不占用任何额外的内存，相当于我这函数调用了以后，它就几乎不占用内存了，然后我会创建若干个 N 个，然后 N 是从命令行里面读取的，好，有这个程序，你知道问出这个问题，我就让 AI 帮我，我就让 AI 帮我写一个脚本，我根本就没有看，看都没有看。

sleep.c 的画面代码；依赖课程 thread.h，未包含该头文件实现。

#include "thread.h"

void T_worker(int T) {
  while (1) {
    sleep(10);
  }
}

int main(int argc, char *argv[]) {
  int N = atoi(argv[1]);
  for (int i = 0; i < N; i++) {
    spawn(T_worker);
  }
}

它的收益都是值得的，所以你可以做这件事，这是我觉得我在，这是我在操作系统上面，课上面，最重要的要告诉他的事，比如说，我创建 1000 个，1000 个它算出来，每一个线程要大约 16.9KB 的资源，这个资源就包括了操作系统内核里面各种数据结构，它需要增长，对吧，你创建一个的时候，你看不到那一点增长，那如果你创建足够多的话，一定程度上能够看到这个数据结构的增长，然后你看到我们用了多少的内存，你可以再去，比如说再跟 agent 去求证，更多的资源，系统里还有哪些资源。
