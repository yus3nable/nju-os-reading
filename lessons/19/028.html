JavaScript 的全栈生态与课程收尾

原片 01:19:34—01:22:35

这是 async/await 的语法糖，然后 JavaScript 就是这样，从一个对吧，10 天的时候设计出来的一个编程语言，逐渐的，因为它真的很糟糕，它有很多语法的特性，然后一度有各种各样的第三方库军阀混战的局面，因为第一个它支持 function as a first class citizen。

所以它编程的模型非常的灵活，你想干什么都可以，它在上面做什么事情，对吧，我可以做这个可以做这个然后甚至新标准的javascript，是用 javascript 写的一个 transpiler，它直接把新版本的 javascript 可以编译成，就代表上 async/await 的，编译成一个老版本的 javascript，这样就可以兼容的在所有的浏览器里面运行。然后在这个上面又生长出了一个完整的应用生态。对吧，从早期的 Angular、Bootstrap。然后到现在你。现在如果我们用的话 express，next，nest，然后再后来，大家发现网页好用以后，他说我们凭什么不能用网页，不能用 javascript来构建桌面应用呢？就有 electron，electron 是一个框架可以让你把网页变成一个应用程序。然后就有了 vscode。对吧。然后后来也想，我们为什么不能用写网页，写 react，写页面的方式来写命令行的程序呢？所以就有了 ink。然后 ink，你们可以去看这个ink，ink 是 Claude Code 的那个界面。

就是用 Ink 这个框架来实现的，然后还有更疯狂的人是想，我既然浏览器运行的性能那么好，我有没有可能在浏览器里面解释执行汇编代码呢？如果我能在浏览器里解释执行机器指令，那我不就可以在浏览器里运行 C 和 C++吗？我就可以在 JavaScript 里面可以和任何 C 和 C++程序互相调用。所以越来越多的人在这个生态上面，这很像操作系统，我们讲从操作系统那个 API，Linux 那个操作系统调用的 API，到 LibC。然后到高级语言 C++。然后一层一层一层再到 JavaScript。

浏览器和 JavaScript 的这个抽象层，在上面又长出了一个巨大无比的应用生态，不仅可以和 C 和 C++互相连接，而且还有像你看这种Mermaid用来画图的，甚至还有 TensorFlow.js，AI 用的 Three.js 用的很溜，你可以让它为你构建 3D 应用，真的是一个非常有意思的发展。然后大家回顾的时候，你会去想，里面的这些编程，就你们刚开始如果看 JavaScript 编程，遇到一些困难，async,await，这些，你不妨重新走一下并发。被发明。然后到被治理好的这个过程。
