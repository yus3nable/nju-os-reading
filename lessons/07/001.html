实验更新：用 AI 理解和同步框架

原片 00:00:00—00:06:56

上周发布了本学期实验。在 AI 辅助下，应该很快能完成。今年我试着让 coding agent 做实验，只说帮我完成，它就做到了。

第一个实验的大部分内容与操作系统关系不大，可以由 AI 生成，但 main 函数要自己实现。框架有个 bug，感谢同学发现。我在 22 号中午更新 main 分支：今年用了新框架，复制时却选错目录，放进旧 testkit。第一时间拉代码的同学，可能过不了 SystemTest。实验还有其他困难，比如须知里的术语不理解，或不会获取框架，如今可以借助 AI。

打开 coding agent，贴入实验要求，看看它的反应和思考。我相信现在 AI 能完成这类操作。

它知道要在命令行执行命令，还会检查目录文件，与实验手册比较，确认是否一致，再给答复。

它说代码已克隆到 OS2026，检查了目录结构，也给出额外提示，建议再查具体实验指南。持续追问，可能能帮忙完成全部作业，不过我不太建议这样做。今天演示的是同步框架更新。课堂说 3 月 22 号中午更新 main，大家可能不熟悉 Git，随时能问 agent。假装我还懂一点，可以看 OS Lab 的提交日志：21 号发布之前有几个 commit，22 号中午有一个 update testkit。

先知道想做什么，再提问题。比如 main 分支能否往前退一个 commit？即使用过 Git，也未必记得精确命令。告诉模型目标，它先 git log 查看提交历史，确认要回退的 commit。

它给出 git reset --hard，会覆盖当前内容，但这里是刚克隆的 repo，没有自己的代码，所以我选 yes。执行后，它确认 main 回退一个 commit，还说明本地恢复办法：git reflog 找到原提交，再 git cherry-pick 或 git reset。

现在 repo 相当于第一天 12 点钟之前克隆的版本，可以模拟学生同步更新。即使不熟悉 Git，只要知道老师更新了代码、希望同步到本地，就能问 AI。日志已显示 Your branch is behind 'origin/main' by 1 commit，接着问 how can I do，它会耐心解释。

我让它直接操作，testkit 更新，远程内容合并到了本地。以前新手上操作系统课，要做很多事、看大量文档，体验很差。今天需要的文档可以由 AI 阅读、解释，刚才短时间就接触了好几个 Git 命令。

包括 git reset、git fetch、git log、git merge。先建立能做什么的概念，再逐步熟悉工具。拥抱变化，让 AI 放大 Self Motivation，愿意做一点，就能往前推进。实验有疑问，可以邮件联系我或助教。当时收到那封邮件，我本来已准备离开办公室，赶紧回去修了 bug。
