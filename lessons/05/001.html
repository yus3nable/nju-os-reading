第 05 课 · 程序和进程；fork, execve, exit

回顾、Book 8088 与课程说明

原片 00:00:00—00:06:39

今天正式进入操作系统课程。先回顾一下，我带来了 Book 8088，忘记花了多少“巨资”。上次讲 Firmware 时提到过，这是 16 位计算机，眼前是固件启动日志。它启动确实很慢，有真正的 8088 CPU，外设则采用更现代的实现。别小看它，它真的可以编程。刚才测试时，打开了类似 IDE 的编辑器，可以想象那时若有 Claude Code，也能实现各种功能。比如用 LINE，给出 11、100、100，应该能画一条线段。我还有肌肉记忆，按 F5 运行，切到图形模式，确实画出了线。

那时几乎什么都能做，还能播放声音。IBM PC 是完整的系统，输入 SOUND，比如 100 赫兹，［听辨不清，00:01:33］，再输入 SOUND 1000 赫兹，两条命令就有两个频率的声音。它和今天的计算机系统没有根本区别，我今天也几乎都在终端里工作，打开 Claude Code 就能完成。再澄清几个问题：有同学问课上用什么模型。直接问它，可能会说自己是 anthropic 的 4.6，但详细日志里能看到豆包。

上节课使用的模型：doubao-seed-2.0-code

实际调用的是豆包，上次课第一次用。试过几家后，［听辨不清，00:02:30］的模型也挺好，但课堂上响应最快、体验最好的是豆包。后来给更多任务，却发现它相比 anthropic、codex 这样的模型，智力很低，经常不听指令。即便如此，它也能帮忙完成操作系统实验。世界进步很快，大家需要花时间跟上变化。

回顾应用视角与硬件视角

回到正课。刚才这个老 CPU 是 16 位，没有保护模式，没有 32 位、分页、MMU 等机制。这样的电脑也是 state machine，状态是 memory、register，也连接物理世界。看接口，这是 VGA——不对，这不是 VGA，是 RS-232。

这可能是并行口，我猜是很老的接口，小时候用过。CPU 每次执行一条指令，reset 后各寄存器值由手册规定，从 firmware 开始执行。操作系统起初可能是磁盘上的一段代码，经固件加载到内存，作为普通程序运行，再支撑 a.out 等应用生态。应用也是状态机。前面既在建立概念，也想说明：硬件、程序都有明确的数学模型。今天不需要自己掌握每个 bit，AI 知道，但要知道背后都有答案，没有魔法。从用 ld 生成最小 _start、控制第一条指令，又看到它 crash 开始，可以逐渐解开计算机系统的疑问。

课程分 3 easy pieces：Virtualization、Concurrency、Persistence，与教科书相同。Virtualization 讲怎样把一台计算机变成多个应用程序同时执行的抽象。每个程序好像独占一台计算机，有了虚拟化后，自然又带来 Concurrency 的问题。最后 Persistence 讲操作系统与外部交互。

从虚拟化开始操作系统正课

虚拟化讲 one of the most fundamental abstractions that OS provides to users the process，也就是进程，怎样把一台物理计算机抽象为多台虚拟计算机。从现在起，每讲都会介绍一些操作系统 API、设计原因，以及能用它做什么。希望每次课都能扩展一点能力边界。仅学习编程语言机制，有些 hacking 做不了；学了操作系统，就能做一些新的 hack。
