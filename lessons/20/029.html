SIMT：独立寄存器与共享的 PC

原片 01:18:00—01:22:30

这个代价都是不能接受的，对吧，一个线程如果你有 1kb 的 cost，你创建 200 万个线程，这件事情根本就是不可能的，所以 CUDA做了这样的一件事，CUDA 允许你创建非常非常多个线程，但是它会非常小心的把它调度到它实际的硬件上，我们刚才说，说这个疯狂想法是说，我们的每一个 CPU 里都要有的，比如说 ALU 对吧，ALU 肯定得有。然后以及每个 CPU 里面都会有 registers，registers。那这个 registers，每一个 CPU 也必须要有一份。

所以当我们的这个 T_worker，先这样，T_worker 被送到这个线程上的时候，送到这个 CPU 上的时候，或者说这个是一个 GPU 的执行单元上，我们的 T_worker，那我们 T_worker，比如说 01，我用这个例子。比如说我现在有好多个 T_worker，比如 (3, 0)、(3,1)、(3, 2)。

课件中的三个相邻像素写入片段；省略其他线程，color_0 等表示各线程计算的结果。

screen[3 * 1920 + 0] = color_0;
screen[3 * 1920 + 1] = color_1;
screen[3 * 1920 + 2] = color_2;

所以我就会让这个 CPU，它的寄存器里面有 3 和 0，然后我会让这个 CPU，它的寄存器里有 3 和 1，我会让这个 CPU 的寄存器里有 3 和 2，然后这个寄存器里面，比如说我们现在每一个像素点，都要算一个它的 Mandelbrot set 的颜色，那比如说那我机也会有一个寄存器，是它的颜色。比如说 color，最后算出来的 color。当然我里面可以有更多寄存器。比如说我有循环变量 i，每一个 CPU里面都有 ALU 和算术单元和寄存器。然后我们干的事是，为了让它们能够并行执行。

我们和现在的 CPU 是不一样的，CPU 现在 CPU 就是，如果我把三个线程加载到三个 CPU 上，它们就各自执行各自的，它没有同步，对吧，就放出去执行了，我们执行 spawn，执行完了以后我们就不管它了，我们要等它结束，我们就得 join 它。但是 GPU 不是这样的，GPU 里面引用了一个概念叫线程束，Thread warp，我要把它们全部捆起来，你想一想，现在如果只有 ALU 和寄存器，或者说只有这些数值型的寄存器，这个程序还是不能执行的，还缺什么。

还缺一个非常重要的寄存器，Program Counter，对吧，你只有 Program，有 Program Counter 这个程序，它才能知道下一条指令执行什么，然后我们的 CPU，对于 CPU 来说，我们的 Program Counter 是在这里的，对吧，CPU 的 Program Counter 是在这里的，这也就意味着，我们的每一个 CPU 里面都有一个 Program Counter，结果也就在每一个 CPU 里都有一个取指令和译码的部件。但是译码。

我说译码是要浪费电路的，对吧，你们都写过那个 NEMU 的译码的逻辑，那个指令就 32 个字节，但你译码完以后就一大堆 if-else，一大堆 if-else，然后这些 if-else 在实际的电路里面完了以后，每一个情况它是，我是不是 Jump 指令，是不是 LoadStore指令，我 Load 的是一个 byte，两个 byte，一个 byte，两个 byte 还是四个 byte，这些信息全部都是一根线，这些线都是要占电路的，都是要占逻辑门的，还要占触发器。

所以，CUDA 把它们捆起来的意思就是，好，我所有的线程，这些线程，我不能有独立的 PC，我的这一捆线程有只有一个 PC，这也就意味着，比如说这里有 32，在这个现代 NVIDIA 的实现里面，一个 Thread warp 里面，有 32 个线程。然后 32 线程就是 32 个T_worker，执行一样的代码的 T_worker，他们共享一个 PC，只有一个 PC 就意味着我只需要一个一个译码单元，我就省下了电路，这样，就是你看。我的 overhead。我交的税。

相比于我实际的参与计算的东西，对吧，我寄存器是省不了的，没有寄存器我就没法计算，没法执行指令了，没有 ALU 我也就没有办法并行了，所以这些电路都是绝对没有办法省的电路，然后他把这些绝对没有办法省的电路，留着，能省的 PC，Decoder 只放一份，他交的税就变少了，这样他的税就交的非常非常的少。

OK，然后这就是一个这样的，基本的叫CUDA 的 Single Instruction，Multiple Threads 的模型，叫单指令多线程，也就是说我只有一个 PC，但是我一次是把很多个 T_worker 都往前执行一步的，神奇的事情就发生了，你看，如果说，我把这个 (3, 0)、(3, 1)、(3,2) 这些 T_worker。
