第 21 课 · 一个 Token 的旅程

矩阵布局、分块和数据搬运

原片 01:17:00—01:19:40

也可以不加。不过还没有发明 PTX 里的那个 SIMD。GPU 设计者面临的难题是内存移动和布局优化。两个大矩阵相乘，最大的麻烦来自行列访问。

矩阵乘法是一行乘一列。还记得行优先、列优先两种存法吗？内存是 linear addressing，线性编址，没有二维结构。我觉得二维内存也可以做，但目前用分块等办法，让访问接近二维。

直接访问时，一个矩阵符合 cache-friendly，另一个就不符合，总要牺牲其中一个的连续访问。现在的办法是分成小块，也就是 tile。官方博客里可能看到 cuTile、TileLang 这些词，都是应对硬件和系统设计限制的做法。

每一块都能进入缓存，才能高效计算。所以 tensor core 还要处理多维寻址、稀疏数据搬运、压缩解压缩、跨步访问、异步同步、内存布局转换等问题。比较新的 GPU 有 cp.async.bulk.tensor，支持稀疏数据拷贝，也支持 zero overhead 转置。取出两个这样的矩阵块时，其中一个需要转置，才能改写为连续的 inner product。这些工作都为了同一个目的：让刚才的 Cuda 程序、Cuda kernel 更高效地运行在 GPU 上。
