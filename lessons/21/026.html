第 21 课 · 一个 Token 的旅程

Attention：Q、K、V 与短时记忆

原片 01:06:40—01:09:52

在你要实现这个系统的时候，你很自然而然都会要用到的概念，然后在深度学习，继续往后发展的时候，到了 transformer 的时候，又有一个跨时代的发明，叫 self-attention，是吧，每一层的 transformer，我回头想了一下，我今天花了点时间来想，我怎么给大家打一个比方来讲，什么是今天的大语言模型。

然后我觉得，我觉得可以打这样的比方，每一层的 transformer 都是一本书，你可以这样想，比如说我有一本书，然后我们的大语言模型做的事情是，next-token prediction，对吧？就是，买什么什么什么什么，或者 answer my question，什么什么什么。然后它要 predict 的是，是 next token。然后这个就叫就叫 q，就 query。然后这个是动态的，每一次都不一样，每次至少这个都不一样。然后还有一个东西叫 k。还有一个东西叫 v。q 就是这个要补全的句子，然后 k 就是书的一个目录，书本的目录，v 就是书那个具体的内容，然后所以是先做一个什么呢？先是把就 q 和 k 在一起，它会去这里找出 v 里面的一些。

相当于是，它会把 v 里面的一部分，以比较高的权重给取出来，相当于是有些部分就书里面，这个书里面有很多东西，是不重要的，或者说对于这个我这句话来说是不重要的，补全这个任务来说是不重要的，然后不重要的话，我就把其他的这些东西都给删掉。但是我可以把这个书里面的一些有用的东西给取出来，完了以后我会做一个运算。对吧，会做一个 softmax。然后再乘以 v 的运算。然后运算完了以后，就相当于我就会形成一个一个很大的向量。然后这个向量就是我的瞬时记忆，相当于我的短时记忆。就每一层，你的每过一层 transformer，就像是你的人去思考了一层，然后思考了一层以后，你就会得到一个短时的记忆，大概是我已经把所有的，这里面的东西的内容都消化了，并且是就这一本书去消化的，就这本书去消化了。然后消化完了以后，它再去重新生成一个这样的结构，长得像这样的结构，传给下一层的 transformer，相当于什么呢？我根据我现在的问题，先去查书。然后查完书以后，我在我自己的大脑空间里面，会产生一个想法。然后这个想法会过几层，这种 dense 的神经网络。

就是做几次，经过一些比较，相对比较复杂的计算，然后完了以后，我再重新把这本书给，把我的问题给重写一遍，然后重写一遍以后，再过再过再过再过，我每往上一层，我的信息的密度就会越接近于我要输出的最后的 next token，最有意思的地方就是你刚开始的时候，你还是看到的就是你的每一个 token。但是你等到越后面的层的时候，你越来越不知道你看到的是什么了，这里面的书的每一个部分也都是你学出来的，就书里面的每一个东西也是你学出来的，一个非常有意思的架构。

甚至我们觉得这个架构，它的潜力还没有到头。

课件中的 CUDA 启动片段；... 表示省略参数，依赖 CEIL_DIV、kernel 和 CUDA 错误检查函数。

void matmul_forward(float* out, ..., int B, int T, int C, int OC) {
    int sqrt_block_size = 16;
    dim3 gridDim(
        CEIL_DIV(B * T, 8 * sqrt_block_size),
        CEIL_DIV(OC, 8 * sqrt_block_size)
    );
    dim3 blockDim(sqrt_block_size, sqrt_block_size);
    matmul_forward_kernel4<<<gridDim, blockDim>>>(
        out, inp, weight, bias, C, OC
    );
    cudaCheck(cudaGetLastError());
}
