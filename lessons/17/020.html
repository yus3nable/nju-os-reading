第 17 课 · 并发 Bugs 和应对

Therac-25：伤人性命的并发 bug

原片 01:02:30—01:04:30

并发 bug，稍微扯出去一点，因为今天本来就是讲一些比较实际的东西，在这有个故事，我们都说，race condition 是 undefined behavior，当然这个 undefined behavior 和那个 C 里面的不太一样，我今天有一个伤人性命的并发 bug 的例子，叫 killed by a machine，有一个 Therac-25 的事故，大概 1985 到 1987 年的时候，有一个放射线的治疗仪，它能够发射这个高能的 X 射线。

然后最终它是这样的，它有一个它有很多束光最后会聚焦在一个地方，然后相当于它可以精准地选择你身体里面的任何一个位置，就你身体里面的任何位置，在不伤害你其他组织细胞的时候，把里面那个位置给烧穿，就是硬烧。然后这个治疗仪有一个事件驱动的并发 bug，导致了至少六个人死亡。所以这个是一个非常有名的并发的 bug，这个图不太好，它是这样的，这个 Therac-25 有两个模式，有一个模式是低剂量照射的模式，相当于它以很低的剂量先帮助你定位。

assert mode in [Electron(Low), XRay(High)]
assert beam_flattener in [On, Off]
assert not (mode == XRay(High) and beam_flattener == Off)

然后它可以拍片，然后还有一个是高剂量模式，就真正灼烧的，烧你的模式，但烧的时候它里面有一个反射镜，有一个 beam flattener，有一个反射镜，然后这个反射镜，我不确定它是什么，它会以一个机械的方式，会移到射线源的下面，这样它可以控制进入人体的辐射剂量，但如果在没有这个反射镜的时候，大剂量的这个射线直接照射你，你就按照那个患者的说法是，他们在接受这个治疗的时候，瞬间感觉到很强的灼烧感。然后可能也没有太久。但是他们逐渐就因为接受了过量的这个照射。然后导致这个最终死亡。
