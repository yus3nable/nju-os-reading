第 17 课 · 并发 Bugs 和应对

顺序执行直觉与原子性、顺序违反

原片 01:09:30—01:14:30

不上锁不就不会死锁了吗？换言之，如果我们把每一个共享内存访问都上锁，这是掩耳盗铃了对吧，对吧，我每一次 sum 加加的时候，我都给 sum 加一个 sum 的锁，每次 sum 加加都加一个 sum 的锁，我不就消除了所有的数据竞争吗？它确实不会产生这种weak memory model 的这种行为了。但是你哪怕给每一次 memory access 上锁，你依然没有解决所有的并发里面的问题。当然当然了对吧，我们回过头来思考一下，刚才那个伤人性命的并发吧。

就是因为我们在编程的时候，太容易做顺序执行的假设了，我们的本质就是 sequential creature，然后我们在编程的时候，一开始大一学编程的时候，你们的函数返回天然是带一个同步的，函数调用是同步的函数调用，你们甚至都没有讲过，在上课的时候没有教过你们函数调用是同步的，因为函数就自带一个 all or nothing 的原子性，当我把控制流交给那个函数的时候，eventually 那个函数一定会把所有的事情都执行好。然后返回给我。这就是我们对函数的一个 expectation。

当我调用它的时候，它总会返回的，而且带着正确的结果回来，如果没有 bug 的话，所以 Therac-25 也是的，刚才那个代码，如果我们那个模式的切换，你看我在切换模式的时候，那个机械装置在开始运动，如果这个机械装置运动都是在一瞬间完成的，或者说你的所有的操作都是同步的，我机械装置，这个开始运动的时候，我就不能执行任何指令了。

当然这个对操作员的体验很差，对吧，你如果是瞬间完成的就没有任何问题了，但是实际上它有一个异步的在未来这件事情才完成的一个系统的语义，但因为我们在编程的时候已经形成了所有的事情都是立即生效的肌肉记忆，对吧，我做了这件事，我做了 switch mode to x-ray，那么模式就应该变过去了，而不是说等到一段时间以后，它才，模式才会变过去，因为我们形成这样的记忆，再加上现在所有的并发控制的机制都是后果自负的，对吧，我们说 lock unlock，你自己没上好锁。那对不起，你就错了，然后你的条件变量，你没有做好，你也错了，所以这就带来了两种类型的并发 bug，一个叫 atomicity violation，一种叫 order violation，然后 atomicity 就是你上锁，你可能就算是每一个共享内存都上了锁。但是如果你有一件很大的事情。比如说你就希望 sum++看到的所有的值都是偶数，但如果你只是 lock a，sum++，unlock a。然后你再 lock a，sum++，再unlock a。好。如果你希望这个 sum 永远是偶数，你可以在这 lock b，对吧，unlock b，那么所有是这样写代码的，它都是偶数，但是你有一天，就有可能有一个线程忘记了，你写了个 lock c，对吧，然后你再 lock a，sum++，unlock a，就是因为这把锁上错了，这个程序是没有任何 data race 的，对吧，data race 的定义，定义是要能同时发生的一对内存访问，至少有一个是写，发生的两个线程，它必须要能同时发生。然后这个是不可能同时发生，因为你所有的 sum 都是用一把锁正确的保护的，但是它还是一个ABA。

它叫 ABA，我本来这个 A 是希望是 atomic 的原子的，因为我写代码的时候，我是 sequential creature，我自然而然的会觉得我需要一把头，顺序地把它执行完，但是被别人强势插入，我就被打断了。然后这个程序就错了。然后另一种是 order violation，就是因为你条件变量或者信号量没有做对，或者同步没有做好，你导致顺序出错了，那也是一个非常常见的并发 bug。所以就有这样的argument，叫 Threads cannot be implemented as a library，这也是我们今天可以思考。

尤其是在有 AI 的时候，你完全可以让 AI 用更安全的方式来实现并发，而不需要用底层的这样的线程库，当然因为我们是操作系统课，你们还是学计算机专业的学生，你们要知道所有的底层，比如说操作系统里面是用什么样的技术来实现同步的，所以你们还被迫要学这些，但当你们真正开始写代码的时候，我觉得像 Threads cannot be implemented as a library，我觉得这是一个正确的argument，锁首先它是可以用的，我是可以把程序写对的，但是你很容易搬起石头砸到自己的脚。

所以我们要彻底杜绝你能够搬石头的任何的可能性，想用一种更高级的语言，更高层的语言来描述你想要做什么，然后由编译器来保证它生成的代码，一定不会有这种奇奇怪怪的并发的问题，一定满足你的需求，好，这就有意思了。

当然这是上一个时代的研究工作了。
